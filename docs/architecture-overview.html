运行时架构总览

一台装在本机的 AI 助手：Tauri 外壳拉起一个只监听回环的 Python 服务，回合引擎在模型与工具之间循环，每一次写文件、跑命令、发消息都要先过权限闸门。模型不出本机自己走，而是经公司自有的 Cloudflare 边界出海。

主链路：一次对话回合

  • 1界面通过 WebSocket /ws/session/{id} 提交，本地服务只认回环与桌面 WebView 的 Origin
  • 2会话管理器按会话取引擎，绑定工作区文件夹
  • 3引擎装配上下文后开始一轮
  • 4按模型名前缀选 provider
  • 5出海只走公司边界，登录态即凭证
  • 6网关转发到真正的模型厂商
  • 7模型要调工具，先过闸门定级
  • 8放行后执行，结果回引擎继续循环，直到模型不再要工具

三条边界与授权

  • 本机：服务只绑 127.0.0.1，随机端口 + 每次启动一把令牌，Origin 白名单挡住浏览器页面，WS 有帧长与频率上限
  • 用户点头：风险分 read / write_local / exec / external 四级，配合讨论・计划・交互・自动四种模式与工作区信任、路径作用域
  • 公司 Cloudflare：域名、Access 名单、限额与用量流水都在管理员手上；中转自己一把 key 都不存，只在转发瞬间经手
  • 第三方：模型厂商、SaaS、MCP 服务器均逐个授权，连接器令牌只落本机

常驻与无人值守

  • 关窗口不退出：托盘常驻，调度器与消息网关继续跑
  • 调度器补跑漏掉的一次、同一任务不叠跑
  • Slack 等入站消息经网关按白名单落到会话
  • 无人值守时要问的事进收件箱排队，回来再一次性处理，审批可断点续跑
  • 另有一条 OpenAI 兼容端点 /v1/chat/completions，把整个运行时当后端用

上下文与落盘

  • 专家库随包分发：270+ 中文专家、163 篇技能（含中文译文层）
  • 技能渐进披露：先给目录，用到才加载正文
  • 还会拼进工作区 AGENTS.md、记忆、已授权目录与团队看板
  • 会话索引进 SQLite，消息按会话追加写 .jsonl；密钥与审计各自独立
  • 上下文涨满自动压缩，不打断当前回合
