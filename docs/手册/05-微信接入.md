# 05 · 微信接入

> 读者：想在微信里使唤 agent 的人，以及帮别人排障的管理员。
> 只讲**个人微信**。企业微信是另一套东西，这里不涉及。

## 1 · 连接

**连接器 ▸ 微信 ▸ 连接 ▸ 扫码连接**，用手机微信扫，手机上点确认。

扫完之后微信里会多出一个**机器人会话**。它是一个独立身份（形如 `xxxxx@im.bot`），
**不是你自己的微信号**——你的号、你的好友、你的群都不受影响，对方看到的是这个机器人。

**二维码最多自动刷新 3 次**（每张有效期很短）。三次都过期还没扫上，会提示失败，
重开一次即可。一直失败通常是网络到 `ilinkai.weixin.qq.com` 不通。

凭据（account_id、token、base_url）只写在本机：

| 系统 | 位置 |
| --- | --- |
| Windows | `%APPDATA%\coworker\secrets.json` 里的 `weixin:default` |
| macOS / Linux | `~/.config/coworker/secrets.json` 里的 `weixin:default` |

轮询游标、上下文令牌、解密后的媒体缓存在同目录的 `weixin/` 下。

## 2 · 第一次通话：谁能发给你

**扫码的人会自动进白名单**——二维码确认时腾讯会回传扫码人的微信身份，所以"谁要接入"
这件事扫码本身就回答了，你自己不用再授权一次。

**其他人默认一个都不放行**：机器人 ID 是可以被搜到的。

别人的第一条消息会停在连接器页的「来自未允许发送者的消息」里等你处理，三个按钮：

| 按钮 | 做什么 |
| --- | --- |
| **允许并投递** | 加白名单 **+** 把刚才那条消息补投一遍。**首次接触用这个** |
| 仅允许 | 只加白名单，这条消息丢弃 |
| 忽略 | 只丢这条，对方仍然不在白名单 |

> ⚠️ **补投补不回附件。** 对还没允许的发送者，图片、视频、文件根本不会下载
> （不然陌生人就能往你硬盘里塞东西），停在这里的只有文字，agent 收到的是一句
> 「发送者未授权，附件未下载」。所以第一条如果带附件，允许之后还得**让他重发一次**。

要移除某个人：在「允许发消息的对象」里点他名字后面的 ×。

## 3 · 回复从哪来

私信没有「发到哪个频道」的选择，所以不用你配置：微信还没有指定会话时，第一条私信会自动
新建一个（叫「来自微信的私信」）接手，之后所有微信私信都进这一个会话。

要换成别的会话，在连接器页的 **「谁来回私信」** 下拉里选。**这个设置是按连接器分开的**
——微信、Slack、Telegram 各有各的会话，互不抢占。

该会话的回复会**直接发回微信**，不会每条都弹框问你。收到的图片和文件所在的目录也会自动
授权给它，agent 能直接读。

agent 思考期间，对方的微信里会显示 **"对方正在输入中"**，答完自动消失。

**没收到回复时先看这里**：**收件箱 ▸ 配置 ▸ 未路由**。
每一条没人接收、或者接收了但那一轮跑失败的消息都存在这里，并写明原因，比翻日志快。

> 原因那一列是**后端原文，基本都是英文**（比如 `No Anthropic API key configured…`、
> `Error code: 400 …`、`could not open a DM session`）。看不懂就整句搜一下，或者对着
> 下面第 9 节的表。

## 4 · 能收什么、能发什么

**收（对方 → agent）**

| 类型 | 怎么处理 |
| --- | --- |
| 文字 | 直接给 agent |
| 语音 | **微信给了转写文字就用转写**，标成 `[语音转写] …`；带音频时另存一份 `.silk` |
| 图片 | 从腾讯 CDN 下载、AES-128-ECB 解密，存成 `.jpg` |
| 视频 | 同上，存成 `.mp4` |
| 文件 | 同上，扩展名沿用原文件（不认识的一律 `.bin`） |
| 引用某条消息 | 被引用的内容和其中的媒体也会一并带给 agent |

媒体存在本机 `weixin/media/` 下（Windows 是 `%APPDATA%\coworker\weixin\media\`），
**落盘用的是随机文件名**（原文件名只出现在给 agent 的那句提示里，agent 拿到的是完整路径）。
下载和 AES 解密都在后端做完，agent 不用联网。

接收微信私信的那个会话**会自动拿到这个目录的只读权限**，所以 agent 能直接读。
换成别的会话接收时，如果它打不开附件，在该会话的
**访问权限 ▸ 「+ 授权访问文件夹…」** 里把这个目录加进去即可。

> **图片和视频给了路径也"看"不了**——目前没有把微信收到的图交给模型看图的通路，
> agent 只能拿到文件本身。

> **微信没给转写的语音，内容就丢了。** 方言、嘈杂、太长都可能没有转写文字，这时 agent
> 只拿得到一个 `.silk` 路径，而 `.silk` 是微信私有格式，本机也没有解码器。碰到这种情况
> 补发一句文字就行。

**发（agent → 对方）**

**只能发文字。** 超长回复自动拆成多条按顺序发（单条上限 2000 字符），优先在空行、换行处断开。

> ⚠️ **扫码生成的个人微信机器人发不了图片和文件。** 上传通道（`getuploadurl`）对这类身份
> 一律回 `ret: -2` 且不给任何说明，而同一个 token 上的其它接口（如打字状态）完全正常
> ——**这是腾讯侧的能力限制，不是配置问题**。代码里的加密上传链路是齐的，一旦这个身份被
> 放开就能用。现在 agent 会收到一句明确的"这个机器人发不了附件"，然后改用文字或告诉你
> 本机文件路径。

**Markdown 会为微信重排。** 微信客户端把消息按 Markdown 重新渲染，而它的子集很窄：
列表和链接能用，标题、表格、``` 代码块都不行——**单个换行会被吃掉变成空格**，
所以原样发出的代码会挤成一整段、缩进全没。重排规则：

| 原文 | 发出去变成 |
| --- | --- |
| `# 一级标题` | `【一级标题】` |
| `## 二级及以下` | `**二级及以下**` |
| 表格 | 每行拆成 `- 列名: 值` 的一组（微信渲染成项目符号，一条一行） |
| 代码块 | 去掉 ``` 标记，**每行之间空一行**（唯一能存活的换行），缩进改用不换行空格 |
| 列表、链接 | 原样（微信本来就渲染得对） |

代码因此会显得很高，但**能读、能复制、能跑**。

## 5 · 会话过期：重新扫码，别断开

腾讯侧的登录会话会过期（错误码 `-14`）。这时轮询会**暂停 10 分钟**再试，日志里写
`session expired`。界面上不会有提示，卡片仍显示已连接——**症状就是"突然不回了"**。

**恢复方式：连接器页 ▸ 「重新扫码」。** 扫一次新码，**已允许的联系人不会丢**。

> ⚠️ **扫码会换一个新的机器人身份。** 每次扫码都是向 iLink 新申请一个 bot，`account_id`
> 会变（`xxxx@im.bot` 换成另一串），微信里会**多出一个新的机器人会话**——旧的那个从此
> 是死的，之后要跟新的那个说话。白名单里存的是对方的微信身份，所以**不用重新授权**，
> 但得告诉大家换会话了。

> ⚠️ **别用「断开连接」**。断开会把整个 weixin 配置删掉，白名单一起没，而且**断开期间
> 消息是彻底收不到的**（连接器已经不在跑，不会有任何东西停在「来自未允许发送者的消息」里）。
> 重连之后每个联系人都要重新允许一遍。「重新扫码」至少保住白名单。

## 6 · 一个机器人只能一个应用收

`getupdates` 是**取走即删**的：谁先问到就归谁。两个 OpenWorker 用同一个机器人 token 轮询，
就会各拿一半消息，而且**两边都不会报错**——只是有一半消息凭空消失。

现在同一台电脑上的第二个会被挡住：微信连接器**拒绝启动**，日志里写

```
another OpenWorker instance on this computer is already receiving WeChat messages
for this bot. Close the other one — two pollers on one bot token each take half
the messages.
```

> 界面上没有提示，只有日志。被挡住的那个应用其他功能照常，只是微信收不到消息。

碰到这条：关掉另一个 OpenWorker（包括开发时手起的 `openworker-server`）再重连。

**这把锁只管同一台电脑、同一个用户配置。** 两台机器拷同一份凭据同时跑，锁互相看不见，
照样各收一半。要在两台机器上用，**各自扫一次码**——每次扫码生成独立的机器人身份和 token，
互不干扰。

## 7 · 群聊为什么不行

扫码生成的是一个 `@im.bot` 身份。这类身份**收不到普通微信群的消息**，一般也加不进群。
这是腾讯侧的限制，不是配置问题——把它当成一个只能私聊的联系人。

---

## 8 · 目前做不到的事

诚实清单，免得你花时间试：

- **agent 发不了图片和文件**（腾讯对个人机器人的限制，见第 4 节）。
- **消息只在应用运行期间接收**。应用关着的时候对方发的消息，下次打开会补上——游标存在
  本机，重启后从上次的位置接着拉；但应用不在跑就没有任何推送。
- **群聊收不到**，见第 7 节。
- **语音没有转写时读不出内容**，见第 4 节。

## 9 · 排障对照表

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 二维码取不到，弹出获取失败 | 到 `ilinkai.weixin.qq.com` 不通。查网络/代理（有 35 秒超时，不会一直转） |
| 二维码反复过期直到失败 | 服务器是通的（能查到过期状态），单纯是没在有效期内扫上。手机准备好再点一次 |
| 对方发了消息，连接器页什么都没有 | 应用没在运行，或连接器被停用 |
| 消息停在「来自未允许发送者的消息」不动 | 正常，等你点「允许并投递」 |
| 允许了，还是没回复 | 看 **收件箱 ▸ 配置 ▸ 未路由**，原因写在那里（英文） |
| 未路由写 `No … API key configured` | 去 设置 ▸ 模型 填 key |
| 未路由写 `Error code: 400 …` | 模型侧报错，整句搜或找管理员 |
| 回复进了别的会话 | 在连接器页「谁来回私信」里改，各连接器互不影响 |
| 突然不回了，日志有 `session expired` | 会话过期 → 「重新扫码」（会换新机器人身份，见第 5 节） |
| 只收到一半消息 | 另一个实例在用同一个 token，见第 6 节 |
| 允许之后附件还是没有 | 补投不含附件，让对方重发一次 |
| 发图片/文件失败，说"发不了附件" | 预期行为：个人机器人没有上传权限，见第 4 节 |
| agent 说打不开收到的文件 | 微信附件目录会自动授权给微信私信会话；换了别的会话就要自己在「访问权限」里加 |
| 语音只剩一个文件、没有文字 | 微信没给转写，补发文字，见第 4 节 |
| 图片/文件下载失败 | 查到 `novac2c.cdn.weixin.qq.com` 的网络访问；超过 50 MB 的也会被拒 |
| 群里 at 没反应 | 见第 7 节，机器人收不到群消息 |

日志位置：

| 系统 | 位置 |
| --- | --- |
| Windows | `%APPDATA%\coworker\logs` |
| macOS / Linux | `~/.config/coworker/logs` |
