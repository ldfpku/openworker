# OpenWorker 使用手册

> 这份是给使用者看的。装好、配好、用起来，加上出问题时先自己试哪几下。
> 全程大约 5 分钟。

---

## 这是什么

OpenWorker 是一个装在你自己电脑上的 AI 助手。它能读写你授权的文件夹、上网查资料、
多步骤地帮你完成一件事，而不只是聊天。

公司模型统一通过 ZY 账号的 Cloudflare AI Gateway（`gateway.smjtools.com`）访问，
包括 OpenAI、Claude 和 Google 模型。第一次使用需要工作邮箱登录。
独立 Gemini 中转和 NVIDIA 卡已停用，其他提供商、Vertex、Ollama 与自定义端点保留。

---

## 开始之前，你需要登记过的工作邮箱

| 需要什么 | 怎么来 |
| --- | --- |
| **公司登记过的邮箱** | 管理员已经把你的邮箱加进名单了。就是发这份手册给你时用的那个。 |
公司网关**不需要个人 Gemini/NVIDIA key**，也不需要你自己的 Cloudflare 账号。
使用其他提供商或自定义端点时，仍按那张卡的提示配置自己的凭据。

---

## 第 1 步：安装

管理员会给你一个安装包（Windows 是 `OpenWorker-windows-setup.exe`）。双击安装。

> **会弹一个安全警告，这是正常的。**
> Windows 会说「Windows 已保护你的电脑」。点 **「更多信息」→「仍要运行」**。
> 因为这个安装包没有买数字签名证书（一年好几千），不是因为它有问题。
> Mac 上如果提示「无法打开，因为无法验证开发者」，把安装包给管理员，他有一条命令能解决。

---

## 第 2 步：登录

1. 打开 OpenWorker。
2. 左下角点你的头像 → **设置** → **模型** → 找到 **Cloudflare AI Gateway**，点进去。
3. 点 **「登录」**。系统浏览器会自动打开 ZY 的 Cloudflare Access 页面。
4. 在页面上填**你的公司邮箱**，点发送。
5. **去邮箱收验证码**，把 6 位数字填回那个页面。
6. 浏览器显示「已登录」的卡片，就可以关掉了。回到 OpenWorker，那一栏会显示
   **「已登录网关」**，随后会自动拉取你有权限使用的模型清单。

> **验证码 10 分钟内有效，只能用一次。**
> 邮件里也有一个可以直接点的链接，但**建议手动输 6 位码**——有些邮箱的安全系统会先替你
> 点一遍链接，把验证码用掉，你再点就会说「已被使用」。

---

## 第 3 步：测试并选模型

点网关卡里的 **「测试」**，成功后从下发的清单勾选模型、设为默认。
拉取失败时点「刷新/重试」；网关卡不能手填模型 id。
从 DF 升级到 ZY 后需要重新登录一次，不会自动迁移旧 Gemini/NVIDIA 会话或任务。

---

## 用起来

配好之后回到主界面就能开始。几个值得知道的：

**第一次打开会有引导。** 一张张小卡片圈着界面，把新建会话、输入框、选模型这些关键位置
带你走一遍，跟着点「下一步」就行。想再看一遍：左下角头像 ▸ **新手引导**。

**选模型**。输入框旁边可以切换模型，默认值由你自己的设置决定。
「**· via Cloudflare**」表示走 ZY 公司网关，Google 模型也在这条线路上。
特别贵的模型可能按角色限制；清单以你的权限和网关当前可用型号为准。
登录后两周授权会话内自动续期；详细说明见
[04-Cloudflare-AI-Gateway](./04-Cloudflare-AI-Gateway.md)。

**它能读文件**。把文件拖进输入框，或者直接让它去看某个文件夹（第一次会问你要不要授权）。

**它会一步步做事**。复杂任务它会自己拆成多步，中间会显示「N 个步骤」，点开能看它做了什么。

**额度与权限**。服务端执行按人配额和模型权限，拒绝时会给出具体提示。
用量与账单由管理员在 ZY 网关和门禁记录中查看。

## 随包带的协作代理：本行的九个岗位

**默认一个都没开。** 新建会话时选择器里只有 OpenWorker——这是故意的：其余的都是
**示例**，摆在那儿让你按需要挑，而不是替你决定该用谁。

去**设置 ▸ 协作代理**，按分组列着，每行一个开关。打开一个，下次新建会话就能选到它。

**生产经营**

| 协作代理 | 干什么 |
| --- | --- |
| 生产计划与排产 | 为交期负责——排产、压瓶颈、盯齐套、复盘延期 |
| 制造工艺与工装 | 工艺路线由它定——工序、切削、热处理、工装 |
| 质量与体系 | 让体系落在证据上——判定、8D、内审、审核整改 |
| 供应链与采购 | 把长周期料和供应商风险按住，别让齐套掉链子 |
| 设备与维护 | 让关键设备按时能干活，停机说得清根因 |

**科研**

| 协作代理 | 干什么 |
| --- | --- |
| 产品研发与结构设计 | 让工具下得去、封得住、捞得回——结构、材料、密封 |
| 试验验证与标准符合 | 定验证等级、编试验大纲、把合格判在证据上 |
| 失效分析 | 从断口到根因，把失效查到能改的那一层 |
| 科研项目与知识产权 | 把技术事实变成能立项、能授权、能验收的材料 |

这九个的职责边界是**咬合**的：验证等级由试验验证定、设计只交井况和失效后果；保养窗口
由设备给区间、计划选日子；供应商现场审核由质量出结论、供应链组织落地；8D 的关闭签字
只有质量能签。所以同时开几个不会互相抢活，你也能放心把一件事从头交到尾。

另外两个是通用的：**OpenWorker**（默认，什么都能干一点）和**专家团队长**（组一支专家团
做一件大事，见下一节）。**代码**默认关着，写脚本、改配置时打开。

## 专家库：现成的专家和技能，即点即用

侧栏左下角**账户菜单 ▸ 专家库**。里面是 120 多位中文专家（写好的专业人设，只收与制造企业
经营、生产、研发相关的）和 230 多个工作技能，**全部内置在应用里，不用联网下载**。

### 找专家

按分类点、或直接搜（名称/描述都能搜到）。搜索框旁边的下拉能切英文库。
每张卡片上：

- **查看提示词 / 复制提示词**——只是看和拷，不安装任何东西。想拿去别的工具用，复制就行。
- **开会话**——让这位专家直接来干活。第一次会弹一张确认卡，告诉你它能做什么
  （读写文件、运行命令等），点「启用并开始」就进入由它主持的会话。
  装过的专家**不会**挤进左下角的协作代理选择器——想再找它，回专家库点开会话即可。

### 挑技能：别全装，按需拿

技能页有三类，排在最前的是**本库自编的制造企业技能**（中文正文，卡片上标着 OpenWorker 中文版：
质量周报、交期风险、设备点检、备件盘点、返厂维修、租赁台账、工艺卡、设计评审、专利交底……
按生产计划与交付、质量管理、设备与备件、售后与工具资产、工艺与工装、研发与知识产权、安全环保
分类）；然后是 **Anthropic 官方的知识工作技能**（标着 Anthropic，按销售、财务、法务、人力资源、
运营管理、数据分析等 14 个插件分类，写周报、评审合同、做月结、写 SOP 这类活）和**按制造业需要
精选的科学/工程技能**（办公文档、数据分析与预测、工程与质量、研究与决策）。
挑的时候记住三件事：

1. **只装你领域用得上的几件**。每个装上的技能，它的名字和简介会常驻模型的
   「工具目录」里——装几十个不会让它更聪明，只会白白占上下文。
2. **看描述再装**。描述写的就是「什么时候该用它」——模型也是靠这段话决定
   要不要调用它的。描述对不上你的工作，就别装。
3. **带脚本的技能**（卡片上标着「N 个脚本」）装完也不会自己运行——模型每次
   想执行脚本都会先征求你的批准，和平时运行命令一样。

装好之后两种用法：在任意会话输入框敲 `/技能名` 点名使用；或者什么都不做——
干相关活的时候模型自己会想起它。技能内容是英文的，属于正常现象，不影响使用。

### 组专家团：几个专家分工干一件大事

适合一个人搞不定的活：一份多角度的报告、一次产品策划、一套完整方案。

1. 专家页点**「组建专家团」**，勾选 2–6 位专家（比如：市场营销 + 财务分析 + 行业研究）。
2. 底部点「组建专家团」，**用一句话写清目标**（要什么交付物、给谁看），点「安装并开始」。
3. 确认能力卡后点「启用并创建团队」——应用会开一个**「专家团队长」**会话，
   选好工作文件夹，发送。
4. 之后队长会先把活拆成几个工作项、再向你提名团队——**都要你批准才开工**。
   开工后在右侧「看板」看进度，成品出来队长会汇报。

### 装过的东西在哪管

专家在**设置 ▸ 协作代理**（可停用、删除），技能在**设置 ▸ 技能**（可开关、删除）。
删掉的随时能回专家库重装，不心疼。

## 遇到问题先自己试这几下

### 收不到验证码

- **看垃圾箱**。QQ 邮箱尤其容易把它归进去。
- 确认填的是**管理员登记的那个邮箱**，一个字母都不能差。
- 还是没有 → 找管理员。你的邮箱可能没在名单里。
  （页面上写「验证码已发送」不代表真的发了——系统故意不告诉外人谁在名单里。）

### 填了验证码，提示「这个邮箱不在允许名单里」

你的邮箱过了验证但还没登记完。找管理员说这一句就行，他知道要做什么。

### 提示「验证码已被使用」

邮箱的安全系统替你点了链接。**手动输入 6 位数字**，别点邮件里的链接。

### 浏览器显示登录成功，但 OpenWorker 里还是「未登录」

浏览器要跳回本机的 OpenWorker，被杀毒软件之类拦住了。
先看浏览器那个标签页停在什么页面，把截图发给管理员。

### 旧版仍提示「还没有填 Gemini API key」

确认已升级至 0.7.1 或之后版本，改用 AI Gateway 登录；不再填公司 Gemini key。

### 提示「Missing bearer or basic authentication」或「不在公司网关的统一计费覆盖内」

不是要你填什么 key。你选的那个型号公司网关代付不了（厂商不接受网关代付，或厂商已下线），
换清单里的另一个型号就行，比如同名不带 Pro 的那一个。0.7.3 起这类型号不会再出现在清单里。

### 提示「客户端版本过旧」

你装的是老版本。找管理员要新安装包，装完**重新登录一次**。

### 提示「今天的额度用满了」

看提示里说的是哪一种：

- **每分钟** —— 等一分钟就好。复杂任务一轮会发十几次请求，偶尔撞上很正常。
- **每天** —— 要等到第二天 0 点，或者找管理员调高。

如果你没做什么特别的事就撞了每分钟的上限，说明可能有个任务在反复循环，
**先停下来看一眼**再继续。

### 用着用着提示要重新登录

网关授权会话约两周；过期后重新点「登录」即可。迁移账号、管理员撤销权限也可能要求重登。
公司的网关不需要个人 API key。

### 换了台电脑

重做第 1、2、3 步。同一个人可以同时在几台设备上登录，互不影响。

## 什么时候该找管理员

- 网关登录、测试或模型清单拉取失败
- 邮箱收不到验证码，或者提示不在名单里
- 需要更高的每日额度
- 安装包装不上
- 登录令牌或其他提供商的 key 可能泄露了——**越早说越好**
- 用了一段时间突然全都用不了了（可能是网关或账号余额出问题）

找管理员时**带上这三样**能快很多：**你看到的错误原话**（截图最好）、
**大概什么时间**、**你当时在做什么**。

## 几件需要你知道的事

**公司网关不等于离线。** 请求经过公司管理的 ZY Worker、Cloudflare AI Gateway 和实际模型
提供商；它们会处理对话内容。身份、用量、错误和审计会按配置记录，网关日志也可能包含
请求/响应内容及相应保留期限。不要假定对话完全不留存，敏感资料先确认公司政策。

**登录令牌不能转发。** 它是你的公司身份凭据；不要贴群里或提交进代码仓库。
其他提供商的个人 key 也要自行保护。发现泄露立即联系管理员。

**额度有上限。** 按服务端当前配置执行；按人配额、共享模型容量和账号余额是不同限制。
不够用时向管理员说明实际报错，不要反复重试跑飞任务。
