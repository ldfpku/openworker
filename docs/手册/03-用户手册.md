# OpenWorker 使用手册

> 这份是给使用者看的。装好、配好、用起来，加上出问题时先自己试哪几下。
> 全程大约 10 分钟，其中申请 API key 占一半。

---

## 这是什么

OpenWorker 是一个装在你自己电脑上的 AI 助手。它能读写你授权的文件夹、上网查资料、
多步骤地帮你完成一件事，而不只是聊天。

它用的是 Google 的 Gemini 模型。因为 Google 的接口在国内连不上，公司搭了一台中转
（`gemini.smjtools.com`），你的请求经它转发。中转还负责确认「是公司的人在用」，
所以第一次要登录一下。

---

## 开始之前，你需要两样东西

| 需要什么 | 怎么来 |
| --- | --- |
| **公司登记过的邮箱** | 管理员已经把你的邮箱加进名单了。就是发这份手册给你时用的那个。 |
| **你自己的 Gemini API key** | 免费申请，下面第 3 步有步骤。 |

**两样都要有才能用。** 只登录不填 key，或者只填 key 不登录，都会报错——这是设计如此：
登录说明「你是谁」，key 决定「谁付钱」。你的用量记在你自己的 Google 账号上，不占别人的。

---

## 第 1 步：安装

管理员会给你一个安装包（Windows 是 `OpenWorker-windows-setup.exe`）。双击安装。

> **会弹一个安全警告，这是正常的。**
> Windows 会说「Windows 已保护你的电脑」。点 **「更多信息」→「仍要运行」**。
> 因为这个安装包没有买数字签名证书（一年好几千），不是因为它有问题。
> Mac 上如果提示「无法打开，因为无法验证开发者」，把安装包给管理员，他有一条命令能解决。

---

## 第 2 步：登录

1. 打开 OpenWorker。
2. 左下角点你的头像 → **设置** → 左边选 **模型** → 找到 **Gemini (Google)** 那一栏，点进去。
3. 点 **「用验证码登录」**。系统浏览器会自动打开一个 Cloudflare 的页面。
4. 在页面上填**你的公司邮箱**，点发送。
5. **去邮箱收验证码**，把 6 位数字填回那个页面。
6. 浏览器显示「已登录」的卡片，就可以关掉了。回到 OpenWorker，那一栏会显示
   **「✓ 已登录」**和你的姓名、部门。

> **验证码 10 分钟内有效，只能用一次。**
> 邮件里也有一个可以直接点的链接，但**建议手动输 6 位码**——有些邮箱的安全系统会先替你
> 点一遍链接，把验证码用掉，你再点就会说「已被使用」。

---

## 第 3 步：申请并填入你自己的 Gemini API key

登录之后，卡片下面会有一行红字提醒你还差这一步。

1. 打开 **https://aistudio.google.com/apikey**
2. 用你的 **个人 Google 账号** 登录（不是公司邮箱，除非你的公司邮箱就是 Gmail）
3. 点 **Create API key**，选一个项目（没有就让它新建一个）
4. 复制生成的那串 `AIza...` 开头的字符
5. 回到 OpenWorker 的同一个页面，粘进 **Gemini API key** 输入框
6. 点旁边的 **「测试」**，显示 **「✓ 已测试并保存」** 就成了

> **免费档够日常用。** Google 对免费额度有自己的限制，正常办公强度不太会碰到。
> 这把 key 只存在你自己的电脑上，公司的中转不保存任何人的 key。

**没有 Google 账号 / 打不开那个网页**：找管理员，这一步可能需要帮忙。

---

## 用起来

配好之后回到主界面就能开始。几个值得知道的：

**选模型**。输入框旁边可以切换模型，默认是 **Gemini 3.7 Flash**，日常够用也够快。
需要更强的推理能力可以换 **Gemini 2.5 Pro**，代价是慢一些、贵一些。

**它能读文件**。把文件拖进输入框，或者直接让它去看某个文件夹（第一次会问你要不要授权）。

**它会一步步做事**。复杂任务它会自己拆成多步，中间会显示「N 个步骤」，点开能看它做了什么。

**看自己的额度**。设置 ▸ 模型 ▸ Gemini 那一栏，登录卡片上有一行
「今日 12/1200 次请求 · 34k/5M tokens」。用到 90% 会变红。

## 遇到问题先自己试这几下

### 收不到验证码

- **看垃圾箱**。QQ 邮箱尤其容易把它归进去。
- 确认填的是**管理员登记的那个邮箱**，一个字母都不能差。
- 还是没有 → 找管理员。你的邮箱可能没在名单里。
  （页面上写「验证码已发送」不代表真的发了——系统故意不告诉外人谁在名单里。）

### 填了验证码，提示「这个邮箱不在允许名单里」

你的邮箱过了验证但还没登记完。找管理员说这一句就行，他知道要做什么。

### 提示「验证码已被使用」

邮箱的安全系统替你点了链接。**手动输入 6 位数字**，别点邮件里的链接。

### 浏览器显示登录成功，但 OpenWorker 里还是「未登录」

浏览器要跳回本机的 OpenWorker，被杀毒软件之类拦住了。
先看浏览器那个标签页停在什么页面，把截图发给管理员。

### 提示「还没有填自己的 Gemini API key」

第 3 步没做完。回设置里填上。

### 提示「客户端版本过旧」

你装的是老版本。找管理员要新安装包，装完**重新登录一次**。

### 提示「今天的额度用满了」

看提示里说的是哪一种：

- **每分钟** —— 等一分钟就好。复杂任务一轮会发十几次请求，偶尔撞上很正常。
- **每天** —— 要等到第二天 0 点，或者找管理员调高。

如果你没做什么特别的事就撞了每分钟的上限，说明可能有个任务在反复循环，
**先停下来看一眼**再继续。

### 用着用着提示要重新登录

登录有效期 30 天。重新点一次「登录」就行。
**你自己的 API key 不用重填**，重新登录不会动它。

### 换了台电脑

重做第 1、2、3 步。同一个人可以同时在几台设备上登录，互不影响。

---

## 什么时候该找管理员

- 邮箱收不到验证码，或者提示不在名单里
- 需要更高的每日额度
- 申请 Google API key 卡住了
- 安装包装不上
- 用了一段时间突然全都用不了了（可能是中转出问题，不是你的问题）

找管理员时**带上这三样**能快很多：**你看到的错误原话**（截图最好）、
**大概什么时间**、**你当时在做什么**。

---

## 几件需要你知道的事

**你的对话内容会经过公司的中转。** 这是反向代理的固有性质——为了能在国内用上 Gemini，
请求必须经过一台中间服务器，它在转发时能看到内容。这台服务器在公司管理员自己的
Cloudflare 账号下，不是第三方。

**会被记录的**：你的邮箱、姓名、部门、用了哪个模型、消耗了多少 token、请求成功还是失败、
登录时间和来源国家。用于按人和按部门统计用量。

**不会被记录的**：你的对话内容、你的 API key、完整的登录令牌。这些都不入库。

**你的 Gemini key 是你自己的。** 只存在你的电脑上，中转不保存。真泄露了你自己去 Google
后台换一把就行，不影响别人，也不用通知谁（但最好还是说一声）。
