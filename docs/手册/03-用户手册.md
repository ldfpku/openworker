# OpenWorker 使用手册

> 这份是给使用者看的。装好、配好、用起来，加上出问题时先自己试哪几下。
> 全程大约 5 分钟。

---

## 这是什么

OpenWorker 是一个装在你自己电脑上的 AI 助手。它能读写你授权的文件夹、上网查资料、
多步骤地帮你完成一件事，而不只是聊天。

它用的是 Google 的 Gemini 模型。因为 Google 的接口在国内连不上，公司搭了一台中转
（`gemini.smjtools.com`），你的请求经它转发。中转还负责确认「是公司的人在用」，
所以第一次要登录一下。

---

## 开始之前，你需要两样东西

| 需要什么 | 怎么来 |
| --- | --- |
| **公司登记过的邮箱** | 管理员已经把你的邮箱加进名单了。就是发这份手册给你时用的那个。 |
| **一把 Gemini API key** | **管理员发给你**，不用自己去申请。每人一把，以你的名字命名。 |

**两样都要有才能用。** 只登录不填 key，或者只填 key 不登录，都会报错——这是设计如此：
登录说明「你是谁」，key 才是真正去调 Google 的凭证。

发给你的那把 key **是公司的**，不是你的私人凭证：请不要转给别人、不要贴进群聊、不要提交进
任何代码仓库。它以你的名字命名，Google 后台能看到每一把 key 各自用了多少——所以真出了事，
对得上号的就是你那一把。管理员也可以只吊销你这一把，不影响别人。

## 第 1 步：安装

管理员会给你一个安装包（Windows 是 `OpenWorker-windows-setup.exe`）。双击安装。

> **会弹一个安全警告，这是正常的。**
> Windows 会说「Windows 已保护你的电脑」。点 **「更多信息」→「仍要运行」**。
> 因为这个安装包没有买数字签名证书（一年好几千），不是因为它有问题。
> Mac 上如果提示「无法打开，因为无法验证开发者」，把安装包给管理员，他有一条命令能解决。

---

## 第 2 步：登录

1. 打开 OpenWorker。
2. 左下角点你的头像 → **设置** → 左边选 **模型** → 找到 **Gemini (Google)** 那一栏，点进去。
3. 点 **「用验证码登录」**。系统浏览器会自动打开一个 Cloudflare 的页面。
4. 在页面上填**你的公司邮箱**，点发送。
5. **去邮箱收验证码**，把 6 位数字填回那个页面。
6. 浏览器显示「已登录」的卡片，就可以关掉了。回到 OpenWorker，那一栏会显示
   **「✓ 已登录」**和你的姓名、部门。

> **验证码 10 分钟内有效，只能用一次。**
> 邮件里也有一个可以直接点的链接，但**建议手动输 6 位码**——有些邮箱的安全系统会先替你
> 点一遍链接，把验证码用掉，你再点就会说「已被使用」。

---

## 第 3 步：填入管理员发给你的 Gemini API key

登录之后，卡片下面会有一行红字提醒你还差这一步。

1. 找管理员要你的那把 key（`AIza...` 开头的一串字符）。**每人一把，以你的名字命名。**
2. 回到 OpenWorker 的 **设置 ▸ 模型 ▸ Gemini**，粘进 **Gemini API key** 输入框
3. 点旁边的 **「测试」**，显示 **「✓ 已测试并保存」** 就成了

> 这把 key 只存在你自己的电脑上，公司的中转**不保存任何人的 key**——它只是转发的时候
> 顺手带过去。所以你换电脑要重新填一次，管理员那边也不能替你查你填的是什么。

**还没拿到 key**：找管理员。不用自己去 Google 申请——那样用量就跟公司的账对不上了。

## 用起来

配好之后回到主界面就能开始。几个值得知道的：

**选模型**。输入框旁边可以切换模型，默认是 **Gemini 3.7 Flash**，日常够用也够快。
需要更强的推理能力可以换 **Gemini 2.5 Pro**，代价是慢一些、贵一些。

列表里还有一批「**· via Cloudflare**」结尾的——GPT、Claude、Grok、DeepSeek、Qwen 那些。
它们走的是另一条线路，和你上面填的 Gemini key 互不相干，而且**什么都不用填**：
网关地址内置在应用里，点一次登录就行，之后两周内自动续期。步骤见
[04-Cloudflare-AI-Gateway 第 2 节](./04-Cloudflare-AI-Gateway.md#2--同事点一次登录)。
没配过的话选了会报错，不影响 Gemini。

**它能读文件**。把文件拖进输入框，或者直接让它去看某个文件夹（第一次会问你要不要授权）。

**它会一步步做事**。复杂任务它会自己拆成多步，中间会显示「N 个步骤」，点开能看它做了什么。

**看自己的额度**。设置 ▸ 模型 ▸ Gemini 那一栏，登录卡片上有一行
「今日 12/1200 次请求 · 34k/5M tokens」。用到 90% 会变红。

## 专家库：现成的专家和技能，即点即用

侧栏左下角**账户菜单 ▸ 专家库**。里面是 270 多位中文专家（写好的专业人设）和
160 多个科研技能，**全部内置在应用里，不用联网下载**。

### 找专家

按分类点、或直接搜（名称/描述都能搜到）。搜索框旁边的下拉能切英文库。
每张卡片上：

- **查看提示词 / 复制提示词**——只是看和拷，不安装任何东西。想拿去别的工具用，复制就行。
- **开会话**——让这位专家直接来干活。第一次会弹一张确认卡，告诉你它能做什么
  （读写文件、运行命令等），点「启用并开始」就进入由它主持的会话。
  装过的专家**不会**挤进左下角的协作代理选择器——想再找它，回专家库点开会话即可。

### 挑技能：别全装，按需拿

技能页是给科研场景准备的工具箱（文献检索、单细胞分析、化学信息、科研写作……）。
挑的时候记住三件事：

1. **只装你领域用得上的几件**。每个装上的技能，它的名字和简介会常驻模型的
   「工具目录」里——装几十个不会让它更聪明，只会白白占上下文。
2. **看描述再装**。描述写的就是「什么时候该用它」——模型也是靠这段话决定
   要不要调用它的。描述对不上你的工作，就别装。
3. **带脚本的技能**（卡片上标着「N 个脚本」）装完也不会自己运行——模型每次
   想执行脚本都会先征求你的批准，和平时运行命令一样。

装好之后两种用法：在任意会话输入框敲 `/技能名` 点名使用；或者什么都不做——
干相关活的时候模型自己会想起它。技能内容是英文的，属于正常现象，不影响使用。

### 组专家团：几个专家分工干一件大事

适合一个人搞不定的活：一份多角度的报告、一次产品策划、一套完整方案。

1. 专家页点**「组建专家团」**，勾选 2–6 位专家（比如：市场营销 + 财务分析 + 行业研究）。
2. 底部点「组建专家团」，**用一句话写清目标**（要什么交付物、给谁看），点「安装并开始」。
3. 确认能力卡后点「启用并创建团队」——应用会开一个**「专家团队长」**会话，
   选好工作文件夹，发送。
4. 之后队长会先把活拆成几个工作项、再向你提名团队——**都要你批准才开工**。
   开工后在右侧「看板」看进度，成品出来队长会汇报。

### 装过的东西在哪管

专家在**设置 ▸ 协作代理**（可停用、删除），技能在**设置 ▸ 技能**（可开关、删除）。
删掉的随时能回专家库重装，不心疼。

## 遇到问题先自己试这几下

### 收不到验证码

- **看垃圾箱**。QQ 邮箱尤其容易把它归进去。
- 确认填的是**管理员登记的那个邮箱**，一个字母都不能差。
- 还是没有 → 找管理员。你的邮箱可能没在名单里。
  （页面上写「验证码已发送」不代表真的发了——系统故意不告诉外人谁在名单里。）

### 填了验证码，提示「这个邮箱不在允许名单里」

你的邮箱过了验证但还没登记完。找管理员说这一句就行，他知道要做什么。

### 提示「验证码已被使用」

邮箱的安全系统替你点了链接。**手动输入 6 位数字**，别点邮件里的链接。

### 浏览器显示登录成功，但 OpenWorker 里还是「未登录」

浏览器要跳回本机的 OpenWorker，被杀毒软件之类拦住了。
先看浏览器那个标签页停在什么页面，把截图发给管理员。

### 提示「还没有填 Gemini API key」

第 3 步没做完。找管理员要你那把 key，回设置里填上。

### 提示「客户端版本过旧」

你装的是老版本。找管理员要新安装包，装完**重新登录一次**。

### 提示「今天的额度用满了」

看提示里说的是哪一种：

- **每分钟** —— 等一分钟就好。复杂任务一轮会发十几次请求，偶尔撞上很正常。
- **每天** —— 要等到第二天 0 点，或者找管理员调高。

如果你没做什么特别的事就撞了每分钟的上限，说明可能有个任务在反复循环，
**先停下来看一眼**再继续。

### 用着用着提示要重新登录

登录有效期 30 天。重新点一次「登录」就行。
**API key 不用重填**，重新登录不会动它。

### 换了台电脑

重做第 1、2、3 步。同一个人可以同时在几台设备上登录，互不影响。

---

## 什么时候该找管理员

- 还没拿到你的 Gemini API key
- 邮箱收不到验证码，或者提示不在名单里
- 需要更高的每日额度
- 安装包装不上
- key 可能泄露了（发错群、贴错地方）——**越早说越好**，换一把是几分钟的事
- 用了一段时间突然全都用不了了（可能是中转出问题，不是你的问题）

找管理员时**带上这三样**能快很多：**你看到的错误原话**（截图最好）、
**大概什么时间**、**你当时在做什么**。

## 几件需要你知道的事

**你的对话内容会经过公司的中转。** 这是反向代理的固有性质——为了能在国内用上 Gemini，
请求必须经过一台中间服务器，它在转发时能看到内容。这台服务器在公司管理员自己的
Cloudflare 账号下，不是第三方。

**会被记录的**：你的邮箱、姓名、部门、用了哪个模型、消耗了多少 token、请求成功还是失败、
登录时间和来源国家。用于按人和按部门统计用量。这些流水**长期保留、没有自动清理**——一次请求
一行、几百字节，量小到不值得清，留着是为了对账。

**不会被记录的**：你的对话内容、你的 API key、完整的登录令牌。这些都不入库。

**发给你的 key 是公司的。** 只存在你的电脑上，中转不保存。但它花的是公司的钱，所以别转发、
别贴群里、别提交进代码仓库。真不小心泄露了，**第一时间告诉管理员**——他吊销你那一把再发新的，
几分钟的事，别人完全不受影响。瞒着不说才会变成大问题。

**额度是有上限的。** 默认每人每天 1200 次请求、500 万 token，每分钟 30 次。前两个是控制账单，
每分钟那个是为了在自动任务跑飞时尽早拦住它。不够用就找管理员调。
