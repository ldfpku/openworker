## 一句话说清这套东西

同事装 OpenWorker 桌面应用 → 所有 Gemini 请求走公司的 Cloudflare Worker 中转
（因为 Google 接口在国内不通）→ 中转用 Cloudflare 一次性验证码确认「是名单里的人」，
再把请求连同**他那把 Gemini API key**（管理员从一个公司 Google 账号签发、以他名字命名）
转给 Google，同时按邮箱记账和限额。

**登录和 key 是两件事**：登录说明你是谁，key 才是去调 Google 的凭证。同事两样都要有，
两样都由管理员给。中转自己一把 key 都不存。
