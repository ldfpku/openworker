## 一句话说清这套东西

同事装 OpenWorker 桌面应用 → 所有 Gemini 请求走公司的 Cloudflare Worker 中转
（因为 Google 接口在国内不通）→ 中转用 Cloudflare 一次性验证码确认「是名单里的人」，
再把请求连同**他自己的** Gemini API key 转给 Google，同时按邮箱记账和限额。

**登录和付费是两件事**：登录说明你是谁，key 决定谁付钱。同事两样都要有。
中转自己一把 key 都不存。
