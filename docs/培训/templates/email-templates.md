# 邮件模板（三个）

## 1. 出题邮件（工作日 08:30）——由 `assemble_quiz.py` 生成，不要手改正文

```text
主题：SMJ AI 培训·每日 5 题｜第 N 周（模块名）｜YYYY-MM-DD
收件人：名单全员｜抄送：讲师

各位同事，早。今天 5 道题，17:00 前回信。格式：题号 答案 一句理由。
满分 100（每题 20 分），简答按要点给分。回信只写自己的，别互相抄。

今天先做这一件事（5 分钟，做完再答题；做不到就在回信里写「卡在第几步」）：
今日 Tip｜T-B01｜提准度、少返工｜OpenWorker 中文版｜第 N 个出题日
  在哪：设置 ▸ 上下文优化 ▸ 开工前核对
  怎么做：保持勾选「开工前先核对任务要素」；核对用的模型保持默认「会话模型的廉价同族」
  为什么：先把「要什么 / 给谁看 / 依据在哪 / 按什么口径」核对一遍，缺什么用一张选择题卡问什么
  怎么算做对了：第一次交代活儿时弹出选择题卡；要素本来就全时不弹卡
  常见误设：嫌烦就把整个功能关掉（要点时该点「跳过」），或把核对模型换成最贵的
  这条会考（M1-13）

1. …（脚本按当天题号渲染）
…
—— 讲评与判分在 17:30 跑，明早随题附上；周五 16:00 有周小结。
```

第 2 天起，正文末尾加一段「昨日答案与讲评」（脚本 `--review` 自动渲染）：

```text
昨日答案与讲评：
1. B｜路径像门牌地址：D 盘是柜子，01-质量周报是抽屉，xlsx 那张纸是文件本身。
2. A｜key 是程序之间门（API）的介绍信，以人命名是为了对账；转发即事故。
```

## 2. 讲评邮件（判分任务产出，随次日题附上或单独发）

```text
主题：昨日 5 题讲评｜第 N 周（模块名）｜YYYY-MM-DD

平均正确率：78%（应交 6 人，实交 6 人）
错得最多：第 4 题（简答「屏幕三段式」），4 人漏了「没看到怎么办」这一步。
一句话记住：交代任务三段式——做什么、应看到什么、没看到怎么办。
个别同事已单独辅导，本周内补交仍计分。
```

规则：每题讲评不超过 3 行；只写「为什么错」，不重复题面；不点名批评个人（点名走私聊）。

## 3. 周小结（周五 16:00）

```text
主题：本周 AI 培训小结｜第 N 周（模块名）

1. 平均正确率 82%，比上周 +6 个百分点。
2. 本周错得最多的 5 道题：M2-05（4 人）、M2-08（4 人）、M1-10（3 人）、M2-03（3 人）、M1-06（3 人）。
3. 缺交：无。补交：李四 1 次。
4. 下周一开始模块 3（技能与自动化）：请带手机，课上要连微信；样例数据仍在 D:\OpenWorker培训\。
```

台账来源：`题库/成绩台账.csv`；模块错题分布按 `mod` 列聚合，不要凭印象写。
