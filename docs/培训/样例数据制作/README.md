# 样例数据制作

[`../OpenWorker培训/`](../OpenWorker培训/) 里的样例数据和 [`../样例数据说明.md`](../样例数据说明.md) 都是这里的脚本做出来的。
这个文件夹只给维护课件的人用，不用拷给学员。

| 文件 | 做什么 |
| --- | --- |
| `生成样例数据.py` | 生成 01–05、07 六个文件夹里的 Excel / Word，并生成《样例数据说明》 |
| `检验记录表.html` | 06 文件夹三张「检验记录照片」的表单和填写内容 |
| `渲染检验记录.cjs` | 把上面的表单渲染成三张 JPEG |

## 重新生成 Excel / Word（上课前对齐日期）

在仓库根目录运行，`--today` 写上课那天：

```
.venv\Scripts\python.exe docs\培训\样例数据制作\生成样例数据.py --today 2026-10-20
```

- 只依赖 `openpyxl` 和 `python-docx`，仓库根目录的 `.venv` 里都有。
- 不写 `--today` 就取运行当天。
- `--out`、`--doc` 可以把数据和说明文档写到别处，试改脚本时用，免得覆盖仓库里这一份。
- 每次运行先清掉六个文件夹里旧的 `.xlsx` / `.docx` 再重写；`06-返厂检验` 不会被碰。

换一个 `--today`，变的只有日期：行数、行的先后、每一行其余的内容、所有参考答案都不变
（`05-返厂维修` 用的是 2026 年的固定日期，连日期也不变）。

脚本写完文件会重新读一遍并逐条核对埋的问题还在不在；有一条对不上就报错退出，不生成说明文档。

## 重新渲染检验记录照片

只有改了表单或填写内容才需要。在仓库根目录运行：

```
node docs/培训/样例数据制作/渲染检验记录.cjs
```

它用的是 `surfaces/gui/node_modules` 里的 Playwright，所以要先在 `surfaces/gui` 下装过依赖。
字体用的是 Windows 自带的宋体、黑体、楷体，换到别的系统上渲染出来的字形会不一样。

改完照片后重新运行一次 `生成样例数据.py`：《样例数据说明》里 06 那一节是从 `检验记录表.html` 读的。

## 改数据时要守的规矩

- 数据里不出现真实的人名、公司名、邮箱、电话。客户一律叫「客户A」到「客户H」，检验员只写工号。
- 不写公式。应用读 Excel 时取的是公式上次算出来的值，脚本写出的公式没有这个值，读出来是空的。
- 日期一律写成相对「今天」的偏移，不写死（`05-返厂维修` 和照片除外）。
- 课件的讲师注里引用了这套数据的编号和数字。改了埋的问题，要同步改三份课件里的讲师注。
