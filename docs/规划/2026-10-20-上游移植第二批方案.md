## 三、需要你定的事

> 2026-10-20 决定：以下五项全部不做；其余按本方案执行，目标版本 1.0.4。

1. **MCP 权限模型（OPE-136）要不要做。** 只有公司实际接了 MCP 服务器才值得花 3,300 行的代价；若目前只用内置工具和微信/网关，建议搁置，等有 MCP 接入需求时整体做。
2. **推理强度 / 思考开关要不要上。** 要做就得为网关模型（claude-sonnet-5-5、haiku-4-5、gpt-6-luna、gemini-3.8-flash 等）维护一张「有没有思考开关、有哪些档位」的表，而且网关对部分模型拒绝 `reasoning_effort` 配合函数工具。建议先不做，等确实有人需要「这题多想想」的场景再说。
3. **Qwen 默认端点是否改为国内站。** 这不是上游改动，是本库自己的事：现在预填国际端点，公司若直接用通义千问密钥会 401。改一行即可；若公司只经网关用模型则无所谓。
4. **无人值守 `openworker run` 和随之而来的登录态锁。** 对 IT 写脚本有用，对一线员工无用；现有定时自动化已覆盖「按时跑」。建议本批不做。
5. **每个协作者独立连接器白名单。** 本公司角色（失效分析、质量体系等）目前都不绑连接器，暂无收益。建议本批不做。
