## 先看懂模型名字后面那个小尾巴

模型选择器里每一行都长这样：

```
Claude Sonnet 5 · Anthropic
GPT-5.6 · via Cloudflare
Kimi K3 · via NVIDIA
qwen3-coder:30b
```

**`·` 后面那截不是装饰，它告诉你这一次调用的钱从谁的口袋里出。**

| 尾巴 | 走哪条路 | 谁付钱 |
| --- | --- | --- |
| `· Anthropic` / `· OpenAI` | 你自己填的那家的 key，直连 | **你自己填的那把 key** |
| `· via Cloudflare` | 公司的 AI 网关（GPT / Claude / Grok / DeepSeek…都在这条线上） | **公司共享账单** |
| （Gemini 那几行） | 公司的 Gemini 中转 | **公司分给你的每日额度** |
| `· via NVIDIA` | 公司的英伟达 NIM 中转 | **不产生公司模型账单** |
| 没有尾巴、名字像 `qwen3-coder:30b` | 你自己电脑上的 Ollama | **不花钱，只费你的电和显卡** |

## 三家大厂各擅长什么

| | 擅长 | 什么时候用它 |
| --- | --- | --- |
| **Claude（Anthropic）** | 长文档、严谨改写、代码 | 读几十页的招标文件、逐条核对条款、把一份材料改到能发出去 |
| **GPT（OpenAI）** | 通用、结构化输出 | 把散乱的记录整成表、大多数"说不清用哪个"的活 |
| **Gemini（Google）** | 快、便宜、上下文大 | 大批量整理、快速问答、一次塞很多资料 |

**说实话**：日常八成的活，这三家的差别小到你感觉不出来，**但账单差别很明显**。
所以规矩很简单——**先用免费的，不够用再往上换**。

## 免费的两条线（学习研究一律先用这两条）

### 一、Kimi K3 · via NVIDIA —— 推荐设成默认

走公司的英伟达 NIM 中转。**能力够强、支持看图、不产生公司模型账单。**
日常整理、起草、改格式、跑重复的活，它完全胜任。

### 二、本机 Ollama —— 完全离线

模型跑在你自己电脑上，**数据一个字都不出机器**。
适合涉及内部资料、又不想经过任何中转的场合。要先在本机装好 Ollama 并 `ollama pull` 一个模型。

> 在模型下拉里，这两条线的型号后面会有一个小小的 **`免费`** 标记，一眼能认出来。

## 怎么把 Kimi K3 设成默认

**只要做一次，之后新建的每个会话都用它。**

1. 左下角**头像 ▸ 设置 ▸ 模型** →〔[直接去这里](app:settings/models)〕
2. 在提供商卡片里找到 **NVIDIA (NIM)**，点进去
3. 把管理员发给你的 **`nvapi-` 开头的 key** 粘进 **NVIDIA API key** 输入框
   - 下面的 **Endpoint（端点）已经预填好了，别改**
   - 没有 key 就找管理员要，**不要自己去英伟达官网申请**——那样用量跟公司的账对不上
4. 点 **测试** → 显示已保存
5. 卡片下方会出现这个提供商的模型清单，找到 **`Kimi K3 · via NVIDIA`** 那一行
6. **鼠标移到那一行上**，右边会冒出 **「设为默认」** 按钮，点它
7. 那一行左边出现黑色的 **`默认`** 小徽章 —— 成了

> **怎么确认生效了**：新建一个会话，看输入框右下角的模型按钮，显示的就是 Kimi K3。

---

## 想临时换个模型

不用回设置。**输入框右下角那个模型按钮**点一下就能换，**会话中途换也可以**。

换了只影响当前这个会话，默认值不变。

---

## 提供商卡片上的状态怎么读

| 显示 | 意思 |
| --- | --- |
| **已连接** | key 填好了，能用 |
| **无需密钥** | 这家不用 key（就是 Ollama），但本机没检测到服务在跑 |
| **未配置** | 还没填 key |

---

## 两件容易踩的事

- **选了没配置的模型会报错**，但不影响其它线路——回来把 key 填上就好。
- **有些模型你会看不到。** 网关上一部分特别贵的旗舰型号按角色限制，不在你的清单里是正常的；
  真选到了会收到一句中文提示，里面写清了找谁申请。
