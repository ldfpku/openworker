## 先看懂模型名字后面那个小尾巴

模型选择器里每一行都长这样：

```
Claude Sonnet 5 · Anthropic
GPT-5.6 Terra · via Cloudflare
Kimi K3 · via NVIDIA
DeepSeek-V4-Flash-0731
qwen3-coder:30b
```

**`·` 后面那截不是装饰，它告诉你这一次调用的钱从谁的口袋里出。**

| 尾巴 | 走哪条路 | 谁付钱 |
| --- | --- | --- |
| `· Anthropic` / `· OpenAI` | 你自己填的那家的 key，直连 | **你自己填的那把 key** |
| `· via Cloudflare` | 公司的 AI 网关（GPT / Claude / Grok / DeepSeek…都在这条线上） | **公司共享账单** |
| （Gemini 那几行） | 公司的 Gemini 中转 | **公司分给你的每日额度** |
| `· via NVIDIA` | 公司的英伟达 NIM 中转 | **不产生公司模型账单** |
| 没有尾巴、名字像 `DeepSeek-V4-Flash-0731` | 你自己在「自定义端点」卡里接的 **AMD 免费线** | **不花钱，AMD 给你每天一份额度** |
| 没有尾巴、名字像 `qwen3-coder:30b` | 你自己电脑上的 Ollama | **不花钱，只费你的电和显卡** |

## 看名字判断模型

型号名不是乱起的。看懂下面几个零件，任何一家的新模型你都能大致估出它是什么档、值不值这个价。

| 名字里的零件 | 意思 | 例子 |
| --- | --- | --- |
| **代次数字** | 越大越新。同一家里，**新代次的中档常常打赢旧代次的顶档** | Gemini 3.7 比 3.5 新；GPT-5.6 比 5.4 新；Claude 5 比 4.x 新 |
| **档位词** | 同一代里的大 / 中 / 小三档，决定能力上限、速度和价格 | Claude：Fable > Opus > Sonnet > Haiku；OpenAI：Sol > Terra > Luna（旧式的 mini / nano 也是"小"）；Gemini：Pro > Flash > Flash-Lite |
| **参数量** | 开源模型直接把大小写在名字里，`B` = 十亿参数。MoE 模型会分"总参 / 激活参"，**激活参才决定快慢** | `Qwen3.8-27B`；DeepSeek-V4-Flash 是 284B 总参 / 13B 激活 |
| **日期或快照号** | `0731`、`20251001` 这种是钉死的版本，不会变；不带日期的同名模型会被厂家悄悄升级 | `DeepSeek-V4-Flash-0731` |
| **状态词** | `preview` / `Exp` / `Next` = 试验版，随时可能改或下线；没有这些词的才是正式版 | `gemini-3.1-pro-preview`、`DeepSeek-V4-Flash-Vision-Exp`、`Qwen3.8-Flash-Next` |
| **能力词** | `Vision` / `VL` 能看图；`Coder` / `Codex` 偏代码；`Cyber` 安全专用；`Realtime` 语音；`Embedding` 不聊天 | `DeepSeek-V4-Flash-Vision-Exp`、`qwen3-coder` |

**一个容易混的词：Flash。** Google 家的 Flash 是"中档"；DeepSeek、Qwen 家的 Flash 是"相对 Pro / Plus 的轻量快速版"。别把不同家的 Flash 当成同一档。

**三步经验**：先看代次，再看档位，最后看有没有 preview / exp。**同样预算里，选最新代次的中档，是最不会错的选择。**

## 三家大厂现在各是什么样

先说一句纠偏的话：**"Claude 擅长长文档、GPT 擅长通用、Gemini 快又便宜"这套说法已经过时了。** 现在三家的前沿模型都是全能选手——都是 1M 上下文、都能看图、都会写代码跑多步任务。真正的差别在**价格梯度怎么切**，和**各家最舍得投入的方向**。

| | 前沿阵容（由高到低） | 特点 | 什么时候选它 |
| --- | --- | --- | --- |
| **Claude（Anthropic）** | **Fable 5.1**：最强，高要求推理与长时段自主任务，思考常开，最慢最贵 → **Opus 5**：复杂的代理式编码与企业工作，官方说"拿不准就用它" → **Sonnet 5**：速度与智能的最佳平衡，主力型号 → **Haiku 4.5**：最快，接近前沿智能，200K 上下文。前三个都是 1M 上下文。另有 **Mythos 5.1**，与 Fable 5.1 同底座，仅邀请制 | 整条线最看重**长时间自主干活的可靠性**和听指令。代理式编码是招牌。Fable 是新出现的、高于 Opus 的顶层 | 让模型自己跑几十步、改一堆文件、逐条核对不出错；对严谨度要求高的正式材料。日常用 Sonnet 5 就够，Fable 留给最难的 |
| **GPT（OpenAI）** | **GPT-5.6 家族**（2026 年 7 月正式），一代三档并行：**Sol**：旗舰，最难的编码和复杂专业工作 → **Terra**：性价比中档，客服、文档分析这类大规模业务 → **Luna**：低价高吞吐，摘要、自动化。都是 1.05M 上下文，用一个"推理力度"滑杆替代了以前的 Instant / Thinking 两套。旧序列 GPT-5.5 / 5.4 / 5.4-mini / 5.4-nano 还在；GPT-5.3-Codex 是代码专用 | **改了命名法**：数字是代次，Sol / Terra / Luna 是固定的档位名，各自独立迭代。生态最广，语音、生图配套最全 | 通用聊天、结构化输出、需要语音或生图配套。说不清用哪家时，Terra 是稳妥的中档 |
| **Gemini（Google）** | **3.7 Flash**（2026 年 8 月）：官方称"最聪明的主力模型"，专攻编码与代理任务，比 3.6 Flash 在真实工程任务上大幅提升，价格还便宜了一半 → **3.1 Pro**（preview）：当前顶档，1M 输入 / 64K 输出，收文字、图、视频、音频、PDF，深度推理最强，但慢、贵、还是试验版 → **3.5 Flash**：上一代中档，稳定，常规任务 → **3.5 Flash-Lite**：3.5 系最快最便宜，约 350 token/秒，高吞吐、抽取、批处理 | **中档 Flash 迭代最快、最便宜**，3.7 Flash 在不少榜上已经超过自家 3.1 Pro；下一代 Pro（3.5 Pro）还在合作方测试。视频、音频输入最全 | 大批量整理、便宜快跑、要塞视频 / 音频 / 整本 PDF 进去；预算敏感的多步任务选 3.7 Flash |

**说实话**：前沿旗舰之间，日常八成的活差别小到你感觉不出来，**但账单差别十倍以上**（Fable 5.1 对 Gemini 3.7 Flash）。
所以规矩很简单——**学习研究先用免费的（AMD / 本机 Ollama）→ 日常用各家的中档（Sonnet 5 / Terra / 3.7 Flash）→ 只有最难的活才上顶档（Fable 5.1 / Sol / 3.1 Pro）。**
别按"某家擅长长文档"去选，三家现在都是 1M 上下文；**按任务难度和预算选档位。**

## 免费的两条线（学习研究一律先用这两条）

### 一、AMD 免费线 —— 推荐练手首选

AMD 的 Radeon Cloud「Token Factory」公开了四个免费模型，**每人自己注册一个 AMD 开发者账号就能用，额度按天重置，不产生公司账单。** 四个都是 2026 年的新模型，拿来练手完全够。

| 模型（手填时照抄） | 出品 | 一句话 | 适合练什么 |
| --- | --- | --- | --- |
| `DeepSeek-V4-Flash-0731` | DeepSeek | V4-Flash 的正式版快照（0731 = 7 月 31 日）。MoE 284B 总参 / 13B 激活，1M 上下文，三档思考力度，多步任务与编码榜上追平 Claude Opus 4.8 一级。**四个里最强的文字模型，推荐设成默认** | 写作、改稿、代码、多步工具任务——日常八成的活 |
| `DeepSeek-V4-Flash-Vision-Exp` | DeepSeek | 2026 年 8 月发布的看图试验版，文字能力同 V4-Flash，加了图片理解。Exp = 实验，**限量免费** | 截图问答、发票 / 表格识图、看图写描述 |
| `Qwen3.8-Flash-Next` | 阿里 Qwen | 2026 年 8 月发布的 Qwen4 架构预览：125B 总参 / 6B 激活，原生 256K 上下文，默认开思考，编码与办公任务强于上一代 Qwen3.7-Plus。Next = 下一代架构试水 | 中文写作、办公整理、代码；速度快 |
| `MiniCPM5-1B` | 面壁 OpenBMB | 2026 年 5 月发布的 1B 端侧小模型，小模型榜第一，CPU 就能跑 | 感受"小模型能到什么程度"；分类、短回复、极快响应 |

> **两个提醒**：它是 AMD 的公共服务，**内部资料别往上传**——这正是它和下面 Ollama 那条的区别。
> 免费额度用完当天就没了，把它当成"别浪费"的训练。

### 二、本机 Ollama —— 完全离线

模型跑在你自己电脑上，**数据一个字都不出机器**。
适合涉及内部资料、又不想经过任何中转的场合。要先在本机装好 Ollama 并 `ollama pull` 一个模型（上面那个 `qwen3.8-flash-next` 也已经上了 Ollama 的模型库，本机也能拉）。

> 在模型下拉里，Ollama 那条线的型号后面会有一个小小的 **`免费`** 标记。
> AMD 那条走的是「自定义端点」卡，**没有这个标记，但同样不产生账单**。

> 已经拿到 `nvapi-` key 的同事：**NVIDIA 线（Kimi K3）照旧能用**，也不产生账单，只是不再作为首选推荐。

## 怎么把 AMD 设成默认

**只要做一次，之后新建的每个会话都用它。**

**先拿 key**：浏览器打开 `developer.amd.com.cn` → 注册 / 登录 AMD 开发者账号 → 进 **Radeon Cloud ▸ Token Factory** → 点开任意一个 Public Free 模型 → 弹窗里 **API Key** 右边的复制按钮。key 以 `rc-` 开头。

1. 左下角**头像 ▸ 设置 ▸ 模型** →〔[直接去这里](app:settings/models)〕
2. 在提供商卡片里找到 **自定义端点**，点进去
3. 三个框这样填：
   - **端点名称**：`AMD`
   - **API key**：粘上刚复制的 `rc-` 开头的 key
   - **Endpoint（端点）**：`https://developer.amd.com.cn/radeon/api/v1`
4. 点 **测试** → 显示已验证并保存
5. 卡片下方的模型清单会自动从 AMD 拉取，勾上想用的那几个（比如 `DeepSeek-V4-Flash-0731`）；一时没看到就点清单上方的 **「刷新」**
6. **鼠标移到那一行上**，右边会冒出 **「设为默认」** 按钮，点它
7. 那一行左边出现黑色的 **`默认`** 小徽章 —— 成了

> **怎么确认生效了**：新建一个会话，看输入框右下角的模型按钮，显示的就是 `DeepSeek-V4-Flash-0731`。

> **三件如实说明的事**：AMD 的模型在下拉里**没有 `免费` 标记**、**没有 `· via` 尾巴**、**没有上下文进度条**（只显示数字）——因为应用的内置清单没有登记这个型号。不是坏了。
> 另外「自定义端点」卡**一次只能接一个**地址，如果你之前用它接了别的服务，填 AMD 会把那个顶掉。

## 想临时换个模型

不用回设置。**输入框右下角那个模型按钮**点一下就能换，**会话中途换也可以**。

换了只影响当前这个会话，默认值不变。

## 提供商卡片上的状态怎么读

| 显示 | 意思 |
| --- | --- |
| **已连接** | key 填好了，能用 |
| **无需密钥** | 这家不用 key（就是 Ollama），但本机没检测到服务在跑 |
| **未配置** | 还没填 key |

## 两件容易踩的事

- **选了没配置的模型会报错**，但不影响其它线路——回来把 key 填上就好。
- **有些模型你会看不到。** 网关上一部分特别贵的旗舰型号按角色限制，不在你的清单里是正常的；
  真选到了会收到一句中文提示，里面写清了找谁申请。
