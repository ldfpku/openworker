## 先弄明白钱是怎么花掉的

模型按 **token** 计费。一个 token 大约是**一个汉字**或者**半个英文单词**。

关键的一点，也是最反直觉的一点：

> **每问一句，整个会话的历史都要重新发一遍给模型。**

模型没有记忆。你们聊到第 20 轮的时候，**前面 19 轮的内容会连同你的新问题一起，再完整地发过去一次**。所以：

- 会话越长，**每一轮都更贵**，而且是越来越贵
- 一个塞了大 PDF 的会话，那个 PDF **每一轮都在重发**
- 装着的技能、开着的连接器，它们的说明**每一轮都在重发**

**这就是为什么"干完一件事就新建会话"能省下最多的钱。**

## 看懂输入框上的那个小胶囊

发出第一条消息后，输入框底部会出现一个安静的小胶囊，写着类似：

> **上下文内 5.3k 个 token · 本会话已计费 14.8k**

两个数字不一样是**正常的**：

- **上下文内** = 这一轮实际发过去多大一坨（你该盯的就是这个数）
- **已计费** = 这个会话从开始到现在累计花掉的总量

点开胶囊能看到更细的账：按模型分组的输入 / 输出 / 缓存读写。

> **为什么有的模型没有进度条？** 有些型号（包括手填进来的 AMD 模型，以及 Kimi K3）没有登记上下文窗口大小，
> 所以显示的是数字而不是进度条。不是坏了。

**这里只显示 token，不显示金额**——因为真实价格取决于折扣、缓存计费方式等等，
在你电脑上算不准。但 token 数就是账单的形状：**它涨你就在花钱**。

## 七条硬规矩

### 1. 默认用免费的那条线

学习、试探、改格式、跑重复的活 → **AMD 免费线上的 DeepSeek-V4-Flash-0731** 或 **本机 Ollama**。
→ [怎么设成默认](app:help/models)

### 2. 贵模型只用在"想不明白"的地方

旗舰型号按 token 算，可能是主力型号的**好几倍**。
用它来改个错别字、调个表格格式，是纯粹的浪费。

**判断标准**：这活是"体力活"还是"需要想明白"？体力活用免费的。

### 3. 干完一件事就新建会话

这是**单条最有效的省钱动作**。

一个会话就该干一件事。上一件事聊完了，**新建一个**，别在同一个会话里换话题——
旧话题的每一个字，之后每一轮都还在为它付钱。

### 4. PDF 别硬塞

附件是随每一轮重发的，**一份大 PDF 能让整个会话的花费翻好几倍**。

两个办法：
- 打开 **设置 ▸ 上下文优化 ▸ Token 节省** →〔[直接去这里](app:settings/context)〕
- 或者先让它把 PDF 摘要成一页，**然后新建会话**，只带着那一页去讨论

### 5. 技能和连接器按需开，别"备着"

每装一个技能，它的名字和一行简介就**常驻每一轮的提示词**。
装三十个技能不会让它更聪明，只会让你每一句话都更贵。

连接器同理。应用已经做了优化——每个连接器的工具是**用到才加载**的，
光这一项就让空会话的开销从 7.2K 降到了 5.3K token，**每轮省下约 2000**。
但这个优化的前提是**你没有把用不上的都打开**。

### 6. 组团前先想清楚值不值

专家团里**每个组员都是一个独立的会话，各花各的**。三个人的团，成本大致就是三倍。

**一个人能干完的活，别组团。** → [什么时候该组团](app:help/experts)

### 7. 自动化设之前先算一笔账

"每天早上跑一次" = **一个月 30 轮起**，而且它会一直跑下去，直到你想起来关掉。

设之前先问自己：这个结果我一周真的会看几次？

## 三个明确的坏习惯

| 坏习惯 | 为什么坏 |
| --- | --- |
| 一个会话从早用到晚，什么都问 | 到下午的时候，你每问一句都在重发一整天的内容 |
| 把整个文件夹拖进去让它"先看看" | 它会真的读，而且读进去的东西每轮都在重发 |
| 让它反复重试同一件做不出来的事 | 每次重试都是全价。试两次不行就换个说法，或者换个模型 |

---

## 一条对免费线也适用的提醒

免费不等于可以浪费。

免费线上，重复塞进去的内容每一轮照样全量处理。在 AMD 那条线上这表现为**慢**，
和**当天的额度提前用完**（它是按天限额的）；但等你哪天把同样的习惯带到付费线上，**它立刻变成账单**。

**好习惯要在免费的时候养成。**
