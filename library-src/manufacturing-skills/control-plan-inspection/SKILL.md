# 控制计划与检验规程

把「哪些特性要盯、用什么测、多久测一次、超了怎么办」写成车间能照着执行、审核员能对着查的两份文件：控制计划和检验规程。

## 适用场景

- 新产品或新规格投产，客户或 API Q1 审核要求提供控制计划。
- PFMEA 做完了，高风险特性要落到具体的检验项目和频次上。
- 车间检验「凭经验」，首件、巡检、终检各管什么说不清，要写成规程。
- 某个尺寸反复超差，要重新定它的检验频次和反应计划。
- 来料或外协件（锻件、热处理、密封件）要定抽样方案。

## 需要的输入

| 输入 | 常见形式 | 常见列名或内容（以用户文件为准） |
| --- | --- | --- |
| 图纸 / 技术要求 | PDF、CAD 导出、技术协议 | 尺寸与公差、形位公差、粗糙度、硬度、材料、螺纹规范、热处理要求、无损检测要求 |
| 工艺卡 / 工艺流程 | Excel 或 Word | 工序号、工序名称、设备、工装、工艺参数（转速、进给、温度、保温时间、扭矩、试压压力） |
| 关键特性清单 | 图纸标注或单独清单 | 特性名称、等级（关键 / 重要 / 一般）、来源（客户 / API / 内部） |
| PFMEA | Excel | 工序、失效模式、S、O、D、RPN / AP、现行控制 |
| 量具清单 | 量具台账 | 量具编号、名称、量程、分辨力、校准日期、校准有效期 |
| 现有检验记录表 / 规程（可选） | Excel、Word | 现有项目、频次、记录格式 |
| 客户或行业特殊要求（可选） | 技术协议、API 规范条款 | 100% 检验项、第三方见证、追溯要求 |

至少要有图纸或工艺卡；没有关键特性清单就按下面的缺省分级，并让用户确认；没有 PFMEA 也能编，但频次只能按经验给，注明「待 PFMEA 核对」。

## 工作步骤

1. **定范围。** 产品 / 规格、覆盖哪些工序（从来料到出厂还是只某几道）、文件要符合谁的格式（贵司模板、客户模板、通用）。
2. **列工序。** 按工艺卡顺序列出工序号、名称、设备、工装；来料和外协也算工序。
3. **列特性。** 每道工序分两类：产品特性（这道工序加工出来的尺寸、硬度、粗糙度）和过程特性（这道工序要控制的参数：转速、炉温、扭矩、试压压力、保压时间）。每条写规格、公差、来源（图纸标注位置、工艺卡行）。
4. **定特性等级。** 用用户的关键特性清单；没有的按缺省：涉及安全和承载（承压件壁厚、螺纹连接、承载截面、硬度）为关键；影响功能和装配（配合尺寸、密封面、释放力）为重要；其余为一般。等级决定频次和反应的严格程度。
5. **对照 PFMEA。** S ≥ 8 或优先级高的失效模式对应的特性，必须出现在控制计划里；PFMEA 里写的探测控制要和这里的检验方法一致，不一致以哪个为准问用户。
6. **定测量方法与量具。** 每条特性配量具：量程覆盖、分辨力不大于公差的 1/10（按贵司规定，缺省建议），有校准有效期。量具台账里没有合适的，列「待配置」。螺纹用螺纹规加量针或三针法；硬度用硬度计并注明标尺；粗糙度用粗糙度仪或样块比对。
7. **定样本量与频次。** 分首件、巡检、终检三段写（口径见下）。关键特性缺省建议全检或每件记录；重要特性按批抽检；一般特性按频次抽检。来料和外协件按 GB/T 2828.1 的思路定 AQL 和检验水平（见下），具体抽样数查标准表。
8. **定控制方法。** 写清是 SPC 控制图、首件 + 巡检记录、防错工装、参数固化、100% 检验还是外协报告审核。
9. **写反应计划。** 每条特性：发现超差时 ①停止加工 / 隔离本批 ②追溯到上次合格检验以来的产品 ③通知谁 ④开不良品处理单 ⑤重新首件。写具体，不写「按程序处理」。
10. **写检验规程。** 从控制计划展开成检验员看的文件：每个检验项目的操作步骤、测量位置（图示或描述）、判定标准、记录表格式、不合格处置。
11. **设计记录表。** 每张记录表列：日期、工序、设备、零件 / 图号、批次、检验项目、规格、实测值（逐件或抽样）、判定、检验员、备注。表头和控制计划的项目一一对应。
12. **给用户核对。** 先发关键 / 重要特性清单和频次，确认后再出全表和规程。

## 行业口径与判断规则

**首件、巡检、终检的区别**

| 类型 | 什么时候 | 检什么 | 谁检 | 目的 |
| --- | --- | --- | --- | --- |
| 首件检验 | 每班开工、换刀、换程序、换批次材料、调机后的第 1 件（按贵司规定，缺省建议如此） | 本工序全部产品特性 | 操作工自检 + 检验员确认 | 防止批量错，没通过不准批量加工 |
| 巡回检验 | 加工过程中按频次（每 N 件或每 N 小时） | 控制计划里本工序的特性，重点关键 / 重要 | 检验员，操作工自检记录 | 发现漂移、及时停 |
| 终检（完工检验） | 本工序或整件完工后 | 产品特性，按抽样或全检 | 检验员 | 放行决定，形成记录 |

首件通过只说明「调对了」，不代表后面不漂；巡检抓漂移；终检是最后一道闸，但不能代替前两道。

**抽样方案的使用方式（GB/T 2828.1 的思路）**

- 适用：按批交付的来料、外协件、成品终检；不适用于连续加工中的巡检（巡检按频次）。
- 三个决定：①检验水平（一般检验水平 Ⅰ / Ⅱ / Ⅲ，缺省用 Ⅱ；要省检验量或破坏性检验用特殊水平）②AQL（按特性等级：关键特性严、一般特性宽；具体数值按贵司或客户规定，缺省建议关键特性的 AQL 比一般特性至少严一档）③严格度（正常 → 连续若干批不合格转加严，连续若干批合格可转放宽，转换规则按标准）。
- 用法：按批量和检验水平在标准的样本量字码表查字码，再按字码和 AQL 在抽样表查样本量 n 和接收数 Ac / 拒收数 Re。**本技能不给具体的 n、Ac、Re 数值，必须查标准表**；用户要具体数值时，提醒查 GB/T 2828.1 并把批量、检验水平、AQL 三个参数写清楚。
- 关键特性（安全、承载、API 要求 100% 的项）不用抽样，全检。
- 抽样接收不等于批里没有不良；让步接收需按处理单流程。

**频次缺省建议**（按贵司规定；缺省如下，供起草）

| 特性等级 | 首件 | 巡检 | 终检 |
| --- | --- | --- | --- |
| 关键 | 必检并记录 | 每件记录，或 SPC 控制图 | 全检 |
| 重要 | 必检并记录 | 每 N 件或每 N 小时抽 1–2 件（N 由用户定） | 抽检，AQL 按贵司规定 |
| 一般 | 必检 | 每班抽检 1 次 | 抽检 |

**量具口径**

- 分辨力：不大于公差带的 1/10（缺省建议）；做不到的注明并考虑换量具。
- 校准：在有效期内；控制计划里写量具类型，检验记录里写量具编号。
- 同一特性在不同工序用不同量具时，终检用的量具精度不低于过程检验。

**反应计划的写法**（缺省建议，按贵司规定调整）

| 情形 | 反应动作 |
| --- | --- |
| 首件不合格 | 不得批量加工；调机后重新首件；记录调整内容 |
| 巡检发现超差 | 停机；隔离自上次合格巡检以来的全部零件并 100% 复检；通知检验员和班组长；开不良品处理单；排查原因后重新首件 |
| 巡检接近控制限或连续同侧 | 通知操作工调整；加密一次巡检；记录 |
| 终检抽检不合格 | 本批全检或退回上工序；开处理单；加严下一批抽检 |
| 过程参数超范围（炉温、扭矩、试压压力） | 停止本炉 / 本件；该炉次或该批产品隔离待评审；设备报修 |
| 量具过期或损坏 | 停用；追溯用该量具检过的产品并复检 |

**来料与外协件的控制计划要点**

- 外协热处理：控制计划要有「外协方参数记录 + 本厂硬度复检」两项，不能只收报告。
- 锻件：材质证明核对（牌号、炉号）、尺寸抽检、必要时硬度 / 探伤复检；炉号写进追溯记录。
- 密封件、轴承等外购件：外观、尺寸抽检，按批次留样；返厂故障追到的批次要回溯。
- 来料检验记录表要有供应商、批次 / 炉号、到货数、抽检数，供 `supplier-quality-audit` 技能汇总。

**常见坑**

- 控制计划只列产品特性不列过程特性：热处理的硬度靠炉温和保温时间保证，炉温就是过程特性，必须有。
- 检验项目和记录表对不上：规程写了检粗糙度，记录表没这一栏，等于没检。
- 反应计划写「按不合格品控制程序处理」：车间看不懂，要写到「停机、隔离、通知检验员、追溯到上次合格件」。
- 频次按方便定而不是按风险定：反复超差的特性要加密，稳定的可以放宽，都要有数据（处理单、Cpk）支撑。
- 外协件只看报告不复检：关键特性来料要有本厂复检或见证。

## 交付前自检

- [ ] 每道工序都有产品特性和过程特性，规格能回指到图纸位置或工艺卡行。
- [ ] 特性等级已经用户确认，关键特性的频次是全检或逐件记录。
- [ ] PFMEA 高优先级特性都出现在控制计划里。
- [ ] 每条特性有量具，分辨力和校准状态已核；没有的列了「待配置」。
- [ ] 抽样方案只写了检验水平、AQL 的选法，没有编具体的 n / Ac / Re。
- [ ] 反应计划写到动作，没有「按程序处理」。
- [ ] 检验规程的项目和记录表的栏目一一对应。
- [ ] 频次、AQL、分辨力这些阈值标了「按贵司规定，缺省建议」。

## 边界

- 不替用户定特性等级和 AQL，只给缺省建议并要求确认。
- 不编造图纸公差、工艺参数和量具；缺的写「待补」。
- 不给 GB/T 2828.1 的抽样表数值，只给查表所需的参数。
- 不修改用户现有的控制计划和规程文件；输出草案由用户审批后替换。
- 文件发布、下发车间、写入文件系统，先问用户。
