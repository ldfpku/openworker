# 设计评审与可制造性检查

把一套井下工具的图纸、设计说明和返厂故障记录按清单过一遍，把该校核的、该改的、该谁在什么时候关闭的写成评审记录，给出能签字的结论。

## 适用场景

- 新产品（液压震击器、机械震击器、减震器、加速器、螺杆钻具）图纸出完，投产前要开评审会。
- 老产品改型，或客户提出新井况（更深、更高温、含硫介质），要确认现有设计能不能用。
- 车间反映某套图「加工不出来」「装不上」「拆不开」，要系统查一遍可制造性和可装配性。
- 同型号产品返厂故障多，要把故障记录对回图纸，看是不是结构问题。
- 评审会开完要出评审记录，每个问题要有等级、责任人和关闭条件。
- 有条件通过的项目要跟踪条件是否关闭，到期要核一遍。

## 需要的输入

| 输入 | 常见形式 | 常见内容 / 列名（以用户文件为准） |
| --- | --- | --- |
| 图纸 / 三维模型信息 | 装配图、零件图（PDF / 图片），或模型导出的零件清单；也可口头描述结构 | 图号、版本、零件名称、材料、热处理、关键尺寸与公差、表面粗糙度、螺纹规格、密封件规格、技术要求 |
| 设计说明 | Word / Markdown，或口头 | 功能与工作原理、外径与通径、工作井深、井底温度、工作压力 / 压差、拉伸 / 压缩 / 扭矩 / 冲击载荷、介质（钻井液类型、是否含 H2S / CO2、固相含量）、连接螺纹、预期寿命或入井次数 |
| 失效后果 | 设计岗给，一句话到一张表 | 失效模式、后果（落井、卡钻、井控风险、停工待修、仅性能下降）、能否在井口发现 |
| 类似产品返厂故障记录 | Excel，每行一次返厂 | 返厂日期、产品型号、序列号、服务基地、井号 / 客户、入井时长（入井次数 / 工作小时）、故障现象（故障描述 / 失效模式）、失效零件、原因分析、处置（修复 / 换件 / 报废） |
| 评审范围 | 用户口头给 | 初评、详评还是投产前评审；参加人；评审日期 |

缺图纸或模型信息就做不了，先要。缺失效后果要问设计岗，不替他定。缺返厂记录可以评，但「故障对照」一节注明「未提供返厂记录」。工况参数缺一项就在清单里标「待补」，不按经验补数。

图纸是图片或扫描件、看不清尺寸的，把看不清的位置列出来问用户，不猜数。

## 工作步骤

1. **定范围和基线。** 确认评审的是哪个图号、哪个版本，是新品还是改型；改型的要上一版图和变更点清单。工况参数逐项记下来（井深、温度、压力、载荷、介质），缺的标「待补」。
2. **读装配图。** 弄清结构和装配关系、拉力和扭矩从哪个零件传到哪个零件、压力作用在哪些面、哪些是动密封哪些是静密封。把零件清单和图上的件号对一遍，对不上的记为问题。
3. **读零件图。** 逐张把材料、热处理、关键尺寸、公差、螺纹、密封件、表面处理列成一张表。图上该标没标的（没写硬度、没写螺纹标准、密封槽没尺寸、没写探伤要求）直接记为问题，不替图纸补。
4. **读返厂记录。** 先看表头在第几行、有没有多张工作表、末尾有无合计行。把故障现象按零件和失效模式归类，写法不同但意思相同的合并（「密封泄漏 / 密封件损坏 / O 形圈挤出」合并为「密封失效」），合并口径列给用户认可。数出每类次数，看集中在哪个零件、哪个部位；入井时间很短就坏的单独标出来，这类多半是设计或装配问题而不是磨损。
5. **逐项过评审清单。** 按「行业口径」里的九类清单逐条核，每条给「通过 / 有问题 / 待补资料」三种状态之一。有问题的写清在哪张图、哪个尺寸或哪个结构，什么问题，依据是什么（工况参数、标准要求、返厂记录第几行、加工或装配经验）。
6. **过 DFM / DFA 要点。** 基准、公差、深孔薄壁、装配顺序、工具可达逐项看。重点找两类：加工得出来但成本高、废品率高的；装得上但拆不开、修不了的。有条件的话请工艺和装配的人一起看这一步。
7. **对照返厂故障。** 返厂记录里次数最多的前三类失效，逐一回到图纸上找对应结构，问三句：这版设计改了没有、改在哪、凭什么认为能解决。没改又没说明的，记为问题。
8. **定等级和责任人。** 每个问题按「行业口径」分 A / B / C 级，写责任人、关闭条件和期限。责任人和期限由用户在评审会上定，不替他定；关闭条件要写成能检查的（「补强度校核报告并经校核人签字」，不是「进一步研究」）。
9. **出结论。** 按三种口径给结论；有条件通过的，把条件逐条列出。把工况参数和失效后果整理成一页，交给试验验证岗，验证等级由他们定，评审记录里不定验证等级。
10. **给用户核对。** 先把问题清单和结论发给用户确认，再出正式评审记录；用户调整等级或口径后重新整理。

## 行业口径与判断规则

**评审清单九类**（列的是要问的问题；答案以图纸、技术条件和贵司规定为准，不替图纸下数）：

1. **功能与强度校核**：工作原理说得清吗；拉伸、压缩、扭矩、冲击、内压、外压各工况下最弱截面在哪（常见在螺纹退刀槽、花键根部、活塞杆台阶、通径最小处）；有没有考虑温度对材料强度的降额；安全系数按贵司设计规范，没有规范的在记录里写明实际取值和依据。
2. **密封设计**：动密封和静密封分开核；密封件材质对井底温度和介质（油基钻井液、H2S、CO2）的适应性有无依据；挤出间隙和挡圈是否匹配压差；压力方向是单向还是双向；密封槽尺寸和表面粗糙度是否按密封件供应商手册；高温高压下有没有试验数据支撑，没有就标「待试验验证」。
3. **螺纹**：API 旋转台肩螺纹要写明规格（NC、REG、IF、FH 等系列），加工和量规检验按 API 对应标准；非标螺纹要有自己的图纸、量规和上扣扭矩；台肩面宽度、应力释放槽、公母扣抗弯强度比有没有核算；上扣扭矩值有没有写进图纸或使用说明。
4. **材料与热处理**：牌号、状态（调质、正火）、硬度范围、冲击功和取样位置是否标全；含硫井况下硬度上限是否按客户要求的抗硫标准；热处理变形和加工余量是否考虑；表面淬火或氮化部位有没有标出；探伤（超声、磁粉）要求是否写明。
5. **公差与可加工性**：公差是否比功能需要更严；长径比大的深孔（芯轴内孔、缸筒）能不能加工、怎么保证直线度；薄壁件热处理和装夹变形；形位公差基准是否统一；粗糙度和加工方法是否匹配；车间现有量具量不量得了。
6. **可装配性与拆卸维修性**：按装配图能不能一次顺序装完，中间要不要反复翻转；要不要专用工装、加热或压装；过盈配合和螺纹胶的使用部位；返厂维修时密封件、活塞、阀件能不能不破坏地取出；易损件能不能单独更换。
7. **标准件与通用化**：O 形圈、挡圈、螺钉、销、轴承等是否用标准规格；能不能与现有产品通用；非标件供应商是否可得、交期多久。
8. **表面处理与防腐**：镀层、喷涂、氮化、磷化等是否与密封面和螺纹兼容；表面处理后尺寸怎么保证；存放和运输的防锈要求。
9. **标识**：序列号、图号版本、材料炉批号的打标位置和方法；打标避开应力集中部位和密封面；内容按贵司规定和客户要求。

**按产品类型多问的几句**：

- 液压震击器：延时机构在井底温度下油的黏度变化有没有考虑；震击力和延时的调节范围与工况是否匹配；油腔压力补偿和泄压结构；活塞与缸筒的配合间隙在温度变化下是否仍可靠。
- 机械震击器：释放力设定机构的可重复性；锁块、卡簧等易磨损件的更换方式；上击和下击的行程是否够。
- 减震器：弹性元件（碟簧、橡胶、液气）的刚度与行程是否与钻压和振动工况匹配；花键传扭部位的磨损和润滑。
- 加速器：储能介质（弹簧、气体、液压）在温度下的性能变化；与震击器的行程和释放时序是否配套。
- 螺杆钻具：定子橡胶与钻井液（油基、高温）的相容性；传动轴万向节和轴承组的寿命依据；弯壳体角度与通径的关系；泄流阀的动作压力。

**DFM / DFA 四条要点**：

- 基准统一：设计基准、工艺基准、测量基准尽量同一个面或同一根轴线；不统一时要有公差换算。
- 避免过严公差：严于某一门槛的公差和粗糙度（门槛按贵司规定，缺省建议 IT7 及以内、Ra 0.8 以下）每一处都要能说出功能理由；说不出的放宽。
- 深孔与薄壁：深孔要有工艺保障（深孔钻、珩磨、分段加工）；薄壁件热处理和精加工顺序要定，必要时留校直工序。
- 装配顺序与工具可达：扳手、吊具、压装工具的空间要够；装配时看不见的配合面要有导向结构；拆卸顺序要能反过来走。

**问题分级**（按贵司规定，缺省建议）：

- A 级：影响安全或基本功能，失效后果为落井、卡钻、井控风险的，或与标准、客户要求冲突的。不关闭不能通过。
- B 级：影响寿命、成本、可制造性或维修性，不影响首批投产安全。可有条件通过，带期限关闭。
- C 级：改进建议、图面规范性问题。记录即可，纳入下一版。

**结论三种口径**：

- 通过：无 A 级，B 级已关闭或有明确期限且不影响投产。
- 有条件通过：无未关闭的 A 级；B 级逐条列条件、责任人、期限，条件未满足前只能做到对应工序（例如可投料，不可装配）。
- 不通过：有未关闭的 A 级，或关键资料缺（强度校核、密封选型依据、工况参数）无法判断。写明补什么、什么时候再评。

**常见坑**：

- 返厂记录里的「原因分析」常写操作或井况原因，同一零件连续几次都这么写的要怀疑是设计问题。
- 「改型」只改了零件图没改装配图和技术要求；图纸改了版本号，BOM 没改。
- 设计说明写的工况是「最大」还是「典型」没说清，评审按最大工况核。
- 评审只看图不看返厂记录，老毛病带进新设计。

## 交付前自检

- [ ] 九类清单每类都有结果，「待补」的写明缺什么资料。
- [ ] 每个问题都能回指到具体图号和位置，或返厂记录的行号。
- [ ] 返厂记录前三类失效在图纸上都有对照，合并口径已列出并经用户认可。
- [ ] A 级问题没有一条未关闭却给了「通过」或「有条件通过」。
- [ ] 关闭条件都是能检查的动作，责任人和期限由用户确认，不是替用户填的。
- [ ] 没有引用标准条款号；安全系数、硬度等数值没有编，缺的标「按贵司规定」或「待补」。
- [ ] 验证等级没有在评审记录里定，工况和失效后果已整理成移交页。
- [ ] 结论口径与问题清单一致：有未关闭 A 级就是不通过。

## 边界

- 只做评审和检查，不替设计岗出计算书、改图纸；强度校核结果以设计岗的计算为准，评审只核有没有、依据对不对。
- 不定验证等级，不定试验项目；这两项由试验验证岗定。
- 不编造标准条款号和数值要求；标准名称可以提，具体要求让用户查原文。
- 不替用户定责任人、期限和等级；给出缺省建议，由评审会确认。
- 评审记录发给参会人、写入 PLM 或 ERP、通知车间停工或改图，都要先问用户。
