# 供应商审核与评价

把一家供应商的资质、来料、交付、投诉记录变成一份有检查表、有不符合项、有整改跟踪、有绩效等级的审核与评价材料，质量出结论，供应链负责落地。

## 适用场景

- 新供应商准入前要做现场或书面审核。
- 锻件、热处理外协、密封件、轴承等某家供应商来料反复不合格，要审核并要求整改。
- 月度或季度供应商绩效评价，要算分、定等级、决定份额或淘汰。
- 客户或 API Q1 审核要求提供供应商控制的证据（审核记录、评价结果、整改跟踪）。
- 返厂故障追溯到外购件（密封件老化、定子橡胶脱胶），要回头查供应商。

## 需要的输入

| 输入 | 常见形式 | 常见列名或内容（以用户文件为准） |
| --- | --- | --- |
| 供应商资料与资质 | 供应商档案、营业执照、体系证书、特种工艺资质 | 供应商名称、供货范围（物料类别）、体系认证（ISO 9001 / API 等）及有效期、关键设备、检测能力、合作年限 |
| 来料检验记录 | Excel，一行一批 | 日期、供应商、物料（名称 / 图号 / 规格）、批次 / 炉号、到货数（数量）、抽检数、不良数（不合格数）、不良类型（不合格描述）、处置（退货 / 让步 / 挑选 / 合格）、检验员 |
| 交付记录 | 采购订单或到货台账 | 订单号、供应商、物料、要求交期（约定交期）、实际到货日期、数量、是否齐套 |
| 投诉 / 退货记录 | 处理单、退货单、索赔记录 | 日期、供应商、物料、问题描述、数量、处理结果、供应商回复、关闭日期 |
| 审核计划 | 年度审核计划 | 供应商、审核类型（准入 / 定期 / 专项）、计划日期、审核员、范围 |
| 上次审核报告（可选） | Word / Excel | 不符合项、整改状态 |
| 评价规则（可选） | 贵司供应商管理程序 | 权重、等级口径、淘汰条件 |

缺来料检验记录就算不了质量得分，先要；缺交付记录可以做审核但绩效表的交付栏写「未提供」；缺评价规则用本技能缺省并注明。

## 工作步骤

1. **定对象和类型。** 哪家供应商、供什么、审核类型（准入 / 定期 / 专项整改）、评价周期（月 / 季）、评价规则用贵司的还是缺省。
2. **读资质。** 核对证书有效期、认证范围是否覆盖所供物料、特种工艺（热处理、无损检测、涂镀）有没有对应资质或能力证明。过期或范围不符列为审核关注点。
3. **读来料记录。** 按供应商筛出评价周期内的批次：到货批数、合格批数、不良批数、不良件数、退货 / 让步 / 挑选各多少；按物料和不良类型做 Pareto；找重复出现的不良（同物料同不良 ≥ 2 批）。每个数字记文件、工作表、行号。
4. **读交付记录。** 算准时交付批数 / 总批数；按天数分「提前 / 准时 / 逾期 1–7 天 / 逾期 > 7 天」；齐套率；找逾期集中的物料。
5. **读投诉与退货。** 列每条投诉的问题、供应商回复、关闭天数；统计未关闭数、超期数、重复投诉。
6. **生成审核检查表。** 三层：体系层（有没有制度、证书、职责）、过程层（关键工序怎么控制：工艺参数、设备、人员、检验、追溯）、产品层（本厂关心的特性怎么保证：材料证明、硬度、尺寸、无损检测报告）。每条写「提问 + 要看的证据」，并把第 3–5 步发现的问题点做成专项提问。
7. **记录审核结果。** 每条检查项：符合 / 不符合 / 观察项 / 不适用，附客观证据（看到的文件编号、记录日期、现场情况）。不符合项分级（见口径）。
8. **开不符合项清单与整改计划。** 每条：要求或条款、客观证据、分级、要求供应商的整改内容、根因分析要求、完成期限、验证方式、跟踪人。
9. **算绩效得分与等级。** 按权重算质量、交付、服务三项得分，合成总分，对照等级口径定 A / B / C / D；一票否决项（重大质量事故、资质过期、拒绝整改）单独判。
10. **写结论和处理建议。** 现场审核结论由质量出；处理建议（份额调整、加严来料检验、二次审核、暂停、淘汰）给供应链决策。
11. **给用户核对。** 先发数据汇总（来料、交付、投诉三张小表）和不符合项清单让用户确认口径，再出全文。

## 行业口径与判断规则

**审核检查表三层**

| 层 | 看什么 | 典型提问 | 要看的证据 |
| --- | --- | --- | --- |
| 体系 | 制度、资质、职责、变更管理、分供方管理 | 体系证书是否有效且覆盖本物料？工艺变更怎么通知客户？分供方（原材料、热处理）怎么管？ | 证书、程序文件、变更通知记录、分供方清单与评价 |
| 过程 | 关键工序的参数、设备、人员、检验、追溯、不合格品 | 锻造 / 热处理参数怎么记录？设备点检和校准？操作工资质？炉号怎么追溯到成品？不合格品怎么隔离？ | 工艺卡、参数记录、设备台账、校准证书、追溯记录、不合格品记录 |
| 产品 | 本厂关心的特性 | 材质证明与实物是否一致？硬度 / 尺寸 / 探伤怎么检、谁检、用什么量具？出厂报告包含哪些项目？ | 材质证明、检验记录、量具校准、出厂报告样本、留样 |

**不符合项分级**（按贵司规定，缺省建议）

- 严重：可能导致批量不合格或安全风险，或体系要求完全缺失（无追溯、关键工序无参数记录、资质过期仍供货）。
- 一般：要求有但执行不到位、记录不全、个别偏离。
- 观察项：有改进空间但未构成不符合。
- 整改期限缺省建议：严重 15 天内提交根因与措施、30 天内验证；一般 30 天；观察项下次审核核查。

**绩效评价缺省口径**（权重和阈值按贵司规定）

| 维度 | 缺省权重 | 计算口径 |
| --- | --- | --- |
| 质量 | 50% | 来料批合格率为主，退货批次和重复不良扣分；让步接收不算合格 |
| 交付 | 30% | 准时交付率（按约定交期），逾期 > 7 天和不齐套加重扣分 |
| 服务 | 20% | 投诉响应与关闭及时性、整改配合、技术支持、文件（材质证明、报告）完整性 |

| 等级 | 缺省总分 | 缺省处理 |
| --- | --- | --- |
| A | ≥ 90 | 优先供应商，可考虑减少来料检验频次 |
| B | 80–89 | 合格，保持 |
| C | 70–79 | 限期整改，加严来料检验，份额受限 |
| D | < 70 或触发一票否决 | 暂停或淘汰，新订单需审批 |

一票否决（缺省建议）：造成客户投诉或返厂故障的外购件质量事故、资质过期或造假、拒绝整改或整改超期两次。

**几条判断规则**

- 来料合格率按批算还是按件算要写明；锻件、密封件这类按批交付的缺省按批。
- 让步接收和挑选使用都不算合格批，但在表里单列，供应链谈判时用得上。
- 同一物料同一不良 ≥ 2 批算重复，重复不良要求供应商出 8D 或等效报告，不接受「已加强检查」。
- 外协热处理、无损检测这类特种过程，只看报告不够，要看参数记录和人员资质；必要时本厂抽检验证。
- 新供应商的首批（或前 N 批，按贵司规定）来料加严检验，稳定后再按正常。
- 资质证书要核范围和有效期，不只看有没有。

**审核前一周的准备**（缺省建议）

- 把评价周期内的来料、交付、投诉三张汇总表做好，带着数据去现场，专项提问从这里出。
- 把上次审核的不符合项和供应商的整改回复整理成一张表，现场逐条核验证据。
- 提前通知供应商审核范围和需要准备的文件：证书、工艺记录、检验记录、量具校准证书、一个炉号的追溯样例。
- 确定审核员分工：质量审体系和过程层，技术 / 工艺审产品层，采购负责日程和商务问题。

**不良类型的合并口径**

同一供应商的来料不良写法常不一致（「硬度偏低 / 硬度不合格」「尺寸超差 / 外径超差」），汇总前把合并口径列出来让用户认可，并写进「数据来源」。

**分工（供应链组织落地）**

- 质量：编检查表、执行现场审核、判定不符合项及分级、出审核结论、验证整改有效性、提供来料和投诉数据。
- 采购 / 供应链：组织审核安排、把不符合项和整改要求发供应商、跟踪期限、根据评价结果决定份额 / 暂停 / 淘汰、合同与商务条款。
- 技术 / 工艺：产品层检查项的技术要求、特种工艺评价、让步的技术评审。
- 来料检验：提供批次记录、执行加严 / 放宽。
- 结论只有质量能出，份额与商务决定只有供应链能做；两边互不替代。

## 交付前自检

- [ ] 来料、交付、投诉三张汇总表的数字能回指到文件、工作表、行号。
- [ ] 合格率、准时率的口径（按批 / 按件、让步算不算）已写明。
- [ ] 检查表三层齐全，每条有「提问 + 证据」，且包含针对本期问题的专项提问。
- [ ] 不符合项每条有客观证据和分级，分级口径标了「缺省建议」或贵司规定。
- [ ] 权重、等级阈值、一票否决标了来源。
- [ ] 结论由质量出、处理建议交供应链，没有混在一起。
- [ ] 重复不良已要求供应商做根因分析，不接受空泛整改。
- [ ] 资质有效期和范围核过。

## 边界

- 不替用户决定淘汰、暂停或份额，只给评价结果和建议。
- 不编造供应商资料、审核现场发现；现场审核没做的，检查表只写「待审核」。
- 不修改用户的来料记录、交付记录、评价规则。
- 发给供应商的不符合项通知、整改要求、评价结果，一律先征得用户确认再发。
- 商务条款、索赔金额不在本技能范围。
