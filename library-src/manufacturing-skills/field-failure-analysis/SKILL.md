# 井下工具失效分析报告

把一支失效工具的现场信息、拆检记录和检测数据整理成一份有流程、有证据、有判断的失效分析报告：失效模式是什么、证据是哪几条、还差什么检测、设计 / 材料 / 工艺 / 使用各能改什么。

## 适用场景

- 工具在井下断了、卡了、不震击了、螺杆钻具不转了，客户要说法，公司要原因。
- 拆检做完了，有照片和测量数据，要整理成正式报告。
- 同一类工具短期内连续失效，要把几支放在一起看共性。
- 技术部门要把失效分析的结论变成设计或工艺的改进项。
- 只有现场描述、还没拆检，先出一份「初步分析 + 需要做哪些检测」。

## 需要的输入

| 输入 | 常见形式 | 内容 / 常见列名（以用户文件为准） |
| --- | --- | --- |
| 失效工具信息 | 用户口头给，或返厂登记里的行 | 工具编号、类型、规格(OD,in)、出厂日期、累计入井时间(h) / 服役时长、历次维修记录、上次检验结果 |
| 井况 | 现场提供或钻井日报 | 井深(m)、井底温度(℃)、压力(MPa)、钻井液类型与密度、是否含 H2S / CO2、钻压(kN)、转速(r/min)、排量(L/s)、泵压(MPa)、井斜 / 狗腿度 |
| 现场描述 | 文字、微信记录 | 失效发生时在干什么（钻进 / 起下钻 / 震击 / 划眼）、失效前的征兆（扭矩波动、泵压变化、悬重变化）、失效时的操作参数、起出后现场看到什么 |
| 拆检记录 | Excel / Word / 照片 | 外观（断口位置、裂纹、变形、磨损、腐蚀产物）、尺寸测量（壁厚、外径、芯轴直径、配合间隙）、硬度(HRC / HBW)、金相（组织、脱碳、夹杂）、断口观察（起裂位置、扩展区、瞬断区）、密封件状态、液压油状态、螺纹状态、定子橡胶状态 |
| 照片描述 | 照片本身或用户描述 | 拍的是哪个部位、看到什么 |
| 历史返厂记录 | 返厂维修登记表 | 这支工具和同类型工具过去的故障部位（失效部位 / 故障位置）、处理措施 |
| 材料与工艺信息 | 图纸、热处理工艺卡、材质证明（用户提供） | 材质牌号、热处理状态、设计硬度范围、镀层 / 涂层 |

缺拆检记录只能出「初步分析」，结论写「待拆检」。缺井况写「井况待补」，不假设井况。缺材料信息，硬度、金相的判断写「待对照图纸 / 工艺卡」。

## 工作步骤

1. **收集并核对信息。** 把上面各项按模板填；每一项注明来源（谁说的、哪个文件、哪张照片）。信息之间矛盾的（现场说「正常钻进时断」，拆检说有震击痕迹）列出来，不选边。
2. **理时间线。** 出厂 → 历次出租 / 维修 → 本次入井 → 失效前征兆 → 失效 → 起出 → 返厂 → 拆检。累计入井时间和设计寿命（用户提供时）对一下。
3. **宏观检查。** 按拆检记录描述：失效位置（哪个零件、哪个截面、距台肩 / 螺纹多远）、失效形态（断裂 / 裂纹 / 变形 / 磨损 / 腐蚀 / 脱胶 / 泄漏）、断口的宏观特征、相邻部位有没有二次损伤。每条对应照片编号。
4. **尺寸 / 硬度 / 金相 / 断口。** 有数据的逐项对图纸或工艺卡：尺寸超不超差、硬度在不在设计范围、组织正不正常、有没有脱碳 / 夹杂 / 淬火裂纹、断口起裂区在哪、扩展区占比多大。没做的项目写「待进一步检测」，并说明这项检测能回答什么问题。
5. **对失效模式。** 把宏观和微观证据对「行业口径」里的特征表，列出符合的模式和不符的模式，每条证据注明来源。两种模式都说得通的并列写，不硬选一个。
6. **机理判断。** 用「证据 → 推断 → 置信度」的格式写：哪些证据支持、哪些证据缺、还需要什么检测才能定。证据不足的写「初步判断……，待进一步检测」。
7. **查历史和同类。** 这支工具过去的返厂记录；同类型、同规格工具在返厂登记里的同部位故障有几次、分布在哪些基地 / 客户，带来源行号。
8. **改进建议。** 分设计 / 材料 / 工艺 / 使用四类，每条对应到证据；写「建议核查 / 建议评估」，不写「应由……负责」。
9. **成稿。** 按模板写；先把「证据清单」和「失效模式判断」发用户核对，再出全文。

## 行业口径与判断规则

**失效模式与典型特征**（通用、可核实的宏观 / 微观特征；最终以实际检测报告为准）：

| 失效模式 | 典型特征 | 常见部位 | 需要的检测 |
| --- | --- | --- | --- |
| 磨损 | 尺寸减小、表面划痕 / 犁沟、镀层剥落；偏磨时周向不均匀 | 外筒、芯轴、花键、卡瓦、扶正块 | 尺寸测量、表面硬度 |
| 疲劳断裂 | 断口有贝纹线（海滩纹），多个起裂源时有棘轮线，扩展区光滑、瞬断区粗糙；起裂多在应力集中处（螺纹根部、台肩圆角、截面突变、加工刀痕） | 接头螺纹、芯轴台肩、万向轴、碟簧 | 断口宏观 + 扫描电镜、硬度、金相、起裂处表面状态 |
| 过载断裂 | 一次性断裂，断口粗糙，有剪切唇或明显塑性变形（颈缩、弯曲）；脆断时断口平齐、有人字纹指向起裂点 | 芯轴、接头、万向轴 | 硬度（是否过硬 / 过软）、冲击韧性、金相、现场载荷记录 |
| 腐蚀 / 硫化氢开裂 | 表面蚀坑、腐蚀产物；含 H2S 井里高硬度材料出现沿晶开裂、裂纹分叉、无明显塑性变形 | 外筒内壁、螺纹、芯轴 | 硬度（酸性环境对硬度上限有通行要求，以 ISO 15156 / NACE MR0175 原文为准）、金相（沿晶 / 穿晶）、腐蚀产物成分 |
| 密封失效 | O 形圈 / 密封件挤出、老化开裂、永久变形、割伤；配合面划伤；液压油乳化 / 发黑 / 进泥浆 | 液压震击器、减震器、加速器的密封段 | 密封件硬度与尺寸、配合面粗糙度与尺寸、油液状态 |
| 螺纹粘扣 | 螺纹面金属撕裂、粘着、扭曲 | 上下接头螺纹 | 螺纹规检、硬度、上扣扭矩记录、螺纹脂使用情况 |
| 定子脱胶 | 橡胶与钢壳脱离、橡胶碎块、局部鼓包 / 掉块；高温或油基钻井液下橡胶变硬开裂 | 螺杆钻具定子 | 橡胶硬度、井温、钻井液类型、粘接面状态 |
| 冲蚀 | 流道表面冲刷沟槽、局部减薄，位置和流向对应 | 过流通道、节流位置、旁通阀 | 壁厚测量、排量 / 含砂记录 |

**判断规则**：

- **先定位置，再定模式**：起裂点在哪比断口长什么样更重要；起裂点在螺纹根部、刀痕、台肩圆角，先看应力集中和加工质量。
- **硬度是关键证据**：高于设计上限 → 怀疑脆性 / 氢致开裂；低于下限 → 怀疑热处理不足或过载；设计范围以图纸和工艺卡为准，不自定。
- **一支工具可能几种模式叠加**（先磨损减薄，再过载断裂）：按时间顺序写「初始失效」和「次生失效」，不只报最后一种。
- **井况和失效要对上**：含 H2S 却没做硬度和金相的，不能排除硫化氢开裂；高温井的密封和定子橡胶失效要先看材料的温度等级。
- **服役时长**：远低于同类工具平均寿命就失效 → 偏向材料 / 工艺 / 异常工况；接近或超过寿命 → 偏向正常磨损或疲劳；都要有证据，不凭时长下结论。
- **历史记录**：同一部位在同类工具上反复失效 → 设计或工艺的共性问题优先；只此一支 → 个案，看材料批次和使用。
- **置信度写法**：「可以判定」只用在证据齐全（宏观 + 尺寸 + 硬度 + 金相或断口）且一致时；否则写「初步判断」或「待进一步检测」。
- **责任**：报告只写失效机理和改进方向，不写「责任在设计 / 车间 / 客户」；给商务用的部分只列证据。
- 标准只引用通用的：钻具连接螺纹按 API Spec 7-1，酸性环境材料按 ISO 15156 / NACE MR0175，硬度试验按 GB/T 230（洛氏）/ GB/T 231（布氏），金相按 GB/T 13298；贵司内部标准由用户提供。

## 交付前自检

- [ ] 每条证据都有来源；现场描述和拆检记录矛盾的已列出、没选边。
- [ ] 没有做的检测都写了「待进一步检测」和目的；没有用「应该是……」去填空。
- [ ] 失效模式的判断列了支持和不符的证据；叠加失效写了先后顺序。
- [ ] 硬度、尺寸的判定引用了图纸 / 工艺卡；没有的写「待对照」。
- [ ] 井况里的 H2S、温度和失效模式对过。
- [ ] 改进建议分了设计 / 材料 / 工艺 / 使用，每条对应证据。
- [ ] 全文没有责任结论；给商务的部分只有证据。
- [ ] 引用的标准只有通用的，没有编贵司内部规定。

## 边界

- 不替实验室出检测数据：硬度、金相、断口、成分分析必须来自实际检测；照片只能做宏观描述。
- 不下责任结论；不写赔偿、索赔建议。
- 不自定材料牌号、硬度范围、设计寿命；以用户提供的图纸和工艺卡为准。
- 报告发客户、发供应商、写入质量系统，先经用户确认。
- 同一类工具的批量趋势分析用返厂维修记录分析另做，本技能针对单支或少数几支。
