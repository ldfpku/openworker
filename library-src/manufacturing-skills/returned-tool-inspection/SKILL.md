# 返厂工具检验报告

把一支或一批返厂租赁工具的检验记录整理成逐件报告：能不能再用、坏在哪、是正常磨损还是异常损伤、要修什么、客户那边怎么交代，每一条都有检验记录做依据。

## 适用场景

- 租出去的震击器、减震器、加速器、螺杆钻具回厂了，质检做完检验，要出一份格式固定的报告。
- 一批工具同时返厂，要逐件判定并汇总：几支可直接再用、几支要修、几支报废。
- 工具有损伤，商务要知道按合同算正常磨损还是异常损伤，需要把证据列清楚。
- 要给客户发检验报告和维修项目清单。
- 纸质检验记录拍了照，要整理成电子报告。

## 需要的输入

| 输入 | 常见形式 | 常见列名 / 栏目（以用户文件为准） |
| --- | --- | --- |
| 返厂登记 | Excel 一行一支，或租赁台账里状态为「已归还」「维修中」的行 | 工具编号（工具号）、工具类型（类型 / 工具类别）、规格（规格(OD,in) / 外径(in)）、客户（甲方）、井号、出租日期（出库日期）、返厂日期（归还日期 / 入库日期）、入井日期、出井日期、累计入井时间(h) |
| 检验记录 | 纸质表单照片、Excel 或 Word；一支工具一份 | 外观检查（外筒、上下接头、芯轴镀层）、尺寸测量（外径、内径、壁厚、芯轴直径、关键配合尺寸）、螺纹检查（粘扣、磨损、规检结果）、密封件与液压油（渗漏、老化、油质）、试压 / 功能试验（震击测试的上击 / 下击释放力 kN 与判定、试压压力与保压时间、螺杆钻具的扭矩 / 转速试验）、结论、处理意见、检验员工号、检验日期 |
| 合同损坏责任条款 | 用户提供原文或摘录 | 正常磨损的定义、异常损伤 / 丢失的处理方式、检验与异议期限、计价依据 |
| 价目表 | 贵司的维修项目单价表（用户提供） | 项目、单价、单位 |
| 磨损限度 | 贵司的检验标准或图纸（用户提供）：壁厚下限、芯轴直径下限、释放力范围、试压参数 | — |
| 出库清单 / 装箱单 | 可选，用来核对缺失件 | 工具编号、随附件（护丝、堵头、配套接头） |

缺检验记录做不了，先要。缺合同条款，「合同口径对照」一节写「未提供合同条款，未做对照」。缺价目表，费用预估只列项目和数量，单价写「待补（按贵司价目表）」。缺磨损限度，尺寸项只记实测值，判定写「待补（需对照贵司标准）」。

## 工作步骤

1. **对清工具清单。** 从返厂登记里列出本次要检的工具：编号、类型、规格、客户、井号；和检验记录逐一对上。登记里有、检验记录里没有的列为「未检」；检验记录里有、登记里没有的问用户。
2. **逐栏抄录检验记录。** 每支工具按栏目抄原文：外观、尺寸、螺纹、密封件与液压油、试验。照片看不清的字写「待补（原件不清）」；空白的栏目写「待补」。不要用「正常」「合格」或任何数字去填空白。
3. **核对身份信息。** 检验记录上的工具编号、规格要和返厂登记一致；不一致的（编号差一位、规格写法不同）列出来问用户，不自行判断哪个对。
4. **尺寸与试验数据对标准。** 有贵司磨损限度的，实测值逐项对比，超限的标出；没有的只记实测值。震击测试的释放力有范围的对范围，没有的只记数值。试压有压力和保压时间的记下，只写「合格」没有数据的注明「无实测值」。
5. **逐件判定。** 按「行业口径」里的规则定：可直接再用 / 维修后可用 / 报废。检验员已有结论的以检验员为准；模型的判定和检验员不一致时并列写出、标「待确认」，不改检验员的结论。
6. **损伤分类。** 每一处损伤归到：正常磨损、异常损伤、缺失件。分类依据写成「检验记录第 X 栏写的是……」；有出库清单的，缺失件对清单核。
7. **合同口径对照。** 把合同里的相关条款原文摘出来，逐条损伤对应：条款怎么定义正常磨损、这处损伤的检验记录原文是什么、实测数据是什么。只列证据，结论一栏写「待商务 / 客户确认」。
8. **列维修项目。** 「维修后可用」的工具：每一处损伤对应一个维修项目（更换密封件套件、修磨螺纹、更换芯轴、补镀、更换液压油……），写数量、单位；对价目表填单价，没有的写「待补」。
9. **汇总。** 一批工具的：各判定数量、各损伤类别处数、维修项目合计、费用合计（有价目表时）；核对各判定数量之和等于工具总数。
10. **起草客户版报告。** 按「输出」里的模板写发给客户的版本：只写检验事实、判定和维修建议，不写内部分析和推测；损伤处理一栏写「按租赁合同第 X 条执行」。
11. **交给用户确认。** 内部报告先发用户核对；客户版本必须用户确认后才发。

## 行业口径与判断规则

**判定口径**（可直接再用 / 维修后可用 / 报废；贵司表单上的「可再租 / 需维修 / 报废」是同义写法）：

- **可直接再用**：所有检验项目在限度内、试验合格、无渗漏、无缺失件；清洗保养后即可入库待租。
- **维修后可用**：有超限或损伤项目，但承载主体（外筒、芯轴、接头本体）尺寸仍在限度内，更换易损件或修磨后可恢复；修完要重新检验。
- **报废**：承载主体超限（外筒壁厚低于下限、芯轴直径低于下限）、主体有裂纹、断裂、严重变形，或修复费用超过贵司规定的比例（按贵司规定，缺省建议为同规格新品价格的 60%）。
- 任何一项关键试验（试压、震击测试、功能试验）**没做或没填**，不能判「可直接再用」；判定写「待补试验后判定」。

**损伤分类**：

| 类别 | 典型表现 | 判断依据 |
| --- | --- | --- |
| 正常磨损 | 外筒均匀磨损、镀层轻微划痕、密封件自然老化、螺纹轻微磨损、液压油到期 | 与累计入井时间相称；磨损均匀，无撞击、过载、违规操作痕迹 |
| 异常损伤 | 外筒偏磨或严重减薄、芯轴弯曲、螺纹粘扣、接头被烧焊或切割、液压油乳化或进泥浆、超期使用 | 与累计入井时间不相称，或有明显外力、违规操作、超范围使用的痕迹 |
| 缺失件 | 出租时有、返厂时没有的部件：护丝、堵头、配套接头、附件 | 对照出库清单 / 装箱单；没有清单的写「待核对出库清单」 |

- 正常和异常的分界**按合同条款**；合同没定义的按贵司检验标准；两者都没有的写「待确认」，不自行判定。
- 累计入井时间和磨损程度要对着看：入井时间短、磨损重，写「磨损程度与服役时长不相称，建议了解井况和使用参数」，不写「客户使用不当」。
- **责任判断**：报告只列三样——合同条款原文、检验记录原文、尺寸 / 试验数据；「责任在谁」由商务和客户按合同协商，报告不替他们下结论。
- 螺纹检查按贵司执行的螺纹标准（API Spec 7-1 或贵司图纸）用螺纹规检；只凭目视的要注明「目视检查」。
- 试压压力、保压时间、释放力范围按贵司检验规程；报告里只引用，不自定数值。
- 一支工具上同时有正常磨损和异常损伤，分开列，不合并成一个结论。
- 检验员工号、检验日期要抄进报告；没有的写「待补」。

## 交付前自检

- [ ] 每支工具的身份信息和返厂登记对上了；对不上的已列出。
- [ ] 检验记录里空白的栏目都写了「待补」，没有用「合格」「正常」或任何数字去填。
- [ ] 每个判定都能指到检验记录的具体栏目；检验员结论和模型判定不一致的已标「待确认」。
- [ ] 关键试验没做的工具没有被判成「可直接再用」。
- [ ] 损伤分类每条都有依据；正常 / 异常的分界引用了合同或贵司标准，没有的写「待确认」。
- [ ] 合同对照只列条款原文和检验事实，结论一栏是「待商务 / 客户确认」。
- [ ] 费用预估的单价全部来自价目表；没有的写「待补」，没有估价。
- [ ] 客户版报告里没有内部分析、推测和责任用语。
- [ ] 批量汇总的各判定数量加起来等于工具总数。

## 边界

- 不替检验员做检验，不根据照片「看起来」判定尺寸是否合格；没有实测值就写待补。
- 不下责任结论，不写「客户使用不当」「现场操作错误」之类的话。
- 不自定磨损限度、试压参数、释放力范围、维修单价。
- 客户版报告、报价单、任何对外发送的东西，必须用户确认后才发。
- 不修改原始检验记录和返厂登记。
