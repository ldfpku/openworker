# 本库自编：制造企业技能（library-src/manufacturing-skills）

这里是 openworker 中文版自己编写的技能，面向**油田井下工具制造企业**（机加、热处理、
装配车间；广汉、天津、新疆等服务基地；租赁与返厂维修业务）的生产、质量、设备、售后、
工艺、研发人员。`packaging/gen_library.py` 把这个目录作为第五个来源打进 `library-pack/`，
分类见脚本里的 `MANUFACTURING_CATEGORIES`，来源标记为 `ldfpku/openworker`。

写新技能照下面的规矩来，写完跑一次 `python packaging/gen_library.py --sources <上游目录>`
即可进库。

## 目录与 frontmatter

每个技能一个目录：`<skill-id>/SKILL.md`（必需），可选 `scripts/`、`reference/`。
`skill-id` 只用小写字母、数字、连字符，和 frontmatter 的 `name` 完全一致。

```
---
name: quality-weekly-report
description: <一段中文，100–200 字：做什么 + 输入什么 + 产出什么 + 当用户说「…」「…」时使用>
---
```

只写这两项，`source:` 由生成脚本自动打标。`description` 是模型决定「要不要用这个技能」
的唯一依据，也是技能卡片上的那段话——触发场景（用户会怎么说）一定要写进去。

## 正文结构（固定顺序）

```
# <中文标题>
一句话说明这个技能帮用户把什么事做完。

## 适用场景        3–5 条触发情形
## 需要的输入      文件/表格/口头信息；每项写清常见列名（含同义写法）；缺哪项就先问
## 工作步骤        编号步骤：读取 → 清洗 → 核对 → 分析 → 成稿；每步写清核对什么、什么算异常
## 行业口径与判断规则  计算口径、分级标准、常见坑；企业自定的阈值写成「按贵司规定，缺省建议 X」
## 输出            交付物模板（Markdown 表格 / 文档结构）；数字要能回指到文件、工作表、行号
## 交付前自检      清单：数字可追溯、口径已声明、无编造、异常已标注、有下一步建议
## 边界            不做什么；对外发送、写入系统、下单、发邮件一律先征得用户确认
```

长度 150–350 行。

## 语言与口吻

- 简体中文，车间和办公室里的话，不堆术语；专有缩写保留英文（Cpk、8D、FMEA、ECN、API Spec 7-1）。
- 用「用户」指代使用者；不写「我是 AI」之类的话。
- 不用 Claude Code / Cowork 的占位符（`$ARGUMENTS`、`~~connector`），不引用不存在的文件。

## 真实性

- 行业规则只写通用、可核实的（ISO 9001、API Q1 / API Spec 7-1、GB/T、IATF 16949 的常识性要求）。
- 不编造企业内部制度；需要企业自定的阈值一律标明「按贵司规定」并给一个缺省建议。
- 不编造数据：缺数据就说缺，让用户补；任何汇总数字都要能回指到来源。

## 数据处理（所有读表的技能都要遵守）

- 不假设列名：写出「这一列可能叫 A / B / C」，以用户文件为准，对不上就问。
- 读 Excel 的坑：表头可能不在第 1 行；末尾可能有合计行；多张工作表里只有一张是数据；
  同一含义有多种写法（「密封失效 / 密封件损坏 / O形圈损坏」）要合并，并把合并口径列给用户认可。
- 日期口径：以用户给的「今天」为准，没给就问；「本周」按周一到周日，除非用户另说。
- 行号一律指 Excel 左侧的行号（表头在第 1 行时，第一条数据是第 2 行）。

## 脚本（可选，每个技能最多一个）

- 只用标准库（`csv`、`json`、`statistics`、`datetime`、`argparse`），输入 CSV，输出 Markdown 或 JSON。
- 顶部 docstring 写清用法；写完要用一组最小样例跑通；不访问网络；不用 pandas / openpyxl。
- 模型运行任何脚本前，OpenWorker 都会先征得用户同意——SKILL.md 里不必再写这句。

## 怎么验证

1. `python packaging/gen_library.py --sources <上游目录>`：新技能应出现在统计里，没有「缺 description_zh」。
2. `pytest tests/test_gen_library.py -q`。
3. 打开专家库 ▸ 技能，按分类找到它，装上，在会话里输入 `/技能名` 试一遍。
