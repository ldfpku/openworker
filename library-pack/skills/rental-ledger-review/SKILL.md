# 租赁台账管理

把租赁台账变成几张能直接用的清单：谁家井上有我们哪些工具、哪些到期哪些逾期、该收多少租金、台账本身有没有记错，每个数字都能指回台账的行号。

## 适用场景

- 商务或租赁业务要知道现在有多少工具在外面、在哪个客户哪口井上。
- 月底要算租金应收、和客户对账。
- 要给基地发「这周哪些工具到期、哪些该催还」。
- 怀疑台账记错了：同一支工具两行都写在外、归还了没登记入库。
- 管理层要利用率，想知道哪类工具不够用、哪类闲置。

## 需要的输入

| 输入 | 常见形式 | 常见列名（以用户文件为准） |
| --- | --- | --- |
| 租赁台账 | 一张 Excel 一行一次出租；或每个基地一个文件 | 工具编号（工具号）、工具类型（类型 / 工具类别）、规格（规格(OD,in) / 外径(in)）、客户（甲方 / 承租方）、井号、出租日期（出库日期 / 出租日）、约定归还日期（合同到期日 / 到期日 / 租期止）、实际归还日期（归还日期 / 入库日期 / 返厂日期）、日租金（租金 / 日租 / 租金标准）、状态（在外 / 已归还 / 维修中 / 待租 / 报废）、基地（服务中心 / 所属基地，不一定有）、备注 |
| 「今天」 | 用户口头给 | — |
| 保养 / 检验记录 | 可选：工具检验台账，或台账里的「上次检验日期」「下次检验日期」列 | 工具编号、上次检验日期、检验周期、下次检验日期 |
| 租金规则 | 可选：合同或贵司规定——出租当天算不算、归还当天算不算、最低租期、逾期加价 | — |
| 可租台数 | 可选：算利用率用，各类型可租工具的台数 | 可从台账的工具编号去重得到，但要剔除报废、维修中 |

缺台账做不了。缺「今天」先问，不自己取系统日期。缺基地列、文件名里也没有基地的，「按基地」一节写「台账无基地信息」。缺保养 / 检验记录，「保养提醒」一节写「未提供检验记录」。

## 工作步骤

1. **定「今天」和范围。** 确认今天是哪天、要看全部还是某个基地 / 客户 / 类型。
2. **摸底台账。** 几张工作表、表头在第几行、有没有合计行、总行数、各状态各多少行。这些数报给用户，后面的清单行数要和它对得上。
3. **统一列名和取值。** 状态写法统一（「在外 / 出租中 / 在租」归一类，「已归还 / 已还 / 入库」归一类），统一表给用户看；日期列里的文字（「待定」「续签中」）、空白、不是日期的值单独列出来，不转成日期也不跳过。工具编号去掉前后空格、统一大小写和连字符。
4. **在外工具清单。** 状态为在外的行；按基地、客户、类型各汇总一次，三张表合计必须相等；每行算在外天数 = 今天 − 出租日期。按工具编号去重，去重前后的数量都报。
5. **到期与逾期。** 约定归还日期和今天比：已过 → 逾期（算逾期天数）；等于今天 → 今天到期；未来 7 天内（按贵司规定）→ 即将到期；空白或非日期 → 「无法判断」单列。今天到期算不算逾期按用户定的规矩，缺省不算、单列。
6. **异常核查。** 逐条找：同一工具编号有 ≥ 2 行在外；状态「已归还」但实际归还日期为空；有归还日期但状态仍「在外」；归还日期早于出租日期；约定归还日期早于出租日期；工具编号、客户、出租日期任一空白；同一工具两段租期重叠。每条带行号，给出「最可能的解释」（例如早的那行是归还后没更新）但由用户确认。
7. **利用率。** 统计期由用户定（缺省上个自然月）。每类工具：在租天数（统计期内所有在外行的天数之和，截到统计期边界）÷ 可用天数（统计期天数 × 可租台数）。可租台数剔除报废、维修中；怎么取的写进报告。
8. **租金应收。** 每行：计费天数 × 日租金。计费天数按用户给的规则，缺省：出租当天算、归还当天不算；未归还的算到今天。日租金空白的行列为「待补」，不估。按客户汇总成对账表，再按工具列明细。
9. **保养 / 检验提醒。** 有检验记录的，列出下次检验日期在 30 天内（按贵司规定）或已过期的工具；在外的标「在外，归还后检验」，在库的标「在库，可安排」。
10. **成稿并核对。** 先把在外清单的行数、逾期规则、异常清单发用户确认，再出全文；用户改规则就重算。

## 行业口径与判断规则

- **在外**的判断以状态列为准；状态列和归还日期矛盾的进异常清单，不算在外也不算已归还，单独报数，不自行改判。
- **逾期**缺省口径：今天晚于约定归还日期；今天等于到期日不算逾期，单列「今天到期」。用户要改就改，改了要写进报告。
- **在外天数**从出租日期算到今天；**计费天数**按合同规则，两者不一定相等，报告里分开写、分开标口径。
- **约定归还日期**空白、「待定」、「续签中」的，不算逾期也不算未到期，单列「无法判断」，并建议补台账或补合同信息。
- **同一工具编号多行在外**：一支工具不可能同时在两口井上，多半是早的那行归还后没更新，也可能是编号写错。报告里列出每行的出租日期、客户、井号，让用户定；统计在外数量时按编号去重，写明去重前后各多少。
- **利用率**口径写清：在租天数 ÷ 可用天数；可用天数 = 统计期天数 × 可租台数；可租台数怎么来的（台账去重、用户给、剔除了哪些状态）写在报告里。没有可租台数就只报在租天数，不算百分比。
- **租金**：日租金按台账；合同有最低租期、逾期加价、停租日（修井等待、井场停工）的，按用户给的规则算，没给就按缺省并标注。租金单位（元 / 天、万元 / 月）统一后再加总。
- **检验周期**：归还后入库前检验是通行做法；按时间或按累计入井时间的定期检验周期按贵司规定，不自定月数或小时数。
- **报废、维修中**的工具不算在外，也不算可租；它们的数量单列。
- 按基地分：有基地列按列；每个基地一个文件按文件名；都没有就不分，注明。
- 日期顺序应为：出租日期 ≤ 约定归还日期，出租日期 ≤ 实际归还日期 ≤ 今天；任一不满足就是日期倒置或未来日期，进异常。

## 交付前自检

- [ ] 在外行数等于台账里状态为在外的行数；去重前后的数量都报了。
- [ ] 按基地 / 客户 / 类型三张汇总表的合计相等。
- [ ] 逾期规则（今天到期算不算、空白怎么处理）写在报告里，和用户定的一致。
- [ ] 日期不是日期的单元格没有被当成日期或被跳过，都列在「无法判断」或「异常」里。
- [ ] 每条异常带行号，给的是「可能的解释」不是结论。
- [ ] 利用率的分子分母口径写明；可租台数的来源写明。
- [ ] 租金计费规则写明；日租金空白的行没有估价；单位统一。
- [ ] 所有数字能指回台账行号；「今天」是用户给的。

## 边界

- 不修改台账；发现异常只列出来，改不改由用户。
- 不替用户决定逾期怎么处理（催还、加价、停租），只给清单和数据。
- 对账表发客户、催还通知发基地、写入系统，先问用户。
- 「今天」由用户给，没给就问，不取系统日期。
- 不自定租金规则、检验周期；没给的按缺省并标明。
