# 专利交底书与先行技术检索

把工程师手里的结构、原理、参数和试验数据整理成专利代理人能直接起草申请文件的交底书，并把检索该怎么查、和代理人该谈什么列清楚。

## 适用场景

- 新结构（震击器延时机构、减震器弹性组件、加速器储能方式、螺杆钻具传动或密封结构）做出来了，要申请专利，先写交底书。
- 科研项目里程碑要求提交专利申请，手头只有图纸和试验报告。
- 想知道自己的方案和别人的有什么不一样，要先做一轮先行技术检索再决定报不报。
- 专利代理人要交底书，工程师不知道该写什么、写到多细。
- 代理人返回了问题清单，要补实施例、补参数范围、补对比效果。
- 立项书的知识产权安排里写了要申请专利，到了时点要兑现。

## 需要的输入

| 输入 | 常见形式 | 常见内容（以用户材料为准） |
| --- | --- | --- |
| 技术方案 | 装配图、零件图、三维截图、原理草图、设计说明 | 结构组成（零件名称、连接关系、运动关系）、工作原理（力或压力怎么传、什么触发什么）、关键参数（尺寸、角度、压力、刚度、材料、温度范围） |
| 要解决的问题 | 口头、返厂故障记录、客户反馈 | 现有产品在什么工况下出什么问题、后果是什么 |
| 与现有技术的区别 | 现有产品说明、已知专利或文献、竞品拆解记录 | 现有技术怎么做的、来源（专利号 / 文献题名 / 产品型号）、本方案改在哪 |
| 取得的效果 | 试验报告、对比数据、现场应用记录 | 指标前后对比、试验报告编号、应用井号与日期 |
| 附图说明 | 图纸或示意图清单 | 图号、图名、各附图标记对应的零件名称 |
| 发明人与公开情况 | 口头 | 发明人名单与贡献、是否已展出 / 发表 / 销售 / 送客户试用、有没有保密协议、合作方 |

技术方案说不清楚结构和原理的，先让用户画草图或口述，逐个零件问连接关系，不替他想结构。与现有技术的区别没有来源的，标「待检索确认」。效果没有数据的，写定性描述并标「待补试验数据」。已对外公开过的，第一步就提醒用户尽快告知代理人公开时间和方式。

## 工作步骤

1. **弄清方案。** 按「零件 → 连接关系 → 运动 / 受力关系 → 触发条件 → 结果」把结构和原理复述一遍给用户确认；每个零件给一个附图标记。说不通的地方（力从哪来、油往哪走）追问，不补脑。
2. **锁定要解决的问题。** 问题要具体到工况和现象：「在 XX ℃ 井温下，现有液压震击器延时漂移，震击时机不可控」，不写「性能不好」。一个交底书缺省围绕一个主要问题，多个问题的建议拆成多份，由代理人定。
3. **列现有技术及其缺点。** 用户提供的每项现有技术写「它是怎么做的 → 在本问题上为什么不行」，附来源；没有来源的写「据工程师了解」并标待检索。
4. **提炼必要技术特征。** 问「去掉这个特征，问题还能不能解决」，不能解决的是必要特征；把必要特征用「部件 + 连接关系 + 作用」写成一段话，这就是技术方案的骨架。
5. **分层从属特征。** 骨架之外的特征按「结构细化 → 参数范围 → 材料与表面处理 → 适用场景与配套」分层，每层写清与上一层的关系；每个参数写区间、优选值和依据（试验报告编号或设计计算）。
6. **写实施例。** 至少一个完整实施例：具体结构、具体数值、工作过程逐步描述、达到的效果；有多种实现方式的各写一个。实施例里的数值要能回指到图纸尺寸或试验数据。
7. **写有益效果。** 每条效果对应一个问题或一个特征，有数据给数据（对比前后、试验报告编号），没有数据写机理并标「待补」。
8. **写可替代方案。** 每个必要特征问「换成什么也能起同样作用」（弹簧换碟簧或液压、螺纹连接换销连接、某材料换同类材料），列出来供代理人扩展保护范围；明显不可行的不列。
9. **整理附图说明。** 图号、图名、每个附图标记对应的零件，和正文一致；附图不要带尺寸公差和公司标题栏。
10. **做先行技术检索思路。** 按「行业口径」列关键词与同义词（中英文）、分类号查法、检索库和检索式草稿；有检索结果的，把最接近的 3–5 篇按「它做了什么 / 和本方案的区别」列成对比表。
11. **列与代理人沟通清单。** 按「输出」里的清单逐项准备答案；拿不准的标「请代理人建议」。
12. **给用户核对。** 交底书先给发明人核结构和数据，再核保密边界（哪些细节不想公开，由用户定），然后交代理人。

## 行业口径与判断规则

- **必要技术特征**：缺了它方案就不成立或问题解决不了的特征；写得越少保护越宽，但每个都要能说出作用。把具体尺寸、材料牌号写进必要特征会把保护范围缩得很窄，这些放到从属层。
- **从属特征分层**（缺省建议）：第一层结构细化（某部件由哪几件组成、怎么连接）；第二层参数范围（角度、间隙、压力、刚度、行程，写区间和优选值）；第三层材料与表面处理；第四层适用场景与配套（与加速器配合、用于某类井况）。每层独立成句，方便代理人逐条转成权利要求。
- **参数范围的写法**：「X 为 A–B，优选 C」，并写依据：低于 A 会怎样、高于 B 会怎样（来自试验或计算）。只有一个点值而没有范围的，提醒用户补试验或给出合理范围的理由。
- **实施例**：至少一个，具体到能照着做出来；数值是实测或设计值，不是估的。多个实施例要体现不同的替代方式，而不是同一结构换几个数。
- **有益效果**：与问题一一对应；对比对象是背景技术里写的现有技术；数据要能回指到试验报告编号，没有就标「待补」。
- **背景技术**：只写用户提供或检索到的、有来源的现有技术；不贬低具体厂家，用「现有的 XX 结构」指代。
- **保密与公开**：申请提交前不对外公开技术细节（展会、论文、无保密协议的客户试用、公开销售都算）；已公开的，把时间、方式、证据交给代理人判断。哪些内容作为技术秘密不写进交底书，由用户定，并在沟通清单里告诉代理人。
- **发明人**：对技术方案做出实质贡献的人；只负责组织、提供条件的不列。有争议的让用户内部定。
- **写到多细**：结构和原理写到本领域工程师能照着做出来；具体牌号、工艺参数、供应商等不影响方案成立的细节不必写，想保密的更不写。拿不准的列在「技术秘密边界」里让用户和代理人定。
- **一份交底书一个核心方案**：同时改了延时机构和密封结构、两者彼此独立的，缺省建议拆成两份，由代理人决定是否合案。
- **不判断能否授权**：新颖性、创造性、申请类型（发明还是实用新型）、是否分案、是否国外申请，都是代理人和审查的事；交底书只提供事实和检索到的对比文件。

**先行技术检索思路**：

- 关键词：产品名、结构名、功能词、问题词各列一组，每组列中文同义词和英文对应词。井下工具常见对应：震击器（钻井震击器 / 液压震击器 / 机械震击器；jar / drilling jar / hydraulic jar / mechanical jar）、减震器（减振器 / 缓冲器；shock sub / shock absorber / vibration damper）、加速器（增力器 / 储能器；accelerator / intensifier）、螺杆钻具（容积式马达 / 井下马达；PDM / positive displacement motor / mud motor / downhole motor）。结构词和功能词由用户按方案补（延时、计量阀、花键、碟簧、密封、定子、传动轴等）。
- 分类号查法：不凭记忆填分类号。到 IPC 分类表（WIPO 官方分类表或国家知识产权局提供的分类查询）按关键词逐级查到小组；再用关键词先检几篇最接近的专利，看它们的分类号，反过来确认或补充；同时查 CPC 对应号。最终用哪个分类号让代理人确认。
- 检索库：国家知识产权局专利检索系统、Espacenet、Google Patents 等公开库各查一遍；检索式先用「关键词组 1 AND 关键词组 2」，再加分类号缩小，再用最接近专利的申请人和发明人扩展。
- 检索结果整理：最接近的 3–5 篇，每篇写公开号、申请人、它的方案一句话、与本方案的区别一句话；有「几乎一样」的，如实写，让代理人判断。
- 检索记录：检索日期、库、检索式、结果数都记下来，交代理人。

**常见坑**：

- 交底书写成产品说明书，只讲优点不讲结构和原理。
- 必要特征里塞满尺寸和材料牌号，保护范围被自己缩窄。
- 效果没有对比对象，或对比的不是背景技术里写的那个现有技术。
- 附图标记正文和图对不上；附图带着公司标题栏和公差。
- 只有一个点值没有范围，代理人无法写参数型从属权利要求。
- 已经在展会上展过、给客户试用过了才想起来写交底书。
- 检索只用了一个中文词，英文同义词和分类号都没查。

**与专利代理人沟通清单**（逐项准备答案，拿不准的标「请代理人建议」）：

- 发明人和申请人信息，发明人贡献说明。
- 公开情况与时间、方式、证据（展会、论文、客户试用、销售）。
- 最希望保护的核心点是什么，哪些是可以让步的细节。
- 哪些内容作为技术秘密不写进申请。
- 检索到的最接近文件和自己认为的区别。
- 申请类型（发明 / 实用新型 / 同时申请）请代理人建议。
- 是否考虑国外申请及目标国家，时间窗口请代理人说明。
- 合作方和权属约定，提供合同原文。
- 附图原件格式和数量。
- 加急需求（招标、展会、论文时间）。
- 费用与进度安排。
- 代理人返回问题的答复人和时限。

## 交付前自检

- [ ] 技术方案按零件、连接关系、工作过程写清，发明人已核对。
- [ ] 必要技术特征每个都能说出作用，去掉就解决不了问题；尺寸和材料放在从属层。
- [ ] 至少一个实施例，有具体数值且能回指到图纸或试验报告。
- [ ] 参数有区间和优选值，依据写明；没有依据的标「待补」。
- [ ] 效果与问题一一对应，数据有报告编号；无数据的标「待补」。
- [ ] 附图标记正文与附图一致，附图不带公司标题栏和公差。
- [ ] 检索思路有关键词表和分类号查找记录，没有凭记忆写具体分类号；检索结果有公开号和区别。
- [ ] 公开情况已问过并写明；技术秘密边界由用户确认。
- [ ] 全文没有「能授权」「新颖性没问题」之类的判断。
- [ ] 沟通清单每项有答案或标了「请代理人建议」。

## 边界

- 不替代专利代理人，不出法律意见，不判断新颖性、创造性和能否授权；申请类型、权利要求撰写、答复审查意见由代理人负责。
- 不编造现有技术、专利号、分类号和检索结果；没查到就写没查到。
- 不替用户决定哪些内容作为技术秘密保留，不替用户定发明人名单。
- 不对外发送交底书、不提交申请、不联系代理机构；这些都要先问用户。
- 交底书内容在申请提交前按保密资料处理，不在公开渠道粘贴。
