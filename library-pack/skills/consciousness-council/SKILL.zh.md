# Consciousness Council(意识委员会)

一套结构化的多视角审议系统，能针对任何问题产生真正的认知多样性。它不是由
单一的声音给出单一的答案，而是召集多个截然不同的思维原型(archetype)——
每一个都有自己的推理风格、盲点和优先事项——然后把它们的观点综合成可付诸
行动的洞见。

## 为什么会有这个技能

单一视角的思考存在天花板。当你只问一个头脑要答案时，得到的只是一种框架。
Consciousness Council 打破了这个天花板，它同时模拟了董事会会议室、哲学
研讨会和作战室在认知层面的等价物。这不是角色扮演，而是结构化的认识论
多样性。

本委员会的灵感来自集体智慧(collective intelligence)方面的研究、群体
智慧现象(wisdom-of-crowds),以及一个观察结论:当真正不同的推理风格
相互碰撞时，往往会产生最好的决策。

## 工作原理

委员会分为三个阶段:

### 第一阶段——召集委员会

根据用户的问题，从下面的原型中选出 4-6 名委员会成员。要挑选那些视角会
真正产生**碰撞**的成员——意见一致是廉价的，富有成效的张力才是有价值的。

**12 种原型**:

| # | 原型 | 思维风格 | 会问 | 盲点 |
| --- | ------------------ | ------- | ------ | ------ |
| 1 | **建筑师(The Architect)** | 系统思维，结构优先 | "底层结构是什么?" | 可能对简单问题过度设计 |
| 2 | **反对者(The Contrarian)** | 逆向思考，唱反调 | "如果情况正好相反呢?" | 可能纯粹为了反对而反对 |
| 3 | **实证主义者(The Empiricist)** | 数据驱动，证据优先 | "证据实际上表明了什么?" | 可能忽略无法被测量的东西 |
| 4 | **伦理学家(The Ethicist)** | 价值驱动，关注后果 | "谁受益，谁受损?" | 可能因道德复杂性而使行动陷入瘫痪 |
| 5 | **未来学家(The Futurist)** | 长期视角，二阶效应 | "十年后这会是什么样子?" | 可能低估当下的现实 |
| 6 | **实用主义者(The Pragmatist)** | 行动导向，关注资源 | "到周五我们实际能做什么?" | 可能为了短期利益牺牲长期利益 |
| 7 | **历史学家(The Historian)** | 模式识别，先例参照 | "这种做法以前什么时候尝试过?" | 可能在打上一场战争 |
| 8 | **共情者(The Empath)** | 以人为本，情商 | "人们实际上会对此作何感受?" | 可能为了舒适而牺牲进步 |
| 9 | **局外人(The Outsider)** | 跨领域，提出天真的问题 | "为什么大家都想当然地这么认为?" | 可能缺乏领域深度 |
| 10 | **战略家(The Strategist)** | 博弈论，竞争动态 | "第二步、第三步棋是什么?" | 可能把简单情况过度复杂化 |
| 11 | **极简主义者(The Minimalist)** | 简化，寻求约束 | "我们能去掉什么?" | 可能把复杂问题过度简化 |
| 12 | **创造者(The Creator)** | 发散思维，新颖综合 | "还有什么没被尝试过?" | 可能为了追求新奇而牺牲可靠性 |

**选择启发法**: 把问题类型匹配到最能产生成效的张力组合:

- **商业决策** → 战略家 + 实用主义者 + 伦理学家 + 未来学家 + 反对者
- **技术架构** → 建筑师 + 极简主义者 + 实证主义者 + 局外人
- **个人困境** → 共情者 + 反对者 + 未来学家 + 实用主义者
- **创意挑战** → 创造者 + 局外人 + 历史学家 + 极简主义者
- **伦理问题** → 伦理学家 + 反对者 + 实证主义者 + 共情者 + 历史学家
- **战略/竞争** → 战略家 + 历史学家 + 未来学家 + 反对者 + 实用主义者

这些只是起点——要根据具体问题灵活调整。目标是产生有成效的分歧，而不是
达成共识。

### 第二阶段——审议

每一位委员会成员按以下格式给出自己的观点:

```
🎭 [ARCHETYPE NAME]

Position: [One-sentence stance]

Reasoning: [2-4 sentences explaining their logic from their specific lens]

Key Risk They See: [The danger others might miss]

Surprising Insight: [Something non-obvious that emerges from their frame]
```

**审议阶段的关键规则**:

- 每位成员必须在某个实质性问题上，与至少一位其他成员产生分歧。如果大家
  意见都一致，那么这场委员会就失败了——要回头去把张力磨得更锋利。
- 各方观点应当是真正不同的，而不是"表面上换了个说法，实际上还是同意"。
- 反对者(The Contrarian)应当挑战最受欢迎的立场，而不是泛泛地表示怀疑。
- 保持每位成员的发言聚焦而犀利。深度优先于广度。

### 第三阶段——综合

在所有成员发言完毕后，给出以下内容:

```
⚖️ COUNCIL SYNTHESIS

Points of Convergence: [Where 3+ members agreed — these are high-confidence signals]

Core Tension: [The central disagreement that won't resolve easily — this IS the insight]

The Blind Spot: [What NO member addressed — the question behind the question]

Recommended Path: [Actionable recommendation that respects the tension rather than ignoring it]

Confidence Level: [High / Medium / Low — based on how much convergence vs. divergence emerged]

One Question to Sit With: [The question the user should keep thinking about after this session]
```

## 委员会配置

用户可以自定义委员会:

- **"快速委员会(Quick council)"** 或 **"快速审议(fast deliberation)"** → 使用 3 名成员，给出更简短的回应
- **"深度委员会(Deep council)"** 或 **"完整审议(full deliberation)"** → 使用 6 名成员，给出更充分的推理
- **"加入 [某原型](Add [archetype])"** → 纳入某个特定原型
- **"不要 [某原型](Without [archetype])"** → 排除某个特定原型
- **"自定义委员会:[名单](Custom council: [list])"** → 用户自行挑选具体成员
- **"匿名委员会(Anonymous council)"** → 在综合阶段之前不透露发言者是哪个原型(以降低锚定偏差)
- **"魔鬼代言人模式(Devil's advocate mode)"** → 每位成员都必须反驳看起来最直觉的观点
- **"多轮模式(Rounds mode)"** → 在初始立场之后，各成员再进行第二轮相互回应

## 什么样的问题适合委员会

在以下情况下，委员会的效果最好:

- 存在真实的不确定性或权衡取舍
- 存在多个都站得住脚的视角
- 用户陷入了困境，或在原地打转
- 问题的重要程度足以支撑多角度思考
- 用户自身的偏见可能限制了他们的视野

在以下情况下，委员会带来的价值较小:

- 有明确答案的纯事实性问题
- 用户已经做出决定、只是想寻求验证的问题
- 重要程度较低的琐碎选择

如果问题看起来太简单，不值得召开完整的委员会，应当直接说明——并转而
提供一个简短的双视角对比。

## 语气与质量

- 让每个原型的"声音"具有足够的辨识度，使用户即便不看标签也能分辨出是
  谁在说话。
- "综合"部分应当让人感觉是真正的整合，而不只是把每位成员说过的话罗列
  一遍。
- "核心张力"是综合意见中最重要的部分——它应当准确点明用户所面对的真实
  权衡取舍。
- "一个值得持续思考的问题"应当真正发人深省，而不是泛泛而谈。
- 绝不能让委员会沦为大家客客气气地一致同意。有成效的摩擦才是重点。

## 示例

**用户**:"我应该辞去稳定的公司工作去创业吗?"

**委员会人选**: 实用主义者、未来学家、共情者、反对者、战略家(5 名
成员——这是一个涉及财务、情感和战略多重维度的高风险人生决策)

然后运行完整的三阶段审议流程。
