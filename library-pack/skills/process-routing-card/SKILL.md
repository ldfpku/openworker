# 工艺路线与工艺卡

把一张零件图变成车间能照着干的工艺路线和工艺卡：工序顺序讲得通、设备装得下、基准统一、检验点落在关键特性上，参数给范围、依据写清楚。

## 适用场景

- 新图号要排工艺，没有现成路线，工艺员要一个起点。
- 老零件改了材料、热处理要求、螺纹类型或精度，原工艺要改版。
- 车间反映某道工序干不了（设备够不着、装夹不住、深孔钻不了），要重排工序或换设备。
- 报价或排产前要估工时，要一个能说清依据的估算方法。
- 新工艺员要一份可以照着填的工艺卡模板和典型零件的路线框架。

## 需要的输入

| 输入 | 常见形式 | 要点（以用户提供的为准） |
| --- | --- | --- |
| 零件图信息 | 图纸、PDF、或口述 | 零件名称、图号、材料牌号（42CrMo、35CrMo、40Cr、4145H 等）、毛坯形式（棒料 / 锻件 / 管料）、总长、最大外径、内孔直径与深度、关键配合尺寸的公差、表面粗糙度、螺纹类型（API 旋转台肩螺纹 NC / REG / IF / FH，或贵司专用螺纹）、热处理与硬度要求、表面处理、数量与交期 |
| 设备与能力 | 设备清单 Excel 或口述 | 设备编号、名称、型号、最大加工直径 / 长度、主轴通孔直径、深孔钻最大深度、是否数控、精度状态、当前是否可用 |
| 现有类似零件的工艺 | 工艺卡 Word / Excel / PDF | 图号、工序号、工序名称、设备、工序内容、装夹、刀具、量具、切削参数、工时 |
| 贵司工艺文件 | 切削参数表、螺纹加工规范、热处理规范、工时定额标准 | 有就以它为准；没有就用本技能的通用范围并标注 |

缺零件图信息不做，先要。缺设备清单先按油田工具厂常见设备（卧式车床、数控车床、深孔钻床、铣床 / 加工中心、花键加工设备、螺纹车床）排，每道工序标「设备待确认」。缺类似零件工艺就用下面的典型路线框架。缺贵司工艺文件时，参数只给通用范围。

## 工作步骤

1. **读图，列关键特性。** 把材料、热处理与硬度、配合尺寸（与公差）、螺纹、深孔、花键、密封面、粗糙度要求逐项列成表。图上标了关键特性符号的照抄；没标的，按下面「行业口径」里的判定规则初步标出，请用户确认。
2. **定毛坯与余量。** 根据材料、尺寸和数量判断毛坯形式（棒料、锻件、管料）。热处理前粗车的留量按贵司规定，缺省建议单边 2–4 mm，直径大、长径比大、易变形的取上限；留量太小热处理变形后精车不够，太大浪费工时。
3. **定热处理在路线里的位置。** 调质一般放在粗车之后、精车之前，让精加工去掉变形和氧化皮；表面处理（氮化、镀层、喷涂）放在精加工之后；有去应力要求的在粗加工后安排。用户的热处理要求和图纸不一致时先问。
4. **排工序顺序。** 遵守：基准先行、粗精分开、热处理分界、先外圆后内孔或先孔后外圆（看哪个做基准）、螺纹和密封面靠后、深孔在精车前完成以便精车校正同轴度。对照类似零件的工艺，差异逐条列出来。
5. **定每道工序的设备、装夹与基准。** 核对设备能力：零件最大直径能不能过主轴通孔或卡盘、长度够不够、深孔钻深度够不够；装夹方式（三爪 / 四爪 / 软爪、一夹一顶、两顶尖、中心架、跟刀架）和定位基准每道工序写明，前后工序基准尽量统一。
6. **定刀具与量具。** 刀具按工序内容写类型（外圆车刀、内孔镗刀、切槽刀、螺纹刀、深孔钻头、花键铣刀 / 拉刀），具体牌号按贵司刀具库和厂商推荐。量具按被测特性写（外径千分尺、内径量表、深度尺、螺纹环规 / 塞规、粗糙度样块或仪、硬度计）。
7. **给切削参数范围并写依据。** 按材料和硬度状态给通用范围（见「行业口径」），每个参数后面写「以贵司工艺文件和刀具厂商推荐为准」。不写精确到个位的「标准值」。
8. **估工时。** 按「机动时间 + 辅助时间 + 准备终结时间 ÷ 批量」的方法估，机动时间按切削长度、进给量、转速和走刀次数算出来，辅助时间与准备终结时间的系数按贵司定额标准；没有定额标准就标「估算，待定额员核」。
9. **标检验点。** 每道工序写检验方式（自检 / 首检 / 巡检 / 完工专检）和检验项目；关键特性所在工序必须有首检和完工专检；热处理后要有硬度检验；螺纹要有量规检验。
10. **成稿。** 先把工艺路线表（工序号、名称、设备、内容概要）和关键特性清单发给用户核对，再出完整工艺卡。用户改了顺序或设备，重新核对装夹与基准是否还成立。

## 行业口径与判断规则

**工序顺序的几条规矩**

- 基准先行：第一道切削工序先把后续定位用的端面、外圆或中心孔做出来。
- 粗精分开：粗加工去大余量、释放应力；精加工留小余量、保证精度；中间隔着热处理的更要分开。
- 热处理分界：调质前的工序叫粗车，调质后叫精车；路线里要写明「热处理后硬度合格再转精车」。
- 螺纹靠后：螺纹和密封面在精车后、尽量最后几道工序做，减少后续装夹磕碰；做完后要有防护措施（螺纹保护器）。
- 深孔先于精车：深孔钻完再精车外圆，用精车校正外圆与内孔的同轴度和壁厚差。

**油田工具常见零件的典型路线框架**（按贵司设备和图纸实际调整，不照搬）

| 零件 | 典型路线 | 要点 |
| --- | --- | --- |
| 上 / 下接头 | 下料 → 粗车（外圆、端面、钻内孔）→ 调质 → 硬度检验 → 精车（外圆、内孔、台肩、密封面）→ 车螺纹 → 螺纹量规检验 → 完工检验 → 防护 | 螺纹与台肩密封面同轴、台肩面垂直度是关键特性；内孔长的要用深孔钻 |
| 芯轴 | 下料 → 粗车 → 调质 → 硬度检验 → 校直（需要时）→ 精车（基准中心孔、外圆、花键轴段预留）→ 花键加工 → 螺纹 → 磨削或精车密封面 → 完工检验 | 长径比大，精车用一夹一顶或两顶尖加中心架；中心孔是全程基准；校直后要去应力或复查硬度按贵司规定 |
| 花键套 | 下料（管料或锻件）→ 粗车 → 调质 → 硬度检验 → 精车（内孔、外圆、端面）→ 内花键（拉削 / 插削 / 线切割，按设备）→ 螺纹 → 完工检验 | 内花键以精车后的内孔和端面定位；壁薄时夹紧要防变形 |
| 缸体 | 下料（管料）→ 粗车 → 调质 → 硬度检验 → 深孔（钻 / 镗 / 珩磨）→ 精车外圆与螺纹（以内孔定位）→ 完工检验 | 内孔是密封面，粗糙度和圆柱度是关键特性；壁厚均匀性靠内孔定位精车外圆来保证 |
| 活塞 | 下料 → 粗车 → 热处理 → 精车（外圆、密封槽）→ 完工检验 | 密封槽尺寸和外圆粗糙度是关键特性 |

**螺纹加工注意点**

- 油田工具螺纹多为 API 旋转台肩螺纹（NC、REG、IF、FH 等）或贵司专用螺纹，牙型、锥度、螺距和台肩尺寸按图纸和贵司螺纹规范，量规检验的方法和判定按 API Spec 7-2 类规范与贵司螺纹规范执行；本技能不给量规数值。
- 螺纹在调质后加工；车螺纹前先确认台肩面和螺纹基面精车到位，螺纹与台肩的同轴和垂直靠同一次装夹保证。
- 螺纹刀片牙型要和螺纹类型对应；多次走刀、最后一两刀小切深；螺纹表面粗糙度通常比外圆要求高。
- 加工后立即戴螺纹保护器；涂螺纹脂、磷化等按图纸要求安排工序。

**深孔加工注意点**

- 长径比大于贵司规定（缺省建议约 10）的孔按深孔处理，用枪钻、BTA 或深孔镗；普通麻花钻分段钻容易偏斜。
- 深孔前先把外圆和端面精车作基准，引导孔的同轴度决定深孔的走偏程度。
- 排屑和冷却是深孔的命：冷却液压力、流量、过滤按设备和刀具厂商要求；断屑不良要停下调参数，不硬顶。
- 深孔完成后检查壁厚差和直线度；超差的在精车外圆时以内孔定位校正。

**花键加工注意点**

- 内花键优先拉削（批量大）或插削、线切割（批量小、硬度高）；外花键用花键铣或滚齿设备。
- 花键在调质后加工时刀具寿命短，要按硬度调参数；调质前加工则要考虑热处理变形对齿形和分度的影响，按贵司经验定。
- 检验用花键量规或综合量规；没有量规的按图纸用跨棒距 / 齿厚测量。

**切削参数通用范围**（调质钢 42CrMo、35CrMo、40Cr 调质态，硬质合金刀具；以贵司工艺文件和刀具厂商推荐为准）

| 工序 | 切削速度 vc（m/min） | 进给量 f（mm/r） | 切深 ap（mm） | 备注 |
| --- | --- | --- | --- | --- |
| 粗车 | 80–150 | 0.2–0.4 | 2–5 | 硬度高取下限；机床功率和装夹刚性不够时降切深 |
| 精车 | 120–200 | 0.08–0.2 | 0.2–1.0 | 粗糙度要求高时降进给、用修光刃刀片 |
| 车螺纹 | 60–120 | 按螺距 | 分多刀递减 | 最后精车刀切深小；以螺纹刀片厂商推荐为准 |
| 深孔钻 | 枪钻与 BTA 差异大 | 差异大 | — | 以深孔设备和刀具厂商推荐为准，不在此给范围 |
| 铣削 | 80–150 | 每齿 0.05–0.15 mm | 按刀具 | 按刀具直径和齿数换算 |

硬度高于 32 HRC、材料是 4145H 等高淬透性钢、或机床老旧时整体往下限取；正火态或退火态材料可往上限取。

**工时定额的估算方法**

- 机动时间 =（切削长度 ÷（进给量 × 转速））× 走刀次数，每道工序逐项算，转速 = 1000 × vc ÷（π × 直径）。
- 辅助时间（装夹、换刀、测量、上下料）和准备终结时间按贵司定额标准取系数或固定值；没有标准时按机动时间的一定比例估并标注「估算」，缺省建议辅助时间按机动时间的 30%–60%，批量越小比例越高。
- 单件工时 = 机动 + 辅助 + 准备终结 ÷ 批量；数量不定时按用户给的批量算，并注明。

**关键特性的判定**（图纸有标识的以图纸为准）

- 与密封、承载、连接相关的尺寸：螺纹、台肩面、密封面、配合外圆 / 内孔、花键齿形。
- 热处理硬度与力学性能要求。
- 公差带窄、粗糙度要求高（按贵司规定，缺省建议 IT7 及以上或 Ra 1.6 及以下）的尺寸。

## 交付前自检

- [ ] 每道工序都有设备、装夹与基准、检验方式，没有「待定」却没标注的空格。
- [ ] 热处理的位置和图纸要求一致，热处理后的工序都写了「硬度合格后转序」。
- [ ] 设备能力核对过：直径、长度、通孔、深孔深度都装得下；装不下的标「设备待确认」。
- [ ] 切削参数都是范围，都注明了依据；没有抄来的「标准值」。
- [ ] 工时估算的方法和系数来源写清，没有凭印象填的数。
- [ ] 关键特性清单经用户确认，所在工序都有首检与专检。
- [ ] 与类似零件工艺的差异逐条列出，并说明原因。

## 边界

- 本技能给的是工艺路线草案和参数范围，不替代工艺员编制、审核与批准；签审栏留给用户。
- 不改贵司已批准的工艺文件和图纸；发现图纸与要求矛盾只提出，不替用户决定。
- 不选具体刀具牌号、不给螺纹量规数值、不给热处理炉工艺曲线；这些以贵司文件、刀具厂商和热处理工艺为准。
- 工艺下发、写入 ERP / MES、通知车间，都要先问用户。
