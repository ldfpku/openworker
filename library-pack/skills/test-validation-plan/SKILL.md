# 试验验证方案与报告

把一台样机该做什么试验、怎么加载、什么算合格、记什么数写成试验大纲，试验做完再把记录整理成能签放行的验收报告。

## 适用场景

- 新产品（液压震击器、机械震击器、减震器、加速器、螺杆钻具）样机做出来了，要编试验大纲。
- 设计改了结构、材料或密封，ECN 要求变更后再验证，要定做哪几项、怎么判。
- 客户或项目验收要一份试验报告，手头只有零散的试验记录和曲线。
- 某项试验没通过，要定下一步是改样品、改方法还是改判据。
- 试验验证岗要给设计岗一个明确的「做到哪一级、测哪些项」的清单。
- 试验记录散在数据采集导出文件和手写表里，要汇成一份带追溯的报告。

## 需要的输入

| 输入 | 常见形式 | 常见内容 / 列名（以用户文件为准） |
| --- | --- | --- |
| 验证等级 | 试验验证岗口头或书面给 | 原理样机 / 工程样机 / 定型 / 变更后再验证；变更后再验证的要附 ECN 编号和受影响项 |
| 产品规格与设计参数 | 设计说明、图纸技术要求、产品规格表 | 型号、外径、通径、总长、连接螺纹、额定拉伸载荷、额定扭矩、额定工作压力 / 压差、温度等级、震击力范围、延时范围、行程、材料与热处理状态 |
| 工况与失效后果 | 设计岗给 | 井深、井底温度、压力、载荷谱、介质、失效模式与后果（落井 / 卡钻 / 井控风险 / 停工 / 性能下降） |
| 标准要求 | 用户指明适用标准和客户技术协议 | API Spec 7-1、API Q1、客户规范；要求的具体条款由用户从原文里摘出来 |
| 样品信息 | 样品清单或随工单 | 样品编号 / 序列号、图号版本、材料炉批号、热处理记录编号、出厂检验记录编号、是否为正式工艺生产 |
| 已有试验记录 | Excel / 数据采集导出 CSV / 曲线图 | 试验日期、项目、样品编号、加载值（压力 / 载荷 / 扭矩）、保压时间、温度、泄漏 / 变形 / 位移读数、结果（合格 / 不合格）、试验员、设备编号 |

验证等级没定就先问试验验证岗，不替他定，也不按设计岗的意见定。工况与失效后果缺的，问设计岗。标准要求只按用户给的原文写，用户没给条款就只写标准名称。写报告时缺某项试验记录，报告里写「未提供记录」，不补数。

## 工作步骤

1. **确认等级和范围。** 记下验证等级、谁定的、什么时候定的；变更后再验证的要把 ECN 的受影响项抄下来，大纲只覆盖受影响项和与之联动的项。
2. **列设计参数和工况。** 把额定值（载荷、扭矩、压力、温度）和工况最大值并排列成一张表；工况最大值超过额定值的直接标出来，这是设计问题，先退回设计岗。
3. **选试验项目。** 按「行业口径」里的缺省项目矩阵选，再按失效后果加严或裁减；每一项的取舍写理由。裁掉的项要写「不做的原因」，不能默默少做。
4. **写每项的加载方式、合格判据、记录项。** 加载值、加载速率、保压 / 保载时间、循环次数、温度点，每个数要么来自设计参数、要么来自标准和客户要求、要么标「按贵司规定，缺省建议」。合格判据写成可测的量（泄漏量、压降、永久变形量、震击力范围），不写「无异常」。
5. **配设备与量具。** 每项试验写用什么设备、量程覆盖不覆盖、传感器精度等级、校准证书是否在有效期；不够的标「需外协或补校准」。
6. **写安全与风险控制。** 按高压、高温、吊装、储能释放、断裂飞溅五类逐项写控制措施和应急处置；高压试验的防护距离、泄压步骤必须写具体。
7. **定试验顺序。** 缺省先做不破坏的（尺寸复测、低压密封、功能动作），再做加载类（静压、拉伸、扭矩），再做冲击和高温，疲劳放最后；每项前后都复测关键尺寸和密封状态。
8. **出记录表。** 每项一张，列头与「记录项」一一对应，留样品编号、设备编号、环境温度、试验员、复核人。
9. **整理结果写报告。** 逐项把实测值与判据对照，写「合格 / 不合格 / 偏差」；偏差要写数值差多少、影响什么；结论和放行建议分开写。
10. **未通过的走处置流程。** 按「行业口径」里的流程，先分清是样品问题、试验方法问题还是判据问题，再定重测范围。
11. **给用户核对。** 大纲先给试验验证岗和设计岗看一遍再定稿；报告先核数据再核结论。

## 行业口径与判断规则

**缺省试验项目矩阵**（按贵司规定，缺省建议；√ 必做，○ 视失效后果选做，— 一般不做）：

| 项目 | 原理样机 | 工程样机 | 定型 | 变更后再验证 |
| --- | --- | --- | --- | --- |
| 尺寸与外观复测 | √ | √ | √ | √ |
| 功能动作（震击 / 释放 / 伸缩 / 转动） | √ | √ | √ | 受影响时 √ |
| 静压（内压、外压） | ○ | √ | √ | 承压件变更时 √ |
| 拉伸 | ○ | √ | √ | 受力件或材料变更时 √ |
| 扭矩 | — | √ | √ | 螺纹或传扭件变更时 √ |
| 冲击（震击力与延时） | ○ | √ | √ | 震击机构变更时 √ |
| 密封（低压、高压、温度） | ○ | √ | √ | 密封或配合变更时 √ |
| 高温功能 | — | ○ | √ | 温度等级或材料变更时 √ |
| 疲劳寿命 | — | ○ | √ | 受力件结构变更时 ○ |

定型样品建议用正式工艺和正式供应商的材料，样品数量按贵司规定，缺省建议不少于 2 台，疲劳至少 1 台做到预期寿命或破坏。

**各项试验的加载方式、合格判据、记录项**（数值一律以设计参数和贵司规定为准）：

- **静压**：内压按额定工作压力乘以贵司规定的试验系数，分级加压（缺省建议先 25%、50%、75% 再到试验压力），每级保压观察；试验介质缺省用水，不用气体。判据：保压期间压降不超过贵司规定值且无可见泄漏，卸压后关键尺寸无永久变形（与试验前复测对比）。记录：各级压力、保压时间、压降、环境温度、泄漏部位、试验前后尺寸。
- **拉伸**：按设计额定拉伸载荷乘以试验系数分级加载，保载后卸载；定型可加做到屈服或破坏并记录破坏位置。判据：试验载荷下无永久伸长超限、螺纹无滑扣、无裂纹（必要时加载后探伤）。记录：载荷—位移曲线、各级载荷与保载时间、卸载后总长变化、螺纹和退刀槽外观。
- **扭矩**：上扣扭矩按图纸或说明书值，工作扭矩按额定值加试验系数；螺杆钻具另做输出扭矩与转速、压降的台架曲线。判据：螺纹无粘扣、台肩无压溃、卸扣扭矩在合理范围；传扭件无塑性变形。记录：上扣 / 卸扣扭矩、工作扭矩与保持时间、螺纹和台肩外观、台架曲线。
- **冲击（震击）**：在震击试验台上按设定拉力或压力触发，测震击力峰值和延时；按贵司规定次数重复。判据：震击力和延时落在设计范围内，重复性满足贵司规定（缺省建议以极差占设定值的百分比考核）；试验后无渗漏、无卡滞。记录：每次的触发载荷、峰值、延时、温度、行程、异常现象。
- **疲劳寿命**：按工况载荷谱或等效载荷循环加载，循环数按预期寿命或入井次数折算；中途按固定间隔停机检查密封和尺寸。判据：达到规定循环数无裂纹、无泄漏、功能参数漂移不超限。记录：循环数、载荷幅值、停机检查结果、失效时的循环数与部位。
- **密封**：低压（检查唇形密封初始接触）和高压各一轮，必要时正反向加压；高温密封与高温功能合并做。判据：保压压降不超限、无可见泄漏、拆检密封件无挤出、切口、硬化。记录：压力、保压时间、压降、温度、拆检照片。
- **高温**：加热到温度等级并保温至整机温度均匀（用贴片热电偶确认）后做功能动作和密封试验。判据：温度下功能参数（震击力、延时、释放力）在设计范围内，冷却后无泄漏。记录：升温曲线、保温时间、各测点温度、温度下的功能参数。

**试验系数、保压时间、压降限值、循环次数**都是企业自定或标准规定的值，大纲里写「按贵司规定 / 按 XX 标准，值由用户填」，不替用户填数。

**常见坑**：

- 样品不是正式工艺做的（手工配研、代用材料）却按定型报；报告里必须写明样品工艺状态。
- 试验前没复测尺寸，试验后说不清变形是不是试验造成的。
- 高温试验只测了表面温度，内部油腔和密封没到温就开始做功能动作。
- 数据采集文件和手写记录对不上，报告引了其中一份没说明取舍。
- 「合格」写在了判据没定的项目上。

**失效后果决定加严方向**：失效后果为落井或井控风险的，静压、拉伸、密封按最严口径做且不裁减；只是性能下降的，疲劳可按抽样或缩短做，但要写明。

**量具与设备**：压力表、力传感器、扭矩传感器、位移计、热电偶、数据采集系统都要有在有效期内的校准证书；量程覆盖试验最大值并留余量（缺省建议试验值落在量程的 20%–80% 区间）；同一项试验前后用同一套量具。

**安全五类**：高压（防护屏、警戒区、远程操作、先泄压再接近、介质用水）；高温（隔热、防烫、冷却到位后再拆）；吊装（吊具额定载荷、试件固定、禁止站在下方）；储能释放（震击器、加速器、弹簧在带载状态下禁止拆卸）；断裂飞溅（拉伸和扭矩破坏试验加防护罩）。每类写责任人和应急步骤。

**未通过时的处置流程**：停止该项试验 → 保留样品状态和全部数据、拍照 → 复核量具和试验方法是否有误 → 分清三类原因：样品问题（设计、材料、加工、装配）、试验方法问题（加载方式、工装、量具）、判据问题（判据定得不合理或与标准不符） → 样品问题退设计岗分析，必要时走 ECN；方法问题改大纲后重做该项；判据问题由试验验证岗会同设计岗重新确认后再判 → 定重测范围（只重做该项，还是前序项目也要重做） → 全部记入报告的「偏差与处置」。

## 交付前自检

- [ ] 验证等级写明由试验验证岗确定，大纲没有自行升降等级。
- [ ] 每项试验都有加载方式、合格判据、记录项三件套，判据是可测的量。
- [ ] 试验系数、保压时间、压降限值、循环数没有替用户填，标了「按贵司规定」或留空待填。
- [ ] 没有引用标准条款号；标准要求只写用户给的原文。
- [ ] 裁掉的试验项写了原因；加严的写了失效后果依据。
- [ ] 报告里每个实测值都能回指到记录表编号和行号。
- [ ] 偏差没有被写成「合格」；未通过的项走了处置流程并记录。
- [ ] 安全措施覆盖高压、高温、吊装、储能释放、断裂飞溅五类。

## 边界

- 不定验证等级，不改验证等级；等级有争议时把分歧写出来让试验验证岗定。
- 不替设计岗做结构分析，不替用户判断失效原因；报告里原因只写试验观察到的事实和「建议核查」。
- 不编造标准条款、试验系数和限值；不把经验数当标准要求。
- 不出具对外的第三方检测报告效力；需要第三方时写「建议送检」。
- 放行建议由用户签署；把报告发给客户、录入系统、通知生产放行，都要先问用户。
