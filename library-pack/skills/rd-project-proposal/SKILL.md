# 科研项目立项书与结题报告

把一个技术问题变成评审会能批的立项书，把做完的工作变成验收会能核的结题报告：指标能测，成果能查，缺的东西明说。

## 适用场景

- 研发想开一个课题（新型震击器、高温密封、螺杆钻具定子材料、返厂故障的结构改进），要写立项书报公司或上级立项。
- 项目到期要结题，试验报告、图纸、专利受理通知散在各处，要整理成结题报告和验收材料。
- 立项书被打回，评审意见是「指标不可测」「现状没依据」「预算说不清」，要改。
- 要申报外部科技项目或高新技术企业相关材料，需要一份内部口径一致的项目材料做底稿。
- 项目中期要核一遍目标完成到哪了，哪些指标还没数据。
- 多个课题要用同一套格式，方便科研管理岗汇总和对比。

## 需要的输入

| 输入 | 常见形式 | 常见内容（以用户材料为准） |
| --- | --- | --- |
| 技术问题或机会 | 口头、会议纪要、返厂故障分析、客户需求 | 问题是什么、在哪个产品哪个工况出现、现在怎么应付、不解决的损失 |
| 现状与差距 | 自测数据、返厂记录、竞品或进口产品参数、文献和专利清单 | 本公司现有产品参数、同类产品参数、差在哪几个指标、差多少；文献和专利要有题名、来源、年份 |
| 目标 | 口头或需求表 | 想做到的参数、适用工况、时间要求 |
| 可用资源与预算 | 人员名单、设备清单、财务给的额度 | 人员与投入比例、可用试验设备、外协渠道、预算总额和科目限制 |
| 周期 | 口头 | 起止时间、硬节点（客户要货、招标、申报截止） |
| 过程记录（结题用） | 试验报告、设计评审记录、ECN、专利受理通知书、检测报告、应用记录、财务决算 | 文件编号、日期、结论 |

技术问题说不清楚就先问清楚再写，不替用户编背景。现状与差距没有数据的，立项书里写「待补：XX 指标的实测数据」，不写「国内领先」「填补空白」这类没有依据的话。结题时某项成果没有编号或原件，写「待补」，不写「已完成」。

## 工作步骤

1. **把问题说成一句话。** 「在 XX 工况下，XX 产品的 XX 指标为 A，客户 / 标准要求 B，导致 XX 损失」。说不出 A 和 B 的，先去要数据。
2. **核现状与差距。** 本公司数据回指到试验报告或返厂记录的编号和行号；同类产品数据回指到样本、文献或检测报告；差距用数字写。没有来源的数据不进立项书。
3. **定目标和指标。** 每个指标写成「名称 + 数值 + 单位 + 测量方法 + 判定条件」，例如「震击器在 XX ℃ 下延时 X–Y 秒，按试验大纲 XX 测，连续 N 次均落在范围内」。指标数量缺省建议 3–6 个，分「考核指标」和「参考指标」。
4. **写技术路线。** 从问题到指标之间要经过哪几步（分析 → 方案 → 样机 → 试验 → 应用），每步的关键技术是什么、为什么难、准备怎么解决、有没有备选路线。
5. **拆研究内容与分工。** 每项研究内容对应到技术路线的哪一步、由哪个岗位负责（结构设计、试验验证、工艺、科研与知识产权）、产出什么（图纸、样机、试验报告、专利申请）。验证等级由试验验证岗定，立项书里写「试验方案由试验验证岗按验证等级编制」。
6. **排里程碑。** 每个里程碑写日期、交付物、检查方式；缺省建议至少有方案评审、样机完成、试验完成、结题验收四个节点，硬节点往前留缓冲。
7. **列预算。** 按贵司科目；没有科目表时缺省建议分材料、试验与检测、设备与工装、外协、差旅、人工、知识产权七类。每笔有依据（询价、工时估算、历史项目），总额对上财务给的额度，不编单价。
8. **写风险与对策。** 技术风险（关键技术做不出来、试验不通过）、资源风险（设备排不上、人员被抽走）、进度风险（外协、采购）、合规风险（侵犯他人专利、标准更新）各至少一条，每条有触发条件、对策、责任人。
9. **写预期成果与验收标准。** 成果分技术成果（图纸、样机、试验报告、工艺文件）、知识产权（专利申请、软件著作权、技术秘密）、应用成果（试用、订单）、论文或标准（如有）；每项写数量和可核形式（编号、原件、受理通知）。验收标准直接对应第 3 步的指标。
10. **写知识产权安排。** 哪些内容申请专利、什么时候申请（缺省建议在样机公开试用和论文发表之前）、谁是发明人、与合作方的权属约定（引用合同原文，没有就标「待签」）。具体申请事宜用专利交底书技能和专利代理人走。
11. **结题时逐项对照。** 把立项书的每个指标和每项预期成果列成对照表，右边填实际值和证据编号；没达到的写差多少、原因、是否申请调整；多出来的成果单独列。
12. **算效益。** 口径先声明（替代进口、降本、减少返厂、新增销售），数据来自财务或销售，每个数字有来源；算不出来的写「定性说明」，不估数。
13. **列验收材料并给用户核对。** 按「输出」里的清单逐项核有没有、编号对不对，再定稿。

## 行业口径与判断规则

- **指标可测**：一个指标必须能回答「用什么测、测几次、什么算达到」；写不出测量方法的不是指标，是愿望，改成参考指标或删掉。
- **成果可核**：成果以「编号 + 原件在哪」为准。专利写「申请号 / 受理通知书编号」，不写「已申请专利 N 项」而没有号；试验写「试验报告编号」；图纸写「图号 + 版本」；应用写「客户、井号、入井日期、应用报告编号」。
- **现状与差距**：引用他人数据要写来源；「国内外现状」只写用户提供的文献、专利、样本能支持的内容，没有就写「待补文献调研」；不写无来源的排名和定性词。
- **目标与考核**：考核指标是验收时必须达到的，参考指标是努力方向；验收标准不能比考核指标松。中途要调指标的，走项目变更记录，不悄悄改立项书。
- **分工口径**：验证等级和试验项目由试验验证岗定，设计岗只提供工况和失效后果；立项书里的试验计划写到「做哪类验证、由谁定方案」为止。
- **预算**：外协和检测费要有询价依据；人工按贵司工时单价，没有就只写工时不写金额；预算与里程碑对应，能看出每个阶段花多少。
- **进度**：里程碑交付物必须是能看见的东西（图纸、样机、报告），「完成调研」不算交付物，「调研报告 XX 页」算。
- **知识产权时点**：对外公开（展会、论文、客户试用无保密协议）之前先提交申请，具体以专利代理人意见为准。
- **经济效益**：分「已实现」和「预计」两栏；预计效益要写假设（年用量、单价、替代比例）和来源；两者不混。
- **遗留问题**：没做完的、没达到的、试验中发现的新问题，都如实列，附建议和去向（转下一课题、转改进项、关闭）。

**指标写法对照**（左边不合格，右边合格）：

| 不合格的写法 | 合格的写法 |
| --- | --- |
| 显著提高高温密封性能 | 在 XX ℃、XX MPa 下保压 N 分钟压降不超过 X MPa，按试验大纲 XX 测，3 台样机全部通过 |
| 延长震击器使用寿命 | 台架疲劳试验达到 N 次循环无泄漏、无裂纹，震击力漂移不超过 X%，试验报告为证 |
| 降低成本 | 单台材料与加工成本较现行型号下降 X%，以 ERP 成本核算单为准 |
| 完成现场应用 | 在 N 口井完成入井试用，累计工作 X 小时，无因本产品导致的事故，应用报告为证 |

数值 X、N 由用户和评审会定，这里只给格式。

**常见坑**：

- 目标写了一堆形容词没有数；指标有数但没写怎么测。
- 预算总额对上了，科目加起来不等；人工单价是编的。
- 里程碑全挤在最后一个月；交付物写成「完成 XX 工作」。
- 结题报告的指标值和试验报告里的不一致，或引用的报告编号查不到。
- 成果清单里的专利只有名称没有申请号；应用成果没有客户和井号。
- 现状分析把网上看来的参数当成实测数据。

## 交付前自检

- [ ] 每个考核指标都有数值、单位、测量方法、判定条件。
- [ ] 现状与差距的每个数字都有来源；没有来源的已标「待补」。
- [ ] 国内外现状只写了用户材料能支持的内容，没有「领先」「空白」类无依据表述。
- [ ] 预算科目之和等于总额，每笔有依据；人工没有编单价。
- [ ] 里程碑都有交付物和检查方式，硬节点前有缓冲。
- [ ] 预期成果每项写了可核形式；结题成果清单每项有编号。
- [ ] 结题对照表的实际值与试验报告一致，未达到的没有被写成达到。
- [ ] 验证等级和试验项目没有替试验验证岗定。
- [ ] 效益分了已实现和预计，假设写清。

## 边界

- 只整理和成稿，不替用户决定课题值不值得立、指标定多高；指标由用户和评审会定。
- 不编造现状数据、文献、竞品参数、单价和效益；缺就标「待补」。
- 不代替专利代理人判断能否授权，不出法律意见；知识产权安排只写时点和分工。
- 不替试验验证岗定验证等级和试验项目。
- 提交立项系统、报送上级、对外申报、发给合作方，都要先问用户。
