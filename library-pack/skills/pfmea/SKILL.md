# 过程 FMEA

把工艺流程逐道工序过一遍「会怎么失效、后果多严重、多常发生、能不能拦住」，排出优先级，落到措施和控制计划上，而不是做一张谁也不看的表。

## 适用场景

- 新产品、新工艺、新设备投产前要做 PFMEA，客户或 API Q1 审核要查。
- 老 PFMEA 好几年没动，要结合这段时间的不良和返厂故障更新。
- 工艺变更（换材料、换刀具方案、改热处理参数、换供应商）后要评估风险。
- 客户投诉或返厂故障追溯到某道工序，要看 PFMEA 里有没有这条、评分对不对。
- 想知道哪些工序风险最高，检验资源该往哪里放。

## 需要的输入

| 输入 | 常见形式 | 常见列名或内容（以用户文件为准） |
| --- | --- | --- |
| 工艺流程与工序 | 工艺卡、工艺流程图、工序清单 | 工序号、工序名称、设备、工装、工艺参数、加工内容 |
| 产品与过程要求 | 图纸、技术要求、检验规程 | 关键尺寸与公差、硬度、粗糙度、螺纹规范、试压压力、API 要求 |
| 历史不良 | 检验记录、不良品处理单 | 日期、设备、零件、工序、不良类型、数量、原因分析、措施 |
| 返厂故障 | 返厂检验记录、维修记录 | 工具类型、故障部位（失效部位 / 故障位置）、故障现象、处理措施、累计入井时间 |
| 设备与工装 | 设备台账、点检表、维修记录 | 设备编号、点检项目、异常记录、维修频次 |
| 现有 PFMEA（更新时） | Excel | 工序、失效模式、S、O、D、RPN、措施、状态 |
| 评分准则（可选） | 贵司或客户的 S / O / D 表 | 没有就用本技能的通用表并注明 |

至少要有工序清单和产品要求；没有历史不良和返厂记录也能做，但 O 和 D 只能按经验估，要注明「待数据验证」。做更新时必须有现有 PFMEA。

## 工作步骤

1. **定范围。** 确认是整条流程还是某几道工序、哪个产品型号 / 规格、用哪套评分准则（贵司、客户、还是本技能缺省）、输出 RPN 还是 AP。
2. **读工艺流程。** 把工序按顺序列出来，每道写设备、工装、关键参数。缺的问用户；不要替用户补工序。
3. **写功能要求。** 每道工序回答「这道工序要做到什么」：尺寸、形位、硬度、清洁度、扭矩、压力。要求要可测量，引用图纸或工艺卡的数值。
4. **列失效模式。** 每条要求至少想「没做到、做过头、做错位置、做漏了」四种；再把历史不良类型和返厂故障部位逐条对进去：每一种出现过的不良都必须能在表里找到对应的失效模式，找不到就是表漏了。
5. **写影响与严重度 S。** 影响分三层：对本工序 / 下道工序、对总成（装配不上、试压渗漏）、对最终用户（井下失效、落井、无法起钻）。S 按最严重的那层评。
6. **写原因与频度 O。** 原因写到可以控制的层面（刀补未更新、炉温均匀性超差、密封件导入无倒角），不写「操作不当」。O 用历史不良率、处理单次数、返厂次数估，有数据就标数据来源。
7. **写现行控制与探测度 D。** 预防控制（防错工装、参数固化、点检、首件）和探测控制（巡检、终检、试压、磁粉 / 超声）分开写。D 看探测控制能不能在流出前发现：没有检验项目的 D 高；靠目视的 D 高；靠量具全检的 D 低。
8. **算优先级。** RPN = S × O × D；或按 AP 口径（先看 S，再看 O，最后看 D）。按优先级从高到低排序。
9. **出建议措施。** 高优先级的每条给措施：优先降 O（防错、工艺固化、更换方案）其次降 D（加检验项目、换量具、加防错探测）；S 一般改不了，除非改设计。措施写责任人、期限。
10. **衔接控制计划。** 每条 S ≥ 8 或优先级高的特性，核对控制计划和检验规程里有没有对应的检验项目、频次和反应计划；没有的列出来交 `control-plan-inspection` 技能补。
11. **实施后重新评分。** 措施落实后用实际数据重评 O、D，记录新 RPN / AP；没落实的保留旧分，不要提前改。
12. **给用户核对。** 先把高优先级前 5–10 条发给用户确认评分和措施，再出全表。

## 行业口径与判断规则

**S / O / D 通用评分准则（1–10）**

以贵司或客户的准则为准；没有时用下表，并在表头注明「通用准则」。

| 分 | 严重度 S（影响） | 频度 O（原因发生） | 探测度 D（现行探测控制） |
| --- | --- | --- | --- |
| 10 | 危及人身安全或违反法规，无预警（井下落物、承压件断裂） | 极高，几乎每批都出 | 无法探测，没有任何检验 |
| 9 | 危及安全或违反法规，有预警 | 很高 | 几乎不能探测，靠偶然发现 |
| 8 | 产品丧失主要功能（震击器不动作、钻具不传扭）| 高，反复出现 | 很低，目视抽查 |
| 7 | 主要功能下降，客户很不满（释放力偏低、寿命明显缩短） | 较高 | 低，目视全检 |
| 6 | 次要功能丧失（渗漏、噪音） | 中等 | 中等，抽样量具检验 |
| 5 | 次要功能下降 | 中等偏低 | 中等，量具全检或终检 |
| 4 | 外观或可返修的缺陷，多数客户会注意 | 低 | 较高，本工序量具全检加终检 |
| 3 | 轻微缺陷，部分客户注意 | 很低 | 高，有防错探测或自动测量 |
| 2 | 很轻微，少数客户注意 | 极低 | 很高，多道独立探测 |
| 1 | 无影响 | 几乎不可能 | 几乎肯定能探测，防错使之不能流出 |

O 的分数对应多大的不良率，按贵司规定；缺省建议用「近 6–12 个月该失效模式的处理单次数或不良率」排相对高低，不硬套 ppm。

**优先级口径**

- RPN：缺省建议 RPN ≥ 100、或 S ≥ 9、或 S × O ≥ 40 的必须有措施；按贵司规定调整。RPN 相同时 S 高的优先。
- AP（行动优先级，AIAG-VDA 口径）：按 S、O、D 的组合查手册里的 AP 表定 H / M / L；原则是 S 高的即使 O、D 低也要优先，D 低不能抵消高 S 高 O。贵司采用 AP 时按手册表查，本技能不复制那张表。
- 用哪种以客户要求为准；都没要求时用 RPN，简单。

**本行业常见失效模式提示**（用来查漏，不是现成答案）

| 工序 | 常见失效模式 | 常见原因方向 |
| --- | --- | --- |
| 车削 / 螺纹 | 中径超差、牙型不对、粗糙度不合格、粘扣 | 刀片磨损、刀补、主轴 / 卡盘跳动、程序、材料硬度 |
| 深孔钻 / 镗 | 直线度超差、内径超差、壁厚不均 | 钻杆支撑、导向、切削参数、冷却 |
| 热处理 | 硬度不合格、硬度不均、变形、开裂 | 温控仪表、炉温均匀性、装炉量、冷却介质、材料炉号 |
| 装配 | 密封件划伤、装反、漏装、扭矩不到 | 导入倒角、清洁度、工装、作业指导 |
| 试压 / 测试 | 渗漏、释放力不符 | 密封、装配、测试程序、仪表校准 |
| 外协 | 外协件尺寸 / 硬度不符、无报告 | 供应商过程、来料检验 |

返厂故障（密封失效、芯轴拉伤、定子脱胶、花键磨损、碟簧断裂）进 PFMEA 时，先区分是制造 / 装配原因还是井下工况原因；工况原因进设计 FMEA 或使用说明，不要硬塞进过程 FMEA。

**更新时机**（按贵司规定，缺省建议）

- 工艺、设备、工装、材料、供应商变更（ECN）时。
- 客户投诉、返厂故障、内部重复不良追溯到某工序时：同步更新该工序的 O、D 或新增失效模式。
- 每年至少评审一次；没变化也写评审记录。
- 新 8D 关闭时，D7 要回填 PFMEA。

**和控制计划、检验规程的关系**

PFMEA 找出「哪里会出事」，控制计划定「怎么盯住」，检验规程定「具体怎么检」。三者的特性要一一对应：PFMEA 里 S ≥ 8 的特性，控制计划必须有；控制计划里的检验项目，检验规程必须有方法和判定。

**填表时的常见错误**

- 失效模式写成原因：「刀片磨损」是原因，失效模式是「中径超差」。
- 影响只写本工序：「尺寸不对」不是影响，要写到「装配不上 / 密封失效 / 井下无法释放」。
- 一条失效模式只写一个原因：实际常有多个，分行写，各自评 O。
- 现行控制只写「检验」两个字：要写清是首件、巡检还是终检，用什么量具，频次多少，否则 D 评不准。
- 用低 D 掩盖高 O：靠全检兜底的工序 RPN 看着不高，但成本和流出风险都在，措施要优先降 O。
- 措施写「加强培训」：不能验证，既不降 O 也不降 D。

**重新评分的口径**

- 措施实施后至少积累一个评价周期的数据（按贵司规定，缺省建议 3 个月或 20 批）再重评 O。
- D 只有在探测控制实际变了（新增检验项目、换量具、加防错）才能改。
- S 不随措施改变，除非设计或用途变了。
- 旧分数保留在表里，新分数另列，审核时要看得到变化。

## 输出

```markdown
# PFMEA：<产品 / 规格>（版本、日期、评分准则：贵司 / 客户 / 通用）

## 一、范围与基础信息
产品、工序范围、依据的工艺卡版本、图纸版本、参与人员、使用的评分准则与优先级口径。

## 二、PFMEA 表
| 工序号 | 工序 / 设备 | 功能要求 | 潜在失效模式 | 潜在影响 | S | 潜在原因 | O | 现行预防控制 | 现行探测控制 | D | RPN / AP | 建议措施 | 责任人 | 期限 | 实施情况 | S' | O' | D' | RPN' / AP' |
（按工序顺序；同一失效模式多个原因分行）

## 三、优先级清单
按 RPN / AP 从高到低；每条写依据（历史不良 N 次、返厂 M 次、来源文件与行号）。

## 四、措施清单
| 序号 | 工序 | 针对的原因 | 措施 | 类型（降 O / 降 D） | 责任人 | 期限 | 验证方式 |

## 五、与控制计划的核对
| 特性 | S | 控制计划有无 | 检验规程有无 | 差距与建议 |

## 六、本次更新说明（更新时）
变更内容、依据（处理单号、返厂记录、ECN 号）、评分变化。

## 数据来源
工艺卡、图纸、检验记录、处理单、返厂记录的文件名、工作表、行数；评分准则来源。
```

## 交付前自检

- [ ] 每道工序都有功能要求，且要求可测量、能回指到图纸或工艺卡。
- [ ] 历史不良类型和返厂故障部位逐条对进了失效模式，没有漏项。
- [ ] 原因写到可控层面，没有「操作不当」「责任心不强」。
- [ ] 预防控制和探测控制分开写，D 的评分和实际检验方式一致。
- [ ] S / O / D 用的准则已注明来源（贵司 / 客户 / 通用）。
- [ ] 高优先级条目都有措施、责任人、期限；措施优先降 O。
- [ ] S ≥ 8 的特性和控制计划、检验规程核对过。
- [ ] 未实施的措施没有提前改分；O 没有数据支撑的标了「经验估计」。

## 边界

- 评分最终由跨部门小组定，本技能给草案和依据，不替用户拍板。
- 不编造工序、参数、不良率；缺的写「待补」。
- 设计类原因（结构、材料选型）记录下来转设计 FMEA，不在过程 FMEA 里展开。
- 不修改用户现有的 PFMEA 文件，输出新版草案由用户审核后替换。
- 向客户提交 PFMEA、写入文件系统、发起 ECN，先问用户。
