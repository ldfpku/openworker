# 热处理工艺与记录核查

把一炉零件的热处理要求、工艺参数和过程记录对到一起：参数在不在合理范围、设备状态有没有凭证、硬度结果和回火温度对不对得上，不合格时按顺序排查，不乱猜。

## 适用场景

- 新零件或新材料要定调质工艺，想先知道通用参考范围，再对照贵司工艺文件定稿。
- 一批零件热处理完要放行，要把记录逐项核一遍再签。
- 硬度检测不合格或同炉硬度散差大，要找原因，又不想一上来就换料。
- 客户或审核员要看热处理记录，要确认记录项目齐不齐、能不能追溯。
- 热处理车间要统一记录表，要一份字段齐全的模板。

## 需要的输入

| 输入 | 常见形式 | 常见列名或内容（以用户文件为准） |
| --- | --- | --- |
| 材料与要求 | 图纸技术要求、材质单、口述 | 牌号、炉号 / 材料批号、材质单上的化学成分、热处理状态（调质 / 正火 / 淬火 + 回火）、硬度要求（HRC / HB，范围与检测位置）、力学性能要求（抗拉、屈服、延伸率、冲击）、有效截面尺寸或零件最大直径 |
| 炉子信息 | 设备台账、口述 | 炉号、炉型（箱式 / 井式 / 台车式 / 连续式）、加热方式（电 / 燃气）、有效加热区尺寸、额定温度、控温仪表型号、热电偶类型与安装位置 |
| 热处理记录 | 每炉一张记录表，Excel 或纸质扫描 | 日期、炉号、工艺卡号、零件 / 图号、数量、装炉方式与装炉量、淬火温度、升温时间、保温时间、出炉到入淬时间（转移时间）、冷却介质与介质温度、回火温度、回火保温时间、回火次数、操作者、检验员 |
| 硬度检测记录 | 热处理记录的一部分或单独一张表 | 检测位置、检测方法（洛氏 / 布氏 / 里氏）、每件读数、硬度计编号、标准块校验结果 |
| 设备校准与均匀性记录 | 计量台账、测试报告 | 炉温均匀性测试日期与有效期、控温仪表与记录仪校准日期与有效期、热电偶校准或更换记录、系统准确度校验记录 |
| 贵司热处理工艺文件 | 工艺规程、作业指导书 | 有就以它为准；没有就用本技能的通用范围并标注 |

缺材料牌号或硬度要求不做核查，先要。缺记录只能给参考范围和模板。缺校准与均匀性记录可以核其他项，但结论要写「设备状态凭证未提供」。

## 工作步骤

1. **确认要求。** 把牌号、硬度范围、检测位置、力学性能要求、有效截面尺寸列成一张表。硬度单位统一（HRC 与 HB 换算按 GB/T 1172 或贵司换算表，只作参考，验收以图纸标注的单位和方法为准）。要求与图纸、客户规范不一致时先问。
2. **读全记录。** 逐炉读，记下记录表的文件名、工作表、行号；缺项（没填保温时间、没填油温、没填转移时间）逐项列出，不补。
3. **核工艺参数。** 把记录上的淬火温度、保温时间、冷却介质、回火温度、回火时间与贵司工艺文件比；没有工艺文件就与本技能的通用参考范围比，超出范围的标出来，并注明「以贵司工艺文件为准」。
4. **核设备状态。** 炉温均匀性测试是否在有效期内、有效加热区是否覆盖装炉位置；控温仪表、记录仪、热电偶是否在校准有效期内；硬度计是否在校准期、用标准块校验过。任何一项过期或没有凭证都单列。
5. **核过程记录。** 升温速率与保温时间是否和装炉量、截面匹配；出炉到入淬的转移时间是否记录；淬火介质温度是否在范围；淬火后到回火的间隔；回火温度、时间与次数是否按工艺。
6. **核硬度结果。** 检测点数量和位置是否按贵司规定；读数是否全在范围内；同炉件间的散差；回火温度与硬度的趋势是否对应（回火温度高了硬度应该低，反了就有问题）；力学性能试样是否随炉。
7. **不合格排查。** 有硬度不合格或散差大的，按「行业口径」里的排查路径逐项问、逐项查，每项写「已排除 / 可疑 / 待查」，不跳步。
8. **成稿。** 先把核查结论表发给用户确认，再出完整报告；用户补了缺项或凭证再更新结论。

## 行业口径与判断规则

**调质工艺的通用参考范围**（只作参考，不作验收依据；淬火、回火温度与时间以贵司工艺文件和材料手册为准，不给精确到度的「标准值」）

| 材料 | 淬火温度参考区间 | 冷却介质 | 回火温度参考区间（调质） | 硬度趋势 |
| --- | --- | --- | --- | --- |
| 42CrMo | 约 830–880 ℃ | 油（大截面或贵司规定时可用水 - 油或聚合物） | 约 500–650 ℃ | 回火温度升高硬度降低；高温回火对应中等硬度 |
| 35CrMo | 约 840–880 ℃ | 油 | 约 500–650 ℃ | 同上 |
| 40Cr | 约 830–870 ℃ | 油 | 约 480–640 ℃ | 同上；淬透性比 42CrMo 低，大截面心部硬度偏低 |
| 用户给的其他牌号 | 按材料手册和贵司工艺文件 | | | 不编造，缺就说缺 |

- 调质态的常见硬度带大致在 HB 240–330 或 HRC 24–36 之间，具体对应温度因炉子、截面、装炉量、材料成分波动而不同；只能说「回火温度越高硬度越低」的趋势，不能说「某温度等于某硬度」。
- 保温时间按有效截面厚度和装炉量估，装炉密、截面大要延长；具体按贵司工艺文件，缺省建议在工艺文件范围内按装炉情况取偏上限，并在记录里写明依据。
- 淬火转移时间要短，按贵司规定，缺省建议记录在案并不超过工艺文件给定的上限。
- 淬火油温常见范围约 40–80 ℃，以油品说明和贵司规定为准；油温过低冷却太急易开裂，过高冷却不足硬度偏低；连续淬火要关注油温上升。
- 淬火后应尽快回火，按贵司规定，缺省建议不超过 4 小时；合金钢淬火后放置过久有开裂风险。
- 回火次数：一般调质一次回火；硬度偏高需补回火的，补回火温度在贵司工艺文件的回火区间内取比原回火略高的值，不超过区间上限；硬度偏低补回火无效，要重新淬火再回火，返工按贵司规定。

**设备状态核查口径**

- 炉温均匀性测试（有效加热区测定）：周期按贵司计量制度，缺省建议至少每年一次，炉子大修、更换加热元件或热电偶后复测；装炉位置必须在有效加热区内。
- 控温仪表、记录仪、热电偶：按贵司计量周期校准，缺省建议不超过一年；热电偶按使用温度和时长定期更换或校验；系统准确度校验按贵司规定。
- 硬度计：在校准期内，每班或每批检测前用标准块校验并记录；里氏硬度计读数只作参考，仲裁用洛氏或布氏。
- 任何一项没有凭证，结论只能写「设备状态未证实」，不能写「设备正常」。

**硬度检测口径**

- 检测数量与位置按贵司规定，缺省建议每炉不少于 3 件且覆盖炉内不同位置（上 / 中 / 下、前 / 后、边 / 中），每件至少 3 点取平均并保留单点读数。
- 检测面要磨平去氧化皮，表面脱碳层会使读数偏低；大截面零件心部与表面硬度不同，图纸没说位置时问用户。
- 同炉件间硬度散差按贵司规定，缺省建议超过 3 HRC 或 30 HB 即视为散差大，要查均匀性和装炉。
- 力学性能试样要随炉同处理，取样位置和试样尺寸按图纸或贵司产品规范；拉伸、冲击结果与硬度矛盾时以试验结果为准并查原因。

**硬度不合格的排查路径**（按顺序，每项写明已排除还是可疑）

1. 先查检测本身：硬度计校准与标准块校验、检测面处理、检测位置是否和要求一致、单位换算有没有错。
2. 查仪表与热电偶：控温仪表显示与记录仪是否一致、校准是否过期、热电偶是否老化或插入深度不对；仪表漂移会让整炉同向偏差。
3. 查炉温均匀性与装炉：均匀性测试是否过期、零件是否超出有效加热区、装炉过密或贴炉壁、工件之间有没有留间隙；均匀性问题通常表现为同炉不同位置硬度不同。
4. 查回火参数：回火温度、时间是否按工艺，有没有记录与实际不符；整炉偏软先怀疑回火温度偏高或淬火冷却不足，整炉偏硬先怀疑回火温度偏低。
5. 查淬火冷却：介质种类、介质温度、搅拌、转移时间、装炉量过大导致冷速不足；冷却不足表现为硬度偏低且心部更低。
6. 查截面与淬透性：大截面零件用 40Cr 等淬透性较低的钢，心部硬度达不到要求不是操作问题，是选材或工艺问题，要反馈设计和工艺。
7. 查材料：材质单上的化学成分是否在牌号范围内、是否混料、同一炉号不同批次是否结果不同；有疑问时做成分复验，不先下「材料不合格」的结论。
8. 复查结论：以上都排除后再考虑返工（重新调质或补回火），返工方案按贵司工艺文件，返工次数按贵司规定。

**常见坑**

- 记录表上温度填的是设定值不是实测值，要看记录仪曲线或实测值栏。
- 保温时间从「到温」算起，不是从入炉算起；记录没区分的要问。
- 燃气炉与电炉的均匀性差异大，不能套用同一经验。
- 里氏硬度计测薄壁件或小件读数不可靠，不能作验收依据。
- HRC 与 HB 换算只在一定范围内近似，不能用换算值判合格 / 不合格。

## 交付前自检

- [ ] 每个参数都写了记录值、对照依据（贵司工艺文件或通用范围）和结论，没有只写「正常」。
- [ ] 设备状态每项都有凭证或写了「未提供」，没有把「未提供」写成「合格」。
- [ ] 硬度判定用的是图纸的单位和方法，换算值只作参考。
- [ ] 回火温度与硬度的趋势核对过，反常的已单独标出。
- [ ] 不合格排查按顺序逐项写了结果，没有跳到「材料问题」。
- [ ] 通用参考范围处都标了「以贵司工艺文件和材料手册为准」。
- [ ] 缺项和疑点列在「数据来源」，没有补数。

## 边界

- 只做核查和参考，不替代热处理工程师的工艺签批和检验员的放行签字。
- 不下「材料报废」「零件报废」的结论；返工与否、返工方案由用户按贵司工艺文件决定。
- 不修改用户的原始记录；发现记录与实际不符只指出。
- 通用参考范围不是贵司工艺，不能直接写进工艺卡；要定工艺请用户以贵司工艺文件和材料手册为准。
- 向客户或审核方提交核查报告、写入系统，都要先问用户。
